# 管理沙盒资源

macOS 受控命令使用 Seatbelt，计算只控制时长，网络采用授权开关，不提供 Linux 资源硬配额。原生路径、撤权和转发边界见 [macOS 原生命令权限](https://molr.ai/zh/docs/admin/sandbox/macos/)。

本页面向管理员。在「资源 → 沙盒」连接执行机器，并添加部署允许的存储、计算和网络资源。助理工作区始终在 Runtime 本地。

## 本机资源与成员范围

本机沙盒由 Runtime 内置，无需单独启动服务。计算资源自动登记；外部目录和网络在对应沙盒分区添加。宽松配置允许输入这台机器上的绝对目录路径或 `~/` 路径；受限配置可选择部署开放的根目录，并填写相对子目录。连接与添加不会自动授予助理权限。

通过[用户组](https://molr.ai/zh/docs/admin/administration/users-and-groups/)分配沙盒和工具，成员再为自己的助理批准目录读写、计算和网络权限。GPU 设备需由部署者先开放，再在用户组计算配置中选择；空选择表示不允许 GPU。Full Access 也需要部署开放，并由管理员明确允许对应用户组授予。

部署依赖、GPU 与网络候选范围见[Linux 沙盒部署](https://molr.ai/zh/docs/admin/sandbox/linux/)。用户授权与用量见[权限与预算](https://molr.ai/zh/docs/user/guides/permissions-and-budget/)。

## 在 WebUI 连接

每个远程沙盒实例只供一个 Runtime 使用，请勿在多个 Runtime 之间复用同一实例或连接凭证。当前服务不会阻止多个 Runtime 接入，也没有按 Runtime 隔离权限和操作状态。多个 Runtime 需要分别部署独立的[沙盒实例](https://molr.ai/zh/docs/admin/sandbox/remote/)。

1. 进入「资源 → 沙盒 → 连接沙盒」，填写名称、HTTPS 服务地址、证书指纹和令牌，先「测试连接」，通过后保存。修改地址、指纹或令牌后需重新测试。
2. 进入该沙盒的「存储 / 计算 / 网络」分区，接入目录或网络资源。目录可选择开放的根目录及子目录；宽松配置还可填写目标机器的本机路径。计算限制只读展示，页面遵守实际部署范围。
3. 通过资源卡片「授权给助理」授予外部存储读写、计算执行或网络使用权限，并可查看、修改和撤销已有授权；也可继续在助理权限页管理。连接远程电脑不会自动授予任何资源权限，也不会创建助理工作区。
4. 助理默认在本地工作。远程文件和 Shell 调用必须显式传 `sandbox_id`，并使用该节点的资源；省略节点但引用远程资源会被拒绝。远端不存在助理 `/work`，也不发现远端 AGENTS.md、skills 或记忆。

页面分别显示连接、存储和计算状态；连接成功不代表计算隔离就绪。「重新检查」刷新实际能力，离线时保留连接时的配置快照。沙盒菜单中「重命名」只更改显示名称，无需再次输入令牌；「更新连接凭证」和「断开沙盒」独立处理。桌面端使用沙盒列表，手机端使用选择框；当前沙盒和分区会在同一浏览器标签内记忆。

沙盒状态、能力和资源详情默认缓存 5 分钟，页面显示检查时间。“重新检查”会立即获取并更新状态与详情；编辑连接或资源后，当前页面也会重新检查。助理、授权和资源列表仍实时读取，实际执行时的权限及隔离检查不使用页面缓存。

Runtime 的 `network.allowed_private_ips` 继续限制它连接私网服务。远程 Sandbox 位于私网时，部署者需明确允许该地址；WebUI 无法修改此限制。禁止重定向，解析后拨号仍经过现有网络 guard。Sandbox 的网络资源描述的是执行机器所处的网络，其中回环地址指该执行机器。
