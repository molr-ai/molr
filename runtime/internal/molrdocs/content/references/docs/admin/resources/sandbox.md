# 管理沙盒资源

macOS 受控命令使用 Seatbelt，计算只控制时长，网络采用授权开关，不提供 Linux 资源硬配额。原生路径、撤权和转发边界见 [macOS 原生命令权限](https://molr.ai/zh/docs/admin/sandbox/macos/)。

本页面向管理员。在「资源 → 沙盒」连接执行机器，并添加部署允许的存储、计算和网络资源。助理工作区始终在 Runtime 本地。

## 本机资源与成员范围

本机沙盒由 Runtime 内置，无需单独启动服务。默认计算和网络资源只在实例首次初始化时按部署策略登记，后续启动不补建。已接入目录和其他网络资源在对应分区添加。宽松配置允许输入这台机器上的绝对目录路径或 `~/` 路径；受限配置可选择部署开放的根目录，并填写相对子目录。连接与添加不会自动授予助理权限。 目录路径末尾的分隔符会自动移除；目录不存在、不可访问、包含符号链接或超出允许范围时，保存会在路径输入框下提示对应原因，修改路径或目录来源后清除提示。

通过[用户组](https://molr.ai/zh/docs/admin/administration/users-and-groups/)分配沙盒和工具，成员再为自己的助理批准目录读写、计算和网络权限。GPU 设备需由部署者先开放，再在用户组计算配置中选择；空选择表示不允许 GPU。Full Access 也需要部署开放，并由管理员明确允许对应用户组授予。

部署依赖、GPU 与网络候选范围见[Linux 沙盒部署](https://molr.ai/zh/docs/admin/sandbox/linux/)。用户授权与用量见[权限与预算](https://molr.ai/zh/docs/user/guides/permissions-and-budget/)。

计算分区专门表示受控命令执行：分别提示命令执行未启用、受控计算不可用、节点离线或已断开；可用时展示计算额度。不可用时显示具体原因和处理方式，不提示开放目录或网络。计算资源卡片和新增授权入口遵守当前受控执行能力；已有授权可查看和撤销。完全访问在独立分区管理，覆盖服务账号可访问的存储、计算和网络；受控计算不可用时，完全访问仍可能可用，需要单独授权并显式调用，普通调用不会自动回退。

## 断开、重新连接与删除

默认列表显示未断开的资源，暂时不可用的条目也保留并显示原因。目录、计算和网络分区的「已断开资源」入口集中显示断开记录；打开入口时加载最新状态；存在有效授权时禁用删除，悬停、聚焦或点击禁用菜单项可查看原因，不探测断开资源。

「断开资源」暂停使用并保留配置、授权及额度用量。「重新连接」重新校验原资源是否仍可用，成功后仍有效的授权恢复生效，资源 ID、授权有效期和额度用量保持不变；校验失败保持断开。断开的计算资源可查看并撤销普通计算和完全访问授权。

只有已断开且没有有效授权的资源才能删除。所有账号的未撤销、未过期授权都会阻止删除，包括暂不可用助理持有的授权；由授权所属账号先撤销，删除不会代为撤权。已撤销或已过期的授权及历史使用记录不阻止删除。删除只移除接入配置，目录文件、部署网络规则和历史记录保留；重新添加产生新资源，需要重新授权。内置助理工作区不能断开或删除。

首次初始化原子创建账号和策略默认资源，失败时一起回滚。后续启动和「重新检查」只检查未断开的已有资源，不自动恢复断开条目，不根据空列表或新增部署规则补建资源。同一网络规则可被多条独立资源引用，断开或删除其中一条不影响其他条目。

## 在 WebUI 连接

每个远程沙盒实例只供一个 Runtime 使用，请勿在多个 Runtime 之间复用同一实例或连接凭证。当前服务不会阻止多个 Runtime 接入，也没有按 Runtime 隔离权限和操作状态。多个 Runtime 需要分别部署独立的[沙盒实例](https://molr.ai/zh/docs/admin/sandbox/remote/)。

1. 进入「资源 → 沙盒 → 连接沙盒」，填写名称、HTTPS 服务地址和沙盒端导出的连接码，先「测试连接」，通过后保存。连接码不包含地址，地址由用户自行填写；格式版本和节点协议兼容性自动校验。修改地址或连接码后需重新测试。
2. 进入该沙盒的「存储 / 计算 / 网络」分区，接入目录或网络资源。目录可选择开放的根目录及子目录；宽松配置还可填写目标机器的本机路径。计算限制只读展示，页面遵守实际部署范围。
3. 通过资源卡片「授权给助理」授予外部存储读写、计算执行或网络使用权限，并可查看、修改和撤销已有授权；也可继续在助理权限页管理。连接远程电脑不会自动授予任何资源权限，也不会创建助理工作区。
4. 助理默认在本地工作。远程文件和 Shell 调用必须显式传 `sandbox_id`，并使用该节点的资源；省略节点但引用远程资源会被拒绝。远端不存在助理 `/work`，也不发现远端 AGENTS.md、skills 或记忆。

页面分别显示连接、存储和计算状态；连接成功不代表计算隔离就绪。「重新检查」刷新实际能力，离线时保留连接时的配置快照。沙盒菜单中「重命名」只更改显示名称，无需再次输入连接码；「更新连接凭证」和「断开沙盒」独立处理。桌面端使用沙盒列表，手机端使用选择框；当前沙盒和分区会在同一浏览器标签内记忆。

沙盒状态、能力和资源详情默认缓存 5 分钟，页面显示检查时间。“重新检查”会立即获取并更新状态与详情；编辑连接或资源后，当前页面也会重新检查。助理、授权和资源列表仍实时读取，实际执行时的权限及隔离检查不使用页面缓存。

管理员配置的远程 Sandbox 服务默认允许私网与回环 IP，无需设置 `network.allowed_private_ips` 或重启 Runtime。连接仍验证 TLS 公钥指纹和连接凭证，并绑定配置的协议、主机和端口。禁止自动重定向，拨号时逐个校验 DNS 解析地址，云元数据与链路本地等禁止地址仍被拦截。Sandbox 的网络资源描述的是执行机器所处的网络，其中回环地址指该执行机器。
