# Molr 文档

按你当前要完成的事情选择指南。同一个人可以先部署服务，再以普通用户身份使用助理。

| 入口 | 适合的任务 |
| --- | --- |
| [使用指南](https://molr.ai/zh/docs/user/) | 登录、聊天、安排计划、管理助理权限与个人设置 |
| [管理员指南](https://molr.ai/zh/docs/admin/) | 安装服务、接入模型与沙盒、管理成员、更新与备份 |
| [开发文档](https://molr.ai/zh/docs/dev/) | 参与贡献、理解实现、查阅接口与维护发行 |

已有服务和账号时，从[用户快速开始](https://molr.ai/zh/docs/user/getting-started/)完成第一次委托；自行部署时，从[搭建 Molr 实例](https://molr.ai/zh/docs/admin/getting-started/)开始。
