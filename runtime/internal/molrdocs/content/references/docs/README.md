# Molr 产品文档

Molr 是可自托管的个人 AI 助理。连接自己选择的模型，通过聊天交代事情，在计划中查看安排与结果。

## 开始使用

- [快速开始](https://molr.ai/zh/docs/getting-started/)：安装、登录并完成第一次委托；已有账号可从登录开始。
- [基本概念](https://molr.ai/zh/docs/concepts/)：助理、计划、记忆、资源，以及服务和数据的边界。

## 日常使用

- [助理与聊天](https://molr.ai/zh/docs/guides/assistants-and-chat/)、[计划与执行](https://molr.ai/zh/docs/guides/plans/)：交代任务、安排时间、查看结果。
- [记忆与自动整理](https://molr.ai/zh/docs/guides/memory/)：查看、编辑、确认或遗忘记忆。
- [权限与预算](https://molr.ai/zh/docs/guides/permissions-and-budget/)：批准资源范围、设置额度、撤销授权。
- [文件与命令](https://molr.ai/zh/docs/guides/files-and-commands/)：工作区、后台任务、终端和临时服务。
- [插件与 Skills](https://molr.ai/zh/docs/guides/plugins-and-skills/)：使用已安装的插件和技能扩展。
- [个人设置](https://molr.ai/zh/docs/guides/settings/)、[账号安全](https://molr.ai/zh/docs/guides/account-security/)：外观、提醒、密码与登录设备。

## 连接模型

- [连接与管理模型](https://molr.ai/zh/docs/models/)：连接模型提供商，配置模型能力、价格与凭证。

## 连接聊天入口

- [微信聊天入口](https://molr.ai/zh/docs/chat-channels/weixin/)：连接微信与助理聊天，管理连接状态与解绑。

## 沙盒

- [管理沙盒资源](https://molr.ai/zh/docs/sandbox/resources/)：连接执行机器，添加存储、计算和网络资源。
- [Linux 沙盒部署](https://molr.ai/zh/docs/sandbox/linux/)：准备本机依赖，配置隔离、GPU 与网络范围。
- [独立 Linux Sandbox 服务](https://molr.ai/zh/docs/sandbox/remote/)：部署远程执行节点并接入 Molr。

## 最佳实践

从[最佳实践概览](https://molr.ai/zh/docs/best-practices/)准备工具与授权，再按场景阅读[操作浏览器](https://molr.ai/zh/docs/best-practices/browser/)、[操作钉钉](https://molr.ai/zh/docs/best-practices/dingtalk/)、[操作飞书](https://molr.ai/zh/docs/best-practices/feishu/)、[操作 ClawEmail](https://molr.ai/zh/docs/best-practices/clawemail/)、[操作知乎](https://molr.ai/zh/docs/best-practices/zhihu/)、[操作 GitHub](https://molr.ai/zh/docs/best-practices/github/)和[操作 Google 服务](https://molr.ai/zh/docs/best-practices/google/)。

## 管理实例

管理员通过[用户与用户组](https://molr.ai/zh/docs/administration/users-and-groups/)管理成员并分配可用资源范围。插件安装、启用和共享连接见[插件管理](https://molr.ai/zh/docs/administration/plugins/)。

## 部署与维护

[部署入口](https://molr.ai/zh/docs/deployment/)按安装方式和运行环境选择步骤，涵盖服务安装、访问配置、Linux 沙盒、远程节点、更新与备份恢复。

遇到连接、权限、预算或执行问题时，从[故障排查](https://molr.ai/zh/docs/troubleshooting/)按页面现象定位。

## 参与开发

实现机制、接口契约与贡献流程见[开发文档](https://molr.ai/zh/dev-docs/)。
