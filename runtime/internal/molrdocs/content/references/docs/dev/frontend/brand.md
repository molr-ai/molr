# Molr 品牌与 UI 基础

品牌名称为 **Molr**，官网域名 `molr.ai`。

## 视觉方向

**理性的结构，有温度的表达。**

采用轻量研究工具的气质：浅色背景、深绿文字、大量留白、适度圆角，以底色区分层级，仅在必要的分隔、次要按钮和输入控件上保留柔和细边框。青柠绿只强调重要节点。界面以内容和清楚的操作层级为核心。

## 品牌色

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| Forest · 深苔绿 | `#263B31` | 品牌主色、标题、正文、主按钮 |
| Lime · 青柠绿 | `#D5F478` | 品牌强调、选中的视觉节点、重点入口 |
| Canvas · 暖雾白 | `#F5F6EF` | 页面背景 |
| White · 纯白 | `#FFFFFF` | 内容容器、输入框 |
| Sage · 灰绿 | `#657368` | 次级文字 |
| Mist · 雾灰绿 | `#DCE1D6` | 弱边框、必要的分隔线 |

建议浅色背景、深绿和青柠绿的视觉占比约为 **80 / 15 / 5**。青柠底使用深绿文字。输入控件与 Select 的默认边框使用 `#DCE1D6`，悬停轻微加深为 `#C5CDC1`，聚焦时使用焦点语义色沿边框向内加粗，错误状态优先使用错误色。

默认配对的计算对比度：深绿 / 暖白 **11.02:1**，灰绿 / 暖白 **4.59:1**，深绿 / 青柠 **9.72:1**。新增配对时重新检查。

成功、警告、错误分别使用独立的绿、琥珀、红色语义变量，并始终搭配文字。品牌强调色不代替状态信息。

## 明暗主题

界面默认跟随系统，可在导航右侧手动选择浅色或暗色，并保存选择。根元素的 `data-theme` 使用 `light` 或 `dark`，共享组件通过语义变量适配。暗色以深苔绿底、暖白文字与青柠强调延续品牌气质：

| 语义角色 | 浅色 | 暗色 |
| --- | --- | --- |
| 页面背景 | `#F5F6EF` | `#131C17` |
| 卡片与输入表面 | `#FFFFFF` | `#1C2922` |
| 正文 | `#263B31` | `#F5F6EF` |
| 辅助文字 | `#657368` | `#A8B6AA` |
| 区块分隔线 | `#DCE1D6` | `#35493C` |
| 控件边框 | `#DCE1D6` | `#35493C` |
| 控件悬停边框 | `#C5CDC1` | `#49604F` |

暗色正文与页面背景的计算对比度为 **16.01:1**，辅助文字与卡片表面为 **7.15:1**。弱边框只辅助识别控件，聚焦状态另用清晰的焦点色。状态标签使用各自的深色底和浅色文字，危险按钮仍使用深红底与白字。

品牌色卡展示原始色值。青柠主视觉使用深绿文字；浅色、深色 Logo 样例保留各自背景。导航与页脚在暗色主题中使用反白字标和青柠猫眼。外观主题独立于 Logo 的昼夜动作时段，动画交互不显示文字提示。

## Logo

**Molr 猫意字标已定稿为轻笔画、紧凑、微外张版。** 四个字母暗示猫的姿态：**M** 两端的高点带出竖耳，中央圆润过渡，两侧直线的下端各向外移 1.25 个设计单位，形成约 2.5° 的对称外张；内部两枚圆点暗示猫眼。`o` 保留原有略偏竖向的贝塞尔曲线，路径等比缩小为 5/6，不改为正圆或横向压扁。`l` 末端轻弯，`r` 从竖笔顺滑转入上翘的末笔，尾尖与 M、l 顶部对齐。

字标统一使用 7 个设计单位的圆角线条。M 上端位于 (10, 12)、(52, 12)，下端位于 (8.75, 41)、(53.25, 41)。双眼直径同为 8，中心位于 (23, 36) 与 (39, 36)，左右对称地落在 M 内部。四个字母共用基线，r 为一条连续笔画。静态、动画的静止姿态、独立 M 和应用图标共用同一份几何。

浅色背景使用深苔绿字形与猫眼 `#263B31`；深色背景使用暖白字形 `#F5F6EF`，猫眼使用品牌青柠绿 `#D5F478`。应用图标采用青柠底、深苔绿 M 与猫眼。

完整字标用于网站导航、页脚和品牌展示；独立 **猫耳 M** 用于应用图标、头像和 favicon。主字标前不再叠加独立 M，避免重复。

资源位于共享 UI 包的 [`public/brand`](https://github.com/molr-ai/molr/blob/main/packages/ui/public/brand)。字标与独立 M 均提供静态版、12 种独立动画和两套组合表演，各覆盖浅色、暗色两套配色：

| 资源 | 用途 |
| --- | --- |
| `molr-wordmark.svg` / `molr-wordmark-light.svg` | 浅色 / 深色背景用完整字标 |
| `molr-mark.svg` / `molr-mark-light.svg` | 浅色 / 深色背景用独立 M |
| `molr-icon.svg` | 青柠底应用图标和 favicon（仅静态） |

动画资源在上述字标 / 独立 M 的文件名末尾添加动画后缀，例如 `molr-wordmark-curious.svg`、`molr-mark-light-sleepy.svg`。

`Logo` 的默认 `/brand` 与内置 `/brand/themes/<palette>` 配色使用随前端代码打包的 SVG；页面加载完成后，首次重连 loading、恢复招呼、重播及日夜切换均无需请求服务端。图片使用 data URL，交互动画使用可访问 SVG 时钟的同源 Blob URL，并在卸载或重播时释放。`ConnectionLogo` 在动画加载成功前保留静态图。自定义资源目录仍使用原地址，加载失败后回退到内置静态图。

`npm run brand:generate` 同时更新下载用 SVG 与 `packages/ui/src/logo-assets.json`，修改图形时须一并提交；不要手工修改打包副本。

| 动画 | 后缀 / `animation` | 节奏与动作 | 适用场景 |
| --- | --- | --- | --- |
| 眨眼 | `blink` | 每 4 秒轻眨一次，约 200 ms | 头像、品牌展示 |
| 休闲 | `idle` | 2.8 秒循环；猫耳内收、舒展，尾梢同步轻弯 | 空闲界面 |
| 好奇 | `curious` | 1.8 秒，播放一次后归位；单耳轻抬，头部连同双眼微微倾斜 | 悬停、键盘聚焦时回应 |
| 打盹 | `sleepy` | 24 秒，播放一次；双眼缓缓眯成弧线，耳尖和尾梢放松，眯眼保持 20.4 秒再睁眼 | 长时间无操作 |
| 招呼 | `greet` | 2.4 秒，播放一次后归位；点头、眨眼，尾梢摆动两下；独立 M 保留点头和眨眼 | 首次进入、欢迎 |
| 加载 | `loading` | o 的环形描边每 1.6 秒匀速一圈；猫耳以 3.2 秒为周期轻柔舒展，尾梢稍后跟随，双眼与 l 保持稳定。独立 M 用随轮廓形变的描边表示加载 | 正在处理、等待结果 |
| 张望 | `look` | 3.6 秒，双眼一起望向两侧，头部轻轻跟随，再看回前方 | 观察周围 |
| 侧耳听 | `listen` | 2 秒，单耳竖起并轻动，短暂停留再回正 | 注意到声音或变化 |
| 伸懒腰 | `stretch` | 3.2 秒，先收身再舒展，字形轻伸展，尾梢稍后跟随 | 从休息转为活跃 |
| 轻蹭 | `nuzzle` | 2.6 秒，眯眼向一侧轻靠，尾梢收拢后归位 | 亲近、回应 |
| 抖耳 | `earflick` | 1.6 秒，耳尖先后轻抖，再自然眨眼 | 短暂的小动作 |
| 探头 | `peek` | 2.8 秒，头部微微前探，双眼略睁大，尾尖抬起后收回 | 主动观察、招呼前奏 |

六个新增独立动作均播放一次后归位，可通过 `replayKey` 重播。

组合表演提供两种性格，按固定顺序循环，动作之间停顿 15～30 秒；眨眼和休闲先连续播放 3～5 轮，再进入停顿；打盹只播放一次，延长眯眼停留：

| 预设 | `animation` / SVG 后缀 | 时长 | 播放顺序 |
| --- | --- | --- | --- |
| 安静好奇 | `alive` | 299.6 秒 | 招呼 → 张望 → 打盹 → 侧耳听 → 好奇 → 休闲 × 5 → 伸懒腰 → 轻蹭 → 眨眼 × 4；段间停顿 20～30 秒 |
| 亲近俏皮 | `playful` | 200.4 秒 | 招呼 → 探头 → 抖耳 → 眨眼 × 3 → 轻蹭 → 张望 → 招呼 → 伸懒腰 → 好奇；段间停顿 15～25 秒 |

`animation="daily"` 按设备本地时间轮换：08:00（含）至 20:00（不含）播放安静好奇，20:00 至次日 08:00 播放亲近俏皮。页面在 08:00、20:00 自动切换，后台恢复时核对时段；夜间跨过午夜不重启。也可以手动选择任一套。组合 SVG 内置完整时间轴，下载后可独立循环；昼夜轮换由组件选择当前文件，因此没有单独的 `daily.svg`。

组合 Logo 可设置 `interactive`：等待间隔中点击 Logo，或聚焦后按 Enter / 空格，立即进入下一阶段；末段等待跳到下一轮开头。播放中的动作和连续轮次保持完整，重复点击不会跳过。动画不显示状态文字或悬停提示，保留读屏标签，鼠标、触摸与键盘均可操作；减少动态效果时显示静态标识。

播放顺序、单轮时长 `duration`、连续轮数 `cycles` 与段后停顿 `pause` 由 [`logo-choreography.json`](https://github.com/molr-ai/molr/blob/main/packages/ui/src/logo-choreography.json) 维护，修改后运行生成命令。`cycles` 默认 1，只有眨眼、休闲可设置为多轮，停顿只发生在该动作全部轮次完成后。各轮在静止姿态衔接，眼睛随头部整体移动，保持小尺寸下的字形辨识度。加载保留给实际的处理状态，日常表演使用表情动作。

所有动画均封装在 SVG 内，直接通过 `<img>` 使用。轮廓形变使用 SVG 原生路径插值，无需 JavaScript；交互组件使用同源 SVG 的实际时钟跳过等待。系统开启减少动态效果时显示原始静态轮廓。M 中央弧线的控制点按相邻耳线方向计算，r 尾部曲线的起始切线保持水平；静态和各动画姿态共用 `logo-contours.mjs`，使关键帧及插值过程的线段衔接保持相切。`packages/ui/tests/logo-contours.test.mjs` 检查导出与内置资源的衔接和一致性。

好奇与招呼由调用方在相应交互发生时触发；递增 `Logo` 的 `replayKey` 可以重新播放。预览页提供「重播」按钮，点击动画选项或切换图形也会从头播放。加载动画表示不确定进度，实际使用时搭配可读状态文字。

配色可自定义。生成脚本内置两套预设：浅色预设的笔画与猫眼同为深苔绿，暗色预设翻转为暖白笔画配青柠绿猫眼。用环境变量覆盖任一品牌色即可重新导出整套矩阵，只传部分参数时其余沿用品牌默认值：

```bash
MOLR_INK='#1b2a22' MOLR_ACCENT='#c8f25d' npm run brand:generate
# 或直接调用脚本
node packages/ui/scripts/generate-logos.mjs --ink '#1b2a22'
```

自定义配色后按品牌色一节的配对规则重新核对对比度。

字标由矢量路径组成，不依赖使用者安装字体。字标周围保留至少半个 M 宽度的净空，猫意完整字标建议不小于 96 px 宽；独立图标建议不小于 24 px；favicon 使用专用图标资源。更小的展示空间优先采用独立 M。

M / l / 尾尖的可见顶线为 y = 8.5，公共底线为 y = 44.5；字标画布为 183 × 54，独立图形为 64 × 64，应用图标为 80 × 80。定稿几何与配色由 [`generate-logos.mjs`](https://github.com/molr-ai/molr/blob/main/packages/ui/scripts/generate-logos.mjs) 维护，在仓库根目录运行 `npm run brand:generate` 导出 62 个 SVG 与 20 个 PNG 应用图标资源。

独立的 [UI Design 应用](https://github.com/molr-ai/molr/blob/main/apps/ui-design/README.md) 在 `#identity` 展示浅色背景、深色背景与应用图标用法，支持昼夜轮换、点击跳过等待、手动选预设、逐一观看独立动作，以及完整字标 / 独立 M，下载对应预览的 SVG。

## 字体与形状

- 英文：**DM Sans**，由项目本地加载。中文：系统无衬线字体，优先苹方、微软雅黑。
- 基础字号：标题 32 px、正文 16 px、控件 14 px、辅助 12 px。
- 间距：4 px 为基准，常用 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64。
- 圆角：控件 8 px，卡片 16 px，标签使用胶囊形。
- 层次：优先使用留白、表面颜色和细边框。动效以约 160 ms 的状态过渡为主，尊重减少动态效果的系统设置。

| 组件 | 约定 |
| --- | --- |
| `Button` | 主操作、强调、次要、文字、危险五种变体；32 / 40 / 48 px 三档高度；支持禁用 |
| `TextField` | 始终显示标签，支持说明、错误和禁用状态 |

| `Textarea` / `SearchField` | 多行输入与可清除搜索；沿用输入框标签、边框与错误语义 |
| `Tabs` / `Breadcrumb` / `Pagination` | 内容分类、当前位置和分页；保留键盘操作与窄屏适配 |
| `Dialog` / `Drawer` | 模态编辑与侧边详情；抽屉采用贴边直角、从右侧滑入滑出，退出结束后恢复焦点 |
| `DropdownMenu` / `Popover` / `Tooltip` | 动作菜单、可交互详情与补充说明；沿用统一弹层视觉 |
| `Alert` / Toast | 页面内消息与角落通知；提供重试、关闭或撤销操作，状态通过文字与颜色共同表达 |
| `EmptyState` / `Skeleton` / `Progress` | 解释空白、表示等待和呈现实际进度；减少动态效果时保留静态信息 |
| `Table` | 语义化表格、受控排序、多选、加载和空状态；窄屏在表格区域内滚动 |

| 聊天组（英文版为 Chat）件 | 气泡无边框且只放文本，头像在气泡外侧且可独立开关，图片、附件和卡片独立展示；输入框 8 px 圆角、自适应高度，仅外框显示焦点；消息信息收进图标，赞／踩置于气泡下方；行动、思考、输入中等使用独立的助理状态组件 |
| `Logo` | 深色、浅色、仅图形；默认静态，支持全部独立动作、`alive` / `playful` 组合与 `daily` 昼夜轮换；递增 `replayKey` 重播，`interactive` 启用等待时点击继续 |

标签页与成组选项只保留两种视觉：**下划线简约版**和**带底色分段控件**。下划线用于内容分类与页内导航，背景透明，选中项使用 2 px 下划线。分段控件用于模式、预设与紧凑筛选，统一使用中性底色、表面色选中项与轻阴影，外圆角 8 px、内圆角 4 px，内边距和项间距均为 4 px。两种样式共用 14 px 字号、禁用与焦点状态；触屏和窄屏保证单项至少 44 px 高。组件分类、平台切换、Logo 动画选择与日程视图均复用共享样式。

实现位于 [`packages/ui/src/components`](https://github.com/molr-ai/molr/blob/main/packages/ui/src/components)，可复用变量位于 [`packages/ui/src/tokens.css`](https://github.com/molr-ai/molr/blob/main/packages/ui/src/tokens.css)。应用通过 `@molr/ui` 和 `@molr/ui/styles.css` 使用组件与样式。浅色主题聚焦状态使用深绿描边，暗色主题使用青柠描边，所有交互元素保留可见的键盘焦点。

组件的完整接口与使用方式见 [组件库文档](https://github.com/molr-ai/molr/blob/main/packages/ui/COMPONENTS.md)。`UIProvider` 统一提供中英文内置标签，展示页中的输入、导航、反馈、弹层和数据示例共用这些组件。

下拉触发器沿用输入框的 8 px 圆角与控件边框，高度为 40 / 44 px。弹层使用主题表面色、12 px 圆角、细边框和轻阴影；选项以淡色底与勾选标记表达当前值，以描边区分活动项，禁用项降低强调度。导航主题切换和表单选择共用同一组件，菜单在窄屏和容器边缘自动调整位置。

这一版确定品牌和通用界面的基础。首页展示的是样式参考；输入验证、色值复制、开关和资源下载均可操作，尚未定义产品业务流程。

### 助理消息输入与消息容器

消息输入容器沿用 `--radius-control`（8 px），消息内容和下挂卡片沿用 `--radius-card`（16 px）。两者用途不同，可使用不同圆角，但同类表面不自行定义其他数值。组合输入器内的 textarea 不单独绘制圆角、边框或焦点描边，外层容器通过 `:focus-within` 改变边框颜色提供焦点提示。

输入区初始一行，随内容增长，达到 180 px 后内部滚动。可见标签由 placeholder 替代，同时保留读屏名称。工具栏左侧为附件，右侧为模型、语音和发送。Enter 发送、Shift+Enter 换行，输入法组合状态下 Enter 不发送。

消息支持正文、图片、附件、静态卡片及反馈。助理和用户消息均使用无边框的 16 px 圆角文本气泡，通过表面色与对齐区分角色；图片、附件和卡片独立于气泡展示；任务操作由聊天 header 入口进入抽屉，消息中不放下挂操作按钮。性能信息收进消息下方的信息图标弹层，默认不在消息流铺开；未读数量使用红底白字徽标。性能信息以可获取的实际测量为准；未接入真实模型时展示“—”，不能用模拟数值伪装真实性能。

## 文档适用范围

本文件维护视觉变量、Logo 和组件规范，具体产品布局由应用负责。官网／UI Design 的外观偏好可保存在浏览器；真实 WebUI 的主题设置由 Runtime 账号保存。输入器支持的模型、语音等扩展槽位不代表每个产品页面都已启用，真实聊天能力以 [产品指南](https://molr.ai/zh/docs/user/guides/assistants-and-chat/) 为准。
