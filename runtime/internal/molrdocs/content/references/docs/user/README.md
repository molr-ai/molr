# Molr 使用指南

本指南面向使用已有 Molr 服务的成员。准备服务地址和账号，连接已分配的资源，管理自己的助理与任务。自行部署或管理成员请阅读[管理员指南](https://molr.ai/zh/docs/admin/)。

## 开始使用

- [快速开始](https://molr.ai/zh/docs/user/getting-started/)：登录、选择可用模型、聘请助理并完成第一次委托。
- [基本概念](https://molr.ai/zh/docs/user/concepts/)：助理、计划、记忆、资源与数据边界。

## 日常使用

- [助理与聊天](https://molr.ai/zh/docs/user/guides/assistants-and-chat/)、[计划与执行](https://molr.ai/zh/docs/user/guides/plans/)：交代任务、安排时间、查看结果。
- [TUI 使用指南](https://molr.ai/zh/docs/user/guides/tui/)：在终端连接服务、聊天、切换助理与处理授权申请。
- [记忆与自动整理](https://molr.ai/zh/docs/user/guides/memory/)：查看、编辑、确认或遗忘记忆。
- [权限与预算](https://molr.ai/zh/docs/user/guides/permissions-and-budget/)：为自己的助理授权资源、设置额度和撤销授权。
- [文件与命令](https://molr.ai/zh/docs/user/guides/files-and-commands/)：工作区、后台任务、终端和临时服务。
- [插件与 Skills](https://molr.ai/zh/docs/user/guides/plugins-and-skills/)：使用已分配插件，在助理工作区安装 CLI 与 Skill。
- [个人设置](https://molr.ai/zh/docs/user/guides/settings/)、[账号安全](https://molr.ai/zh/docs/user/guides/account-security/)：外观、提醒、用量、数据导出、密码与登录设备。

## 聊天入口与实践

[微信](https://molr.ai/zh/docs/user/chat-channels/weixin/)、[飞书聊天入口](https://molr.ai/zh/docs/user/chat-channels/feishu/)和[Telegram 聊天入口](https://molr.ai/zh/docs/user/chat-channels/telegram/)和 [Slack 聊天入口](https://molr.ai/zh/docs/user/chat-channels/slack/)介绍绑定、消息收发和解绑。按任务查阅[最佳实践](https://molr.ai/zh/docs/user/best-practices/)，使用浏览器、钉钉、飞书、邮箱、知乎、GitHub 或 Google 服务。

## 遇到问题

从[使用问题排查](https://molr.ai/zh/docs/user/troubleshooting/)检查连接、权限、预算与执行状态。需要新增资源或修改服务器配置时，联系管理员并提供错误信息和版本。

钉钉机器人单聊的连接、配对与解绑见[钉钉聊天入口](https://molr.ai/zh/docs/user/chat-channels/dingtalk/)。

[QQ 聊天入口](https://molr.ai/zh/docs/user/chat-channels/qq/)支持扫码或手动凭据连接。
