# 微信聊天入口

助理创建后默认在 WebUI 聊天。打开聊天页右上角「… → 切换聊天入口」，在抽屉列表中选择微信，再点击「连接微信」，使用微信扫码并确认；如果微信要求配对验证码，在页面中输入验证码。

扫码页面会提示：通过微信渠道收发的聊天消息和附件会被发送给腾讯，腾讯可能保留这些数据。请注意数据隐私。

只有扫码确认并成功保存绑定后才切换入口。连接失败、取消或二维码过期不会影响原有 WebUI 聊天。当前助理已连接时会提示无需重复扫码；微信返回已绑定时，需要核对当前助理的本地绑定和凭据，不会自动接管其他助理的连接。

## 连接后的使用

- 在微信中发送消息并接收助理回复；先发一条文字消息以建立回复上下文。
- WebUI 展示同一份聊天记录，保留任务、文件、配置和权限审批，不再提供聊天输入。服务器同时拒绝该会话的普通发消息 API 请求。
- 绑定前的记录和助理上下文保留，旧记录不会补发到微信。
- 每个微信身份在一个 Molr 实例中只能绑定一位助理；克隆助理不会复制微信绑定。助理解雇后暂停收发，返聘后恢复。
- 支持文字、图片和文件双向收发。微信图片和文件会保存到同一会话的附件中；视频可作为附件接收。微信提供转写的语音按转写文字处理，没有转写的语音会作为音频附件接收，支持的 SILK 语音会自动转成 WAV；理解语音需要启用支持音频的模型，转换失败时保留原始音频。
- 助理明确发布到聊天中的图片以图片消息发送，其他附件以文件消息发送；不会自动上传工作区里的其他文件。单个附件受 Runtime 上传上限和存储配额限制，渠道上限不超过 100 MiB。收到文件不代表模型已经读取，理解图片和文件还取决于所选模型及文件格式。
- 支持微信引用回复，包括文字、局部文字及附件。只带消息 ID 的引用依靠本地缓存还原；未缓存、已过期或附件已删除时会明确说明，不能自动恢复接入前的微信历史。
- 微信不展示 Molr 交互卡片。连接期间模型会收到渠道提示，优先使用文字；必要的卡片转换成标题、摘要和 Molr 链接。审批仍在 Molr 完成。

## 连接状态与投递

网络中断时自动重连，失败后的等待从 5 秒起逐次翻倍，最长 640 秒；恢复成功后重置等待间隔。「需要重新扫码」时，在「聊天入口」弹窗中重新连接；此期间聊天入口仍为微信。定时或后台回复可能因微信回复凭据过期而失败，不能保证长期无人交互后的主动提醒。

发送成功时聊天页不展示投递提示。等待微信新消息、发送受限、附件失败、平台拒绝或发送结果未知等异常仍会展示。「结果未知」不代表发送失败；已经在微信收到时可以忽略，这类消息不会自动重发。投递异常在当前聊天中展示，多条提醒逐条关闭、依次查看。右上角关闭会在服务端保存“已忽略”，刷新、重新登录和换设备都不会再次主动提醒同一异常。历史消息仍在聊天记录中查看。新的异常状态或新消息投递异常会生成新的通知。关闭不会重发、取消或修改投递结果。等待回复上下文时，可在微信发一条新消息。接口成功不表示用户已读。限流提示只显示一条，可关闭；等待服务端指定的间隔后再重试。

附件上传遇到临时网络或服务端错误时最多尝试三次；这仅重试上传步骤，不会重复发送已提交给微信的消息。

每次公开回复的文字分段和各个附件独立记录投递，不会因为发送失败重新执行助理任务。长文本拆成多条微信消息。微信内既有普通好友聊天和群聊不在接入范围内。

已绑定时，聊天页底部的消息输入框以锁定样式保留轮廓，显示微信发送与解绑恢复输入的说明；点击框内「管理微信连接」可直接打开同一弹窗。需要重新扫码等异常连接状态在弹窗中以提示块展示。自动重连和需要重新扫码时，聊天顶部都会通过系统提醒提示，点击「查看详情」可打开连接管理。自动重连提醒不会要求重新扫码；关闭提醒不停止后台重试，同一次中断不会反复提醒，恢复连接或解绑后自动解除。

## 解绑

在「聊天入口」弹窗中点击「解绑微信」并确认，恢复 WebUI 聊天。历史和助理上下文保留，待发送的微信回复取消；已经被平台接受的消息无法撤回。本地解绑停止 Molr 使用绑定凭据，不代表撤销微信服务端的所有授权。


连接与访问地址由管理员配置，见[微信连接配置](https://molr.ai/zh/docs/admin/deployment/configuration/#微信连接配置)。
