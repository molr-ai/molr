# Telegram 聊天入口

在聊天页「… → 切换聊天入口」中选择「连接 Telegram」。每位助理使用一个专属机器人，只接受绑定用户的私聊；同一助理只能选择一个外部聊天入口。已经连接微信时，先解绑微信。

## 连接

1. 在 Telegram 中打开 [@BotFather](https://t.me/BotFather)，使用 `/newbot` 创建机器人并取得 Bot Token。
2. 在 Molr 的连接页面填写 Bot Token，点击「验证并继续」。Token 由 Runtime 加密保存，不会返回给页面或进入模型上下文。
3. 点击「打开 Telegram」或扫描页面二维码，在机器人聊天中点击 Start。
4. 返回 Molr，核对显示的 Telegram 用户名和用户 ID，点击「确认绑定」。绑定链接五分钟内有效；取消、过期或 Runtime 重启后重新发起。

确认前仍可使用 WebUI 聊天，确认后保留聊天历史与助理上下文，聊天输入切换到 Telegram。此入口的消息和附件会经过 Telegram；绑定前的 Molr 记录不会补发。不要将 Bot Token 发到聊天记录中。

若机器人已被另一助理绑定，或已配置其他服务的 Webhook，连接会被拒绝。使用专属机器人，避免两个服务争抢消息。部署要求见[Telegram 连接配置](https://molr.ai/zh/docs/admin/deployment/configuration/#telegram-连接配置)。

## 使用

支持文字、图片和文件双向传输，长回复会拆成多条消息。图片和文件保存到当前会话，文件是否能被理解取决于模型及文件工具；附件接收失败会明确标注内容未读取。每张相册图片作为独立入站消息处理。群聊、私聊 Topics、历史同步、消息编辑同步和个人账号代管不在当前范围内。

普通文件发送上限为 50 MB，接收上限为 20 MB，同时受 Runtime 上传上限和存储配额约束。符合发送条件的 JPEG/PNG 以图片发送，其他附件以文件发送。语音和视频可以保存为附件，当前没有专门的语音转写流程。

后台任务发布的新回复也会投递到 Telegram。任务和权限卡片转换为标题、摘要及需要登录的 Molr 链接；审批仍在 Molr 完成。手机必须能访问该 Molr 地址。

## 状态与解绑

网络中断时自动重连，等待间隔从五秒逐次翻倍到最多 640 秒。Telegram 未领取的更新最多保留 24 小时，长时间离线可能丢失消息。助理解雇或账号停用期间暂停收发；返聘后恢复。克隆助理不会复制绑定。

机器人被屏蔽时，在 Telegram 解除屏蔽并发送新消息。Token 无效或其他服务占用机器人时，按提示处理后解绑重连。限流按平台返回的等待时间重试，最多五次；平台未明确确认的发送标记为结果未知，不自动重发。成功表示平台接受，不表示已读。

在「管理 Telegram 连接」中解绑，可恢复 WebUI 输入。历史与上下文保留，待投递回复取消；平台已经接受的消息无法撤回。本地解绑不撤销 Token，需要撤销时到 @BotFather 操作。
