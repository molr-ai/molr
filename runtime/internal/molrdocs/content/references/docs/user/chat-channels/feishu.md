# 飞书聊天入口

在助理聊天页打开「更多 → 切换聊天入口」，选择「连接飞书」。使用飞书扫描二维码，在授权页面确认创建应用及私聊消息权限。连接建立后，在飞书中找到应用机器人并发送文字。

每个机器人应用只绑定一位 Molr 助理，且只接收绑定用户的私聊。连接后通过飞书发送消息；WebUI 保留聊天记录、任务、文件和权限管理。已有历史不会补发，助理上下文保留。同一助理只能绑定一个聊天渠道。

## 使用已有应用

选择「使用已有应用」，输入 App ID、App Secret 和你在该应用下的 Open ID。应用必须是飞书自建应用并启用机器人能力，开通 `im:message.p2p_msg:readonly`、`im:message:send_as_bot`，订阅 `im.message.receive_v1`。

提交连接后，在飞书开发者后台选择使用长连接接收事件并保存，发布应用版本，确保自己位于应用可用范围内。设置长连接时需要 Molr 客户端已经在线。应用凭据由 Runtime 加密保存；普通状态查询不返回 App Secret。

Runtime 需要能够访问飞书公网服务，无需公网入站地址。不要在另一个实例中同时使用相同应用连接，否则消息可能被分发给另一个实例。扫码方式目前只支持飞书租户，不支持 Lark 国际版；是否能创建应用取决于租户管理策略。

## 消息与状态

当前支持文字及富文本中的文字。图片、文件、语音和其他入站类型会标注为未读取；请改发文字描述。助理发布的附件和卡片会提供 Molr 链接，需要在 Molr 登录后查看或处理。群聊和交互卡片暂不支持。

聊天内容会传输至飞书。连接中断会自动重连并显示提醒；暂停助理时停止收发，恢复助理后继续。消息发送异常显示通知，未知结果和限流会在有限次数及去重时间窗口内重试。超出限制后停止自动重试，需要在飞书核对是否收到。

## 解绑

打开聊天入口设置并选择「解绑飞书」。解绑恢复 WebUI 输入，保留历史与上下文，取消未发送回复。飞书已经接受的消息不能撤回。解绑不会删除飞书应用，可在飞书开发者后台自行管理。

助理操作日历、文档等资源的授权见[操作飞书](https://molr.ai/zh/docs/user/best-practices/feishu/)，与聊天入口分别配置。
