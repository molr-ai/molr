# 账号安全

从「用户设置 → 安全」管理登录验证、设备和一次性登录链接。

## 登录与设备

登录页优先使用浏览器 Cookie 中保存的语言偏好；没有保存时跟随浏览器语言，中文使用简体中文，其余语言使用英文。登录后使用账号语言设置，并同步保存到当前浏览器；退出后保留该偏好。登录页不提供单独的语言切换或初始化账号说明。

登录按钮上方的“保持登录状态”默认勾选，使用可在浏览器重启后保留的登录 Cookie；取消勾选时使用会话 Cookie，清除时机由浏览器的会话结束和恢复设置决定。二次验证沿用登录时的选择。默认连续 7 天没有认证请求或距离本次登录已满 30 天，会话失效；退出、改密或撤销会话也会使其提前失效。部署者可通过 `auth.session_idle` 和 `auth.session_lifetime` 调整时限。

登录被限流时，若服务器提供等待时间，提示会按小时、分钟、秒倒计时：不足一小时不显示小时，不足一分钟只显示秒。没有可靠的等待时间时显示通用重试提示；等待结束后需要手动重试。

安全设置支持修改密码、二次验证、恢复码、登录设备和一次性登录链接。登录设备只展示仍有效的会话，当前设备置顶，名称采用“Chrome / Windows · Web”等格式，并显示最近登录和访问时间。可退出单个设备或退出其他所有设备；不会自动取消后台任务。安全页底部的「退出登录」仅退出当前设备，其他设备保持登录。

同一浏览器在同一服务地址重复登录会更新原设备会话，普通退出后再登录仍识别为同一设备。不同浏览器、服务地址和客户端各自独立；清除站点数据后会识别为新设备。设备会话失效后立即从列表隐藏，保留 7 天后自动清理。

一次性链接可选择 15 分钟、1 小时或 24 小时有效期，仅显示完整链接一次；已用、过期或撤销后不能继续兑换。启用二次验证时仍要求验证码。需要新的链接时，从已登录设备重新生成。默认展示可用及等待二次验证的链接，已使用、撤销或过期的记录收在“近期记录”中，链接到期 7 天后自动清理。

“敏感操作验证”默认关闭，开启后保存／更换凭证及数据导出需要再次验证；修改密码与安全设置始终要求身份确认。账户无法登录时，由部署者按 [本机恢复流程](https://molr.ai/zh/docs/admin/deployment/maintenance/#备份恢复与升级) 处理。
