# 个人设置

桌面点击侧边栏底部头像，手机点击助理页顶部头像和用户名，进入用户设置。管理员通过用户设置页头右上角的「管理员设置」按钮进入管理页面，操作见[管理用户与用户组](https://molr.ai/zh/docs/admin/administration/users-and-groups/)。

## 个人资料与头像

在用户设置 → 个人资料中设置显示名称和头像。可选择预设头像，或上传不超过 10 MB、4000 万像素的 PNG、JPG、WebP 图片；图片会在浏览器内居中裁剪为 256 × 256 的缩略图。点击「保存」后，桌面侧栏和手机顶部显示新头像；清除并保存后恢复名称首字符。头像随账号保存，换设备登录后仍可使用。

## 语言、主题与偏好

常规设置管理语言、时区、币种等偏好。“显示插件”默认关闭，开启后显示插件导航、插件主题及相关管理选项，设置随账号同步；具体范围见[插件](https://molr.ai/zh/docs/user/guides/plugins-and-skills/)。主题页区分界面主题、配色和明暗模式，保存到账号后可在其他设备读取；提供默认、测试两套内置主题，也可选择管理员已安装、授权并启用的[插件主题](https://molr.ai/zh/docs/user/guides/plugins-and-skills/)。主题配色可选森林、海盐蓝、鸢尾紫、暖砂、玫瑰和素墨，均支持浅色与深色显示。素墨使用中性灰阶界面，成功、警告、错误等提示保留语义色。

记忆的查看、编辑和做梦时间见[记忆指南](https://molr.ai/zh/docs/user/guides/memory/)。默认模型与助理模型的选择见[权限与预算](https://molr.ai/zh/docs/user/guides/permissions-and-budget/#选择模型)。

## 用量

用户设置 → 用量默认显示本年统计，可选择本月、近 30／90 天、往年或最多一年的自定义日期范围，并按助理和模型筛选。总览包含输入、输出、缓存输入、总 Token、已确认模型费用、模型调用和活跃天数。总 Token 为输入加输出，缓存输入已包含在输入中；没有取得用量的调用单独标记，不视为零消耗。

每日消耗日历支持 Token／金额切换，热度颜色跟随主题配色和明暗模式。悬停或键盘聚焦时，提示分行显示日期和当前指标的精确数值，未知用量单独注明；方向键移动日期，点击日期查看当天分组明细。桌面按周排列，日期方块保持固定大小，空间不足时显示截至今天（历史范围则截至范围末日）的最近几周；可缩小日期筛选范围查看更早日期。手机按月浏览。明细支持按助理／模型分组，按 Token、费用或调用次数降序排列；点击名称继续筛选，已解雇助理保留历史记录。缺少模型标识的调用保留在总量和“未知模型”明细中，不作为模型筛选项。总览统计完整筛选范围，选择单日只改变明细。

日期按个人时区划分，迟到回执仍归入调用发起日。费用按结算原币种汇总后，以同一汇率快照换算为个人偏好币种，换算金额带 `≈`；零费用调用仍可有 Token 消耗。执行中的调用和未知费用分别列出，不计入已确认费用。「累计用量与额度」默认展开，显示累计用户消息、累计调用、预留费用、附件／上下文存储和当前成员额度，这些数据不受历史日期筛选影响。累计用户消息统计本人在所有聊天会话中发送的消息，包含归档会话，不包含助理回复和内部上下文消息；重试同一次发送和克隆聊天记录不会重复计数，删除聊天记录不会减少累计值。

用量统计会在 Runtime 内存中保留最多 5 分钟。页面显示统计时间；点击“刷新”可立即重新计算并更新缓存，后续普通访问复用结果。实际模型预算和调用额度判断始终使用实时数据。

## 系统提醒

微信投递／连接异常、助理持续受阻、授权请求、计划待交接和任务／后台执行失败由服务端统一管理提醒状态。后台执行失败提醒在开发工作台可用且已设置显示时显示「在开发工作台中查看」，点击定位对应执行；未设置显示时保留提醒和关闭按钮，不显示查看入口。未采集或已过期的执行会明确提示记录不可用。其他提醒直接进入对应的聊天、授权、任务或计划页面；需要长期查阅的内容保留在对应业务页面，不设独立通知历史页。

聊天一次显示一条提醒，并显示剩余数量。当前提醒不会被新到达的提醒打断；关闭成功后按发生顺序显示下一条，关闭失败时保留当前条。关闭状态在设备间同步，刷新不会重新出现同一次提醒；关闭不会重发消息、取消任务或改变业务处理结果。问题恢复后提醒自动消失，新的异常会产生新的提醒。

用户设置的“通知设置”管理当前浏览器或桌面 App 的提醒、预览、声音和桌面通知。关闭主动提醒不影响聊天内的待处理提醒或消息未读计数。可信 HTTPS／本机环境可授权桌面通知；页面关闭后暂不推送，重新打开可在相应聊天查看仍待处理的提醒。桌面通知自动收起和 Toast 自动消失不等于已读或已解决。

打开“桌面通知”开关会按需请求授权，不再单独显示授权按钮。桌面 App 通过系统原生通道发送通知，设置按当前连接和账号保存在本机；关闭开关停止桌面通知，保留应用内提醒和提示音。macOS 的系统授权由系统管理，如未显示通知，请在系统通知设置中允许 Molr，并检查专注模式。App 需保持打开且连接正常。

桌面通知和消息提示音各自在对应设置行内显示状态、测试按钮和结果。“发送测试通知”可在浏览器尚未授权时申请权限；桌面通知关闭或不可用时使用应用内测试提醒。“试听提示音”不改变提示音开关。发送请求成功不代表系统一定展示通知。

## 关于 Molr

「关于」顶部在浏览器中显示服务版本，在桌面 App 中始终显示桌面版本。「版本不一致」和「可更新」标签可以同时出现，与版本号组成同一个可点击入口，共用悬停和键盘焦点。点击任意位置打开版本详情弹窗；窄屏使用底部抽屉。弹窗先展示更新结论和操作，有新版本时显示当前版本到目标版本的变化；管理员根据服务能力只看到一种升级入口：支持在线升级时显示「更新并重启服务」，不支持时显示「手动升级指引」，两者均保留更新说明。手动指引展开后才读取安装信息，提供终端命令或部署指南；读取失败可重试，不将加载或错误状态误判为不支持在线升级。下方以紧凑列表列出桌面 App（如有）、Runtime 和 WebUI 的版本与 commit，并保留带图标的一致性状态。不重复展示推荐版本、最近检查时间或可再次检查时间，冷却只在底部检查按钮显示。浏览器比较 WebUI 与 Runtime，桌面 App 还会纳入桌面版本；所有组件的版本号和 commit 均一致时显示「所有组件版本一致」。有差异时仅列出不一致的组件关系，构建信息不足或服务不可达时不显示一致。打开弹窗时自动读取组件版本与一致性；底部仅保留「立即检查新版本」按钮，禁用时直接显示原因或冷却剩余秒数。WebUI 标注「随服务更新」，不提供独立升级。默认页面保留 Logo 与版本入口、服务信息和 GitHub 入口，不再单独展示版本信息或服务更新分组。

版本详情集中提供检查更新、更新说明、桌面下载、服务升级指引和升级进度。检查更新分别遵守桌面和服务的冷却时间，一方暂时不可检查不影响另一方；查询失败保留上次成功信息并显示错误。桌面独立检查正式版目录，未连接服务时也可在连接管理页检查，开发版本不自动比较。组件版本或构建不同只作提示，不阻止使用；页面与服务不同会提供保存输入后刷新的操作。头像圆点引导进入「关于」，桌面更新和本地服务待更新对桌面用户显示，独立服务的新版本头像提醒仍仅对管理员显示。

桌面附带的 Runtime 比已安装本地服务更新时，顶部显示「版本不一致」和「可更新」。版本详情中的本地服务条目与连接管理页显示「本地服务更新待完成」、当前版本和目标版本。点击「更新并重启本地服务」后确认任务中断提示，才使用附带版本升级；完成后重新连接并更新各组件状态，顶部仍显示桌面版本。用户可以关闭弹窗继续使用旧服务，退出或重启桌面应用不会自动升级。取消保持原状，失败保留提示并可重试，不提供降级更新。

「服务信息」分组展示当前 Runtime 的名称与地址。下方可前往 [Molr GitHub 项目](https://github.com/molr-ai/molr)，为项目点 Star。完整 Logo 使用昼夜循环动画，按设备本地时间在 08:00 和 20:00 自动切换，沿用减少动态效果偏好。

## 数据导出

用户设置 → 个人数据导出将当前账号的数据打包为 ZIP，生成后在页面下载。默认包含共享及助理私有记忆（含核心、主题、回顾与遗忘记录）、助理资料、任务与修订、待办和计划、账号设置、属于当前账号的资源记录，以及做梦配置和处理记录。导出时可选择聊天记录（默认勾选）和附件与交付物（默认不勾选）。导出请求取消或超时后，Runtime 会停止继续读取附件并关闭已打开的文件；尚未完成的压缩包不会发布。数据导出不是完整服务灾备。部署者仍需备份数据库、文件、助理工作区、配置和密钥，见 [部署与维护](https://molr.ai/zh/docs/admin/deployment/maintenance/)。

## 桌面客户端窗口

在桌面客户端连接 Runtime 后，顶部显示当前连接、断开连接和最小化／最大化／还原／关闭按钮；顶部空白区域可拖动窗口。这些入口在登录页和故障页也可使用。浏览器访问不显示桌面窗口控件。

关闭后再次打开桌面 App，会自动连接关闭前使用的 Runtime，并沿用仍有效的登录状态。主动断开或返回连接列表后，下次打开停留在连接列表。自动连接失败时可重试或选择其他连接；已停止的本机 Runtime 需要手动启动。

点击「断开连接」返回桌面连接列表，下次连接保留登录状态；关闭窗口和断开连接都不会停止 Runtime 或后台任务。当前页面尚未完成的下载会取消，需要重新下载。连接失败或页面崩溃时，桌面客户端返回内置恢复界面，可重试或选择其他连接。
