# TUI 使用指南

通过 `molr tui` 在终端连接已有 Molr 服务，选择助理、收发消息和处理授权申请。连接同一服务和账号时，可以接着 WebUI 或桌面 App 中的聊天继续。

## 准备工作

准备可运行的 `molr` 程序、服务地址和账号。`molr` 随 Runtime 分发，获取方式见[安装指南](https://molr.ai/zh/docs/admin/deployment/installation/)。终端至少需要 42 列 × 18 行，启动时标准输入和输出都需连接交互终端。

首次使用 Molr 时，先在 WebUI 按[快速开始](https://molr.ai/zh/docs/user/getting-started/)创建助理并选择模型；已有助理可直接连接。

## 启动与连接

在交互终端运行：

```bash
molr tui
```

默认恢复上一次成功连接的 Runtime；没有使用记录时进入连接管理页。方向键选择已有连接，Enter 连接；选择“新增连接”或按 N 添加地址，名称与 CA 证书路径可选，Tab 切换输入项，Enter 保存并连接。连接失败时保留列表和错误提示，可重试或选择另一项。

在聊天页按 Ctrl+O 或发送 `/connections` 打开连接管理；Esc 可返回当前聊天。切换到其他 Runtime 后，原连接的请求和实时订阅会停止。连接、登录会话及本次运行期间的聊天草稿按 Runtime 和账号隔离；切回同一账号可继续原草稿。

## 登录与会话

首次连接在独立登录页输入账号、密码；启用 MFA 时继续输入验证码。密码与验证码遮蔽显示，不写入磁盘。TUI 的连接列表与上次使用记录位于用户配置目录的 `molr/tui/connections.json`，会话各自保存在 `molr/tui/sessions/`，与桌面应用资料隔离，文件权限为 `0600`。登录过期时可进入连接管理，重新选择该连接登录。

## 选择助理与聊天

终端使用现有 Runtime 的助理、聊天记录和授权申请。聊天、助理选择、审批和帮助都是无边框的独立全屏页面。Ctrl+K 或 `/assistant` 打开助理选择，输入名称搜索，方向键选择，Enter 打开。切换助理保留本次运行期间各自的草稿、光标与滚动位置。没有助理时先在 WebUI 创建，再按 Ctrl+R 刷新。

Enter 发送，Alt+Enter 或 Ctrl+J 换行；输入框从一行扩展到最多三行，更多内容在框内滚动。PgUp/PgDn 和滚轮滚动历史，在顶部继续上翻可加载更早记录；Ctrl+End 回到最新消息。实时连接断开后自动重连并补取消息。Ctrl+R 手动刷新。发送失败时保留草稿，按 Enter 重试相同内容会复用该次发送的幂等键。消息保存在 Runtime，退出终端不会删除历史；未发送的草稿不写入磁盘。

附件在 TUI 中以提示显示。查看或上传附件、创建助理和配置资源时，请使用 WebUI 或桌面 App。终端聊天触发的任务由 Runtime 执行，沿用助理的[权限与预算](https://molr.ai/zh/docs/user/guides/permissions-and-budget/)及沙盒限制。

## 处理授权申请

Ctrl+P 或 `/approval` 打开当前助理的待审批申请，展示资源、操作、范围、有效期和额度。默认选中批准，方向键可改为拒绝，Enter 提交；打开页面不会直接批准。PgUp/PgDn 滚动长申请。审批按当前展示的申请及版本提交，冲突时返回聊天重新打开。组合申请按整组处理，授权参数保持申请中列出的值；需要调整参数时使用 WebUI。每次处理一条，后续申请可再次打开审批页查看。

## 阅读与复制

用户消息与输入框共用背景色，助理回复使用终端背景。消息和帮助支持 Markdown，包括表格、引用、代码、粗体与斜体；输入框保留原文。鼠标拖动选择可见文字，Ctrl+C 复制，单击任意位置或 Esc 取消选区。高亮保留文字样式，输入框和消息列表的选区各自限制在所属区域。复制需要终端支持并允许 OSC52 写入剪贴板。滚动或调整窗口会取消选区。

## 快捷键速查

| 快捷键或指令 | 操作 |
| --- | --- |
| Ctrl+O / `/connections` | 打开连接管理 |
| Ctrl+K / `/assistant` | 选择助理 |
| Enter | 发送消息；在选择或审批页确认当前操作 |
| Alt+Enter / Ctrl+J | 换行 |
| PgUp / PgDn | 滚动聊天记录或审批详情 |
| Ctrl+End | 回到最新消息 |
| Ctrl+R | 刷新服务数据 |
| Ctrl+P / `/approval` | 查看当前助理的授权申请 |
| Ctrl+C | 有选区时复制，无选区时退出 |
| Esc | 取消选区或返回上一页 |
| F1 / `/help` | 查看帮助 |
| Ctrl+Q / `/quit` | 退出 TUI |

## 连接参数

`--server URL` 或 `MOLR_SERVER` 可覆盖本次默认选择，并将地址加入连接列表；连接成功后成为下次默认值。`--connections FILE` 使用独立的连接列表和会话目录；与 `--server` 一起使用的 `--session FILE` 可指定该连接的会话文件，`--ca FILE` 可指定额外信任的 PEM 证书。`--login` 重新登录选中的连接；`--logout` 撤销选中连接的会话并退出，连接条目保留。

例如，连接指定服务（将示例地址替换为实际地址）：

```bash
molr tui --server https://molr.example.com
```

`--username NAME` 可预填登录用户名；完整参数可通过 `molr tui --help` 查看。

## 离线预览

`molr tui --demo` 保留离线预览，使用预设助理、回复和模拟审批，不连接 Runtime；退出后丢弃演示数据。

```bash
molr tui --demo
```
