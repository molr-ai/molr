# TUI 使用指南

通过 `molr tui` 在终端连接已有 Molr 服务，选择助理、收发消息和处理授权申请。连接同一服务和账号时，可以接着 WebUI 或桌面 App 中的聊天继续。

## 准备工作

准备可运行的 `molr` 程序、服务地址和账号。`molr` 随 Runtime 分发，获取方式见[安装指南](https://molr.ai/zh/docs/admin/deployment/installation/)。终端至少需要 42 列 × 18 行，启动时标准输入和输出都需连接交互终端。

服务和账号准备完成、管理员已分配可用模型后，可以直接在 TUI 创建助理。首次使用的账号与资源准备见[快速开始](https://molr.ai/zh/docs/user/getting-started/)。

## 启动与连接

在交互终端运行：

```bash
molr tui
```

默认恢复上一次成功连接的 Runtime；没有使用记录时进入连接管理页。方向键选择已有连接，Enter 连接；选择“新增连接”或按 N 添加地址，名称与 CA 证书路径可选，Tab 切换输入项，Enter 保存并连接。连接失败时保留列表和错误提示，可重试或选择另一项。

在聊天页按 Ctrl+O 或发送 `/connections` 打开连接管理；Esc 可返回当前聊天。切换到其他 Runtime 后，原连接的请求和实时订阅会停止。连接、登录会话及本机聊天草稿按 Runtime 和账号隔离；切回同一账号可继续原草稿。

## 登录与会话

首次连接在独立登录页输入账号、密码；启用 MFA 时继续输入验证码。密码与验证码遮蔽显示，不写入磁盘。TUI 的连接列表与上次使用记录位于用户配置目录的 `molr/tui/connections.json`，会话各自保存在 `molr/tui/sessions/`，与桌面应用资料隔离，文件权限为 `0600`。登录过期时可进入连接管理，重新选择该连接登录。

## 选择助理与聊天

每条助理消息的首行左侧显示灰色圆点 `●`，用于区分连续发送的独立消息；同一条消息内的段落和换行不重复标记。

终端使用现有 Runtime 的助理、聊天记录和授权申请。聊天、助理选择、审批和帮助都是无边框的独立全屏页面。Ctrl+K 或 `/assistant` 打开助理选择，输入名称搜索，方向键选择，Enter 打开。有未读消息时，助理名右侧以高亮标签显示「X条未读」，可与正在处理、待审批状态同时显示；没有未读时隐藏标签。切换助理保留各自的草稿和光标，以及本次运行期间的滚动位置。没有助理时输入 `/new` 创建；助理选择页也可按 Ctrl+N 创建。F1 打开操作菜单，无需记住所有指令。

Enter 发送，Alt+Enter 或 Ctrl+J 换行；输入框从一行扩展到最多五行，更多内容在框内滚动。Alt+↑ / Alt+↓ 和滚轮滚动历史，在顶部继续上翻可加载更早记录；Ctrl+G 回到最新消息。PgUp/PgDn 和 Ctrl+End 仍可使用。离开底部后，输入框上方靠右显示可点击的「返回底部」；有未读时显示「有新消息」。入口不挤动消息或覆盖运行状态，上翻期间新消息不会打断阅读。实时连接断开后自动重连并补取消息。Ctrl+R 手动刷新。发送失败时保留草稿，按 Enter 重试相同内容会复用该次发送的幂等键。消息保存在 Runtime，退出终端不会删除历史；未发送草稿自动保存到本机；发送结果未确认时，可用 `/retry-send` 按原内容和幂等键继续发送并确认结果。该操作不会把后来编辑的内容一起发送。

正文最多 4000 字符；达到上限时提示用 Ctrl+T 转为文本附件，已有草稿保留。终端聊天触发的任务由 Runtime 执行，沿用助理的[权限与预算](https://molr.ai/zh/docs/user/guides/permissions-and-budget/)及沙盒限制。`/settings` 调整当前助理的模型、预算和压缩阈值；资源由管理员准备，TUI 管理已有资源的助理授权。

助理绑定微信、Telegram 等外部入口时，TUI 在输入框上方显示当前渠道，输入标识由 `›` 改为 `/`，只执行命令。直接输入 `help`、`compress` 等命令即可，也可保留开头的 `/`；Tab 补全，Enter 执行。普通消息草稿与附件单独保留，解绑后恢复；命令输入不添加附件，Ctrl+C 只清空当前命令。请在该渠道发消息，或使用 `/channel` 查看并确认解绑，恢复 TUI 输入。查询入口期间也暂停发送，Ctrl+R 可重新检查。停止、审批、查看历史与下载附件仍可用；解绑会停止外部渠道收发并取消未完成投递，聊天记录和草稿保留。

macOS iTerm2 中使用 Option+Enter 换行。TUI 会向支持 Kitty 键盘协议的终端请求保留按键修饰信息，退出时恢复原模式。请允许当前 Profile 的 **Keys → General → Apps can change how keys are reported**。若 Option+Enter 仍直接发送，终端可能仍将它编码为普通 Enter；可在 **Keys → Key Mappings** 添加 Option+Enter，选择 **Send Hex Code** 并填写 `0x1b 0x0d`，或直接使用 Ctrl+J。应用无法从普通 Enter 中恢复已经丢失的 Option 信息。参见 [iTerm2 键盘设置](https://iterm2.com/documentation-preferences-profiles-keys.html)。

## 附件与长文本粘贴

Ctrl+F 或 `/attach` 打开文件选择页；↑↓ 浏览，Enter 进入目录或添加文件，空格多选，Backspace 返回上级目录。Ctrl+L 编辑路径，Tab 补全唯一匹配的路径。也可发送 `/attach ./报表.xlsx`；支持 `~`、空格和成对引号。文件路径属于运行 TUI 的机器；通过 SSH 运行时读写的是远端文件。

附件先上传并加入当前助理的草稿，Enter 随说明文字发送，也可只发送附件。每条消息最多 5 个附件，单个最多 20 MiB，服务端部署限制和账号额度仍会校验。上传显示进度，失败后通过 Ctrl+E 或 `/drafts` 查看附件，R 重试、D 或 Delete 移除。重试使用相同原文和幂等键；发送失败保留正文和附件，成功仅移除本次发送的附件。切换服务取消传输，返回后可重试。

支持括号粘贴的终端中，一次粘贴超过 4000 个 Unicode 字符、达到 20 行，或使现有正文累计超过 4000 字符时，会将原文保存为 UTF-8 文本附件，不插入消息正文。附件按文件名、大小与上传状态展示；短屏只展示前几项，可用 Ctrl+E 查看全部附件，Enter 预览文本、Alt+↑ / Alt+↓ 翻页、Esc 返回。原文件保留换行和制表符，预览会清理终端控制字符。Ctrl+T 可把现有输入框正文完整转为文本附件，再补写说明。超过附件大小或数量限制时会明确提示未添加。

文本附件不会自动作为消息正文进入模型上下文；普通发送与加急均只携带附件引用，由助理通过附件和文件工具按需读取。已读取的内容仍可能进入上下文。

消息中展示附件名称和大小，`/attachments` 列出已加载聊天记录中的附件。选择后 Enter 编辑完整保存路径，再次 Enter 下载；目标已存在时需要确认替换，也可 Esc 返回修改路径。下载期间 Esc 取消，成功后显示实际保存位置。下载校验大小和 SHA-256，通过后才发布到目标文件；失败不留下半成品。更早的附件先在聊天页向上翻页加载。

未转为附件的粘贴，超过 100 字符或超过两行时，会在输入框中折叠为紫色的 `[粘贴了 N 字符：预览…]` 文本块，与普通正文区分。每次粘贴独立成块，左右方向键跨过整块，Backspace 或 Delete 一次删除整块；普通输入可以写在块前后。发送时按原位置展开正文，不上传文件、不发送预览占位文字，4000 字符限制按展开后的原文计算。切换助理保留各自的文本块。

聊天页无鼠标选区时，Ctrl+C 先清空当前正文、文本块和待发送附件，并取消尚在上传的附件；输入完全为空时才退出。它不撤回已发出的消息，也不停止 Runtime 执行。有鼠标选区时 Ctrl+C 仍复制选区，Ctrl+Q 始终退出。

## 执行控制与指令

Ctrl+S 或 `/stop`（`/停止`）中断当前一轮，已完成的写入不回滚；退出 TUI 不会停止 Runtime 的任务。工作中可以继续补充普通消息，随后用 `/expedite`（`/加急`）请求优先读取截至当前序号的未读消息，已开始的工具操作会先结束。

`/compress`（`/压缩`）请求上下文压缩，不发送聊天消息，也不清除已有附件。开头输入 `/` 后，↑↓ 选择指令，Tab 或 Enter 补全，再次 Enter 执行；Esc 关闭补全提示。完整指令可直接执行。

`/permission approve|reject`（`/权限审批 同意|拒绝`）处理当前助理最新一条待审批申请；追加完整申请 ID 可精确选择，追加 `all` 或 `全部` 处理发送指令时已有的全部申请。执行前复核 ID 和版本，批量操作先检查全部选择，中途失败停止并显示已处理数量，已成功的操作保留。批准保留原申请参数；缺少资源或额度时，从 `/approval` 中选择申请并补全。

## 处理授权申请

Ctrl+P、`/approval` 或单击输入框上方左侧的「待审批」提示，打开当前助理的待审批列表。点击提醒或已绑定渠道提示可打开状态详情或渠道管理；点击后保留草稿和历史阅读位置。选择申请后查看资源、操作、范围、有效期和额度，可按原申请批准、调整后批准或拒绝。调整页按资源类型展示字段，Tab 切换字段，左右键切换选项，Enter 查看最终范围；在确认页再次 Enter 提交。组合申请可逐项调整，最后整组提交。

审批绑定当前展示的申请 ID 和版本；新申请不会替换正在审核的对象。版本冲突时保留当前内容，返回重新打开后核对。计算、网络和存储额度通过对应字段填写，临时额度仅在填写到期时间后生效。Full Access 会明确显示其完整权限范围。

`/permissions` 查看已有授权，包括范围、额度和有效期，并支持新增、调整及撤销。撤销可能中断正在使用该授权的工作。新授权只选择账号可见且可用的资源；资源或账号额度不足时需由管理员处理。

## 阅读与复制

用户消息与输入框共用背景色，助理回复使用终端背景。消息和帮助支持 Markdown，包括表格、引用、代码、粗体与斜体；输入框保留原文。鼠标拖动选择消息列表或输入框中的可见文字，松开鼠标自动复制；Ctrl+C 可再次复制，单击任意位置或 Esc 取消选区。高亮保留文字样式，输入框和消息列表的选区各自限制在所属区域。复制需要终端支持并允许 OSC52 写入剪贴板；“复制请求已发送”表示请求已交给终端，不能确认系统剪贴板是否接受。滚动或调整窗口会取消选区。

## 独立使用与管理

F1 的操作菜单提供以下入口。管理页使用 ↑↓ 选择、Enter 打开或确认、Tab 切换表单字段、左右键切换选项、Alt+↑ / Alt+↓ 阅读长内容、Esc 返回；有未保存的表单修改时，Y 放弃、N 继续编辑。Ctrl+R 刷新当前列表或详情。

| 指令 | 用途 |
| --- | --- |
| `/new` | 创建助理，选择已有可用模型 |
| `/settings` | 调整当前助理名称、模型、预算和压缩阈值 |
| `/status` | 查看执行状态、阻塞原因和待处理提醒 |
| `/permissions` | 查看、新增、调整和撤销资源授权 |
| `/tasks` | 查看任务、修订、费用与交付物，暂停、恢复或取消任务 |
| `/plans` | 查看已有计划、执行历史，暂停或恢复后续安排 |
| `/processes` | 查看后台进程、终端会话与输出，结束指定项 |
| `/files` | 浏览助理工作区、预览文本、上传和下载文件 |
| `/search [关键词]` | 搜索当前助理或全部助理的聊天消息 |
| `/messages` | 查看已加载消息的完整原文、时间、附件和本轮用量 |
| `/channel` | 查看聊天入口，解绑外部渠道并恢复输入 |
| `/retry-send` | 按原载荷重试尚未确认的发送 |

创建助理时所选模型的授权由现有创建操作一并完成。更换模型只提供当前助理已有有效调用授权且价格已配置的模型；需要新模型时先在权限页授权，再返回选择。预算为 0 时只允许零费用操作。TUI 不连接新的模型提供商。

聊天显示待处理提醒及数量，`/status` 查看当前提醒或关闭它；关闭仅表示已确认，不改变问题源状态。任务、审批和计划提醒可打开相关内容。错误显示安全原因和请求 ID；没有对应恢复接口的情况只提供已支持的检查或配置入口。

`/stop` 停止助理当前一轮；任务页的暂停、恢复和取消作用于业务任务；计划页只控制后续安排；进程页结束具体后台进程。已经完成的文件写入和费用保留。终端会话在确认后接管并结束，TUI 不提供交互式 Shell 输入。进程输出按游标读取，页面最多保留最近 64 KiB，可切换跟随或保存当前输出；不完整归档明确标记。

任务详情展示当前和历史修订的交付物，选择后下载到运行 TUI 的机器。`/files` 访问当前助理的本地 `/work`：目录可分页并切换隐藏文件，文本可预览，文件可上传和下载。上传最多 64 MiB，并受服务端部署和工作区额度限制；同名文件可替换指定版本或保留两份。上传不发送聊天消息。文件详情可复制助理路径或把路径加入输入框。

工作区写入结果未知时先刷新核对目标，不能自动重试；文件下载期间检测到版本变化会失败。保存到本机前校验目标是否已变化，存在同名文件时明确确认替换。下载到临时文件，成功后才发布目标。

搜索结果打开命中消息的完整详情，可复制原文、保存为本机文本、下载附件或打开卡片目标；搜索不会扫描全部聊天历史，也不加载命中消息周围的上下文。返回恢复搜索结果位置。其他助理的完整运行状态在打开后刷新，不显示未经读取的实时状态。

## 本机草稿与连接维护

正文、粘贴块原文、光标、附件字节快照和未确认发送的幂等键保存于连接配置目录下的 `drafts/`，按连接、账号和助理隔离。文件权限为 `0600`、目录为 `0700`；缓存上限为每个连接账号 256 MiB，达到上限时明确提示，不自动删除未发送内容。附件上传前先保存原始字节，因此源文件后来变化不会改变重试内容。

重新登录同一账号后恢复草稿，不自动发送。成功回执只清除该次发送包含的内容。Ctrl+C 清空草稿的操作也保存到本机。草稿文件损坏或写入失败时保留原文件并提示；同一账号的草稿只能由一个 TUI 进程写入，关闭另一个实例后重新连接。草稿文件使用操作系统文件锁，进程退出后释放。

连接列表支持 E 编辑、L 退出登录、A 更换账号、D 删除连接但保留草稿、X 删除连接及其本机草稿。修改地址保存为独立连接，不复用旧地址的会话；存在本机登录记录的连接需先退出登录再删除。离线退出失败时，R 重试服务端撤销，F 明确只清除本机登录，服务端撤销状态仍会提示。删除连接不会删除 Runtime 中的助理或聊天。

## 连接参数

`--server URL` 或 `MOLR_SERVER` 可覆盖本次默认选择，并将地址加入连接列表；连接成功后成为下次默认值。`--connections FILE` 使用独立的连接列表和会话目录；与 `--server` 一起使用的 `--session FILE` 可指定该连接的会话文件，`--ca FILE` 可指定额外信任的 PEM 证书。`--login` 重新登录选中的连接；`--logout` 撤销选中连接的会话并退出，连接条目保留。

例如，连接指定服务（将示例地址替换为实际地址）：

```bash
molr tui --server https://molr.example.com
```

`--username NAME` 可预填登录用户名；完整参数可通过 `molr tui --help` 查看。

## 离线预览

`molr tui --demo` 保留离线预览，使用预设助理、回复和模拟审批，不连接 Runtime；退出后丢弃演示数据。

```bash
molr tui --demo
```
