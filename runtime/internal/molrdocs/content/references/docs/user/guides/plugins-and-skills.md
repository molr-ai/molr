# 插件与 Skills

先在 **用户设置 → 常规** 开启 **显示插件**，再通过侧栏 **插件**（`/#/extensions`）管理主题、页面和 HTTP 工具。此开关默认关闭，按账号保存并跨设备同步。关闭后隐藏插件入口、插件主题、插件工具目录、登录链接的插件目标、用户组中的插件和服务连接选项，以及用量中的连接明细；直接打开插件页面会转到常规设置。已选择的插件主题暂时使用默认主题，重新开启后恢复。已有插件配置、授权和后台工具执行不受影响。CLI 和 Skill 直接安装在助理工作区，无需导入插件包。

## 使用已授权插件

普通成员使用管理员已启用并分配给所属用户组的插件。个人启停只影响自己的使用；插件有个人设置时，可在对应配置入口填写。插件页面、主题和 HTTP 工具仍受组权限、个人启用和助理授权限制。安装与共享服务连接由[管理员管理](https://molr.ai/zh/docs/admin/administration/plugins/)。

## 内置 Molr 文档

所有账号的助理默认可使用 `molr-docs`，回答 Molr 功能、使用、配置、部署及故障排查问题。助理按需查询随当前 Runtime 发布的中文文档，并使用你的语言回答；文档不代表当前实例的实际配置或运行状态。

此 Skill 无需安装、网络或计算权限，本地沙盒关闭时也可用。助理信息的 Skills 页显示“内置 · 只读”和资料包版本。内置内容随 Runtime 升级，不能由助理修改；个人工作区中的同名 Skill 不覆盖它。

## 安装 CLI 或 Skill

直接在聊天中告诉助理来源与用途，例如：“把这个 CLI 安装到你的工作目录，并按文档验证可用。”助理使用普通 Shell 和文件工具安装程序及依赖，需要计算或网络资源时沿用现有权限申请流程。

CLI 安装在助理的 `/work` 内。Skill 放入 `/work/.agents/skills/<名称>/SKILL.md`，系统自动发现，助理按需读取。不同助理拥有独立工作区，文件跨执行和重启保留。登录按 CLI 自身支持的流程完成，登录文件保存在工作区；更新、检查和删除也由助理使用普通工具完成。

这类安装不会在插件列表中生成记录。插件启停、版本切换和卸载不管理这些工作文件。

助理信息的 Skills 页可以查看已发现的条目；当前没有安装、编辑或启停入口。Skill 提供流程指引，不额外授予文件、网络或工具权限。

## 查看 Skills 总览

在 **资源 → Skills** 集中查看当前账号的技能，按内置、账号共享和助理专属分组。可以搜索名称、用途、路径或助理，并组合来源与助理筛选。选择助理时仍包含内置和账号共享技能；同名的专属技能按助理分别展示。目录展示在职助理，已离职助理不包含在总览中。

点击技能打开详情抽屉，查看来源、适用助理、内容版本和 `SKILL.md` 原文。内置技能只读；账号共享技能来自 `/global/.agents/skills/`，专属技能来自对应助理的 `/work/.agents/skills/`。文件变更后点击刷新重新读取目录。此入口不受“显示插件”开关影响。

助理信息中的 Skills 页继续展示该助理的能力目录。总览展示技能归属，不代表当前执行已加载技能或已获得其工作流程所需的权限。
