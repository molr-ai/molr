# 文件与命令

macOS 受控命令使用 Seatbelt，计算只控制时长，网络采用授权开关，不提供 Linux 资源硬配额。原生路径、撤权和转发边界见 [macOS 原生命令权限](https://molr.ai/zh/docs/admin/sandbox/macos/)。

先确认助理拥有所需目录和计算权限。文件工具、Shell 与网络授权分别管理，具体操作见[权限与预算](https://molr.ai/zh/docs/user/guides/permissions-and-budget/)。

## 工作区与文件

每位助理有一个独立、跨会话保留的本地工作区 `/work`。Runtime 初始化默认目录：`inbox/` 保存附件和导入原件，`projects/` 按事项组织草稿、脚本和工作文件，`outputs/` 保存交付成果。可以要求助理使用其他目录；文件保存后仍需明确发送到聊天才完成交付。

Skills、记忆和回顾沿用 `.agents/` 下的对应目录；`.local/state/molr/` 按用户状态目录的语义存放工具结果及命令输出等执行记录，跨重启保留，当前不自动清理。`.cache/` 是可重新生成的缓存，但当前不会自动清理。`/tmp` 只属于一次命令执行，需要下次继续使用的文件应保存在 `/work`。同一账号共享的 `/global` 对助理普通操作只读。

助理会自动收到这些路径、用途、持久性和可用状态，具体文件按需查找。根目录 `AGENTS.md` 自动加载；进入具体工作目录时，助理先列目录，再加载该目录及上级的指令。附件、交付目录、缓存和运行产物中的同名文件不会自动成为指令。目录约定不增加文件或命令权限。

全局搜索中的聊天结果会进入对应助理，自动加载目标所在的历史页并高亮消息；链接保留消息位置，刷新后仍可定位。点击“返回最新消息”回到会话末尾。目标不存在或不可访问时会明确提示。搜索按批次读取当前内容；搜索期间有新增、删除或权限变化时，结果数量和后续页面可能变化，重新搜索可查看更新后的结果。

## 用户如何使用

1. 在助理信息的权限页授予计算资源的执行权限；普通成员只能选择所属用户组允许的沙盒。
2. 需要外部文件时，让管理员连接目录，再为助理授予读取或读写范围。助理自己的本地工作区可以通过文件工具使用。
3. 需要联网时另授网络权限。允许执行命令不会自动获得联网或模型密钥访问权。
4. 在聊天中说明目标、输入文件和预期产物。权限不足时核对助理申请，再批准所需范围。

资源未就绪时由管理员检查[沙盒资源](https://molr.ai/zh/docs/admin/resources/sandbox/)，系统依赖由部署者处理。断开资源或撤销授权后，重启不会恢复授权。

## 前台命令、后台任务与终端

助理执行的普通命令最多同步等待 60 秒，未结束时转为后台任务。需要持续运行的程序可以直接后台启动；需要逐步输入的命令可以打开终端。

聊天标题栏的「终端」角标显示当前运行中的交互式会话数量，没有活跃会话时隐藏。打开「终端」，可在助理的本机工作区新建交互式 Shell，也可查看助理已开启的 TTY 会话。标签与标题栏合并，只显示当前运行中的会话，点击切换，使用加号新建；有控制权时可通过标签上的关闭按钮结束会话，结束后自动移出标签栏，历史输出仍在「运行任务」中查看。终端支持实时输出、中文、方向键、补全、Ctrl-C 和窗口缩放；桌面可浮动或停靠，手机使用底部窗口。状态栏的「终端配色」可选择跟随应用、浅色或深色，默认跟随应用；选择保存在当前浏览器，只影响终端窗口，切换配色不会重建会话。「运行任务」中的 TTY 使用相同终端界面，普通任务仍显示文本输出。

助理开启的终端默认由助理控制；用户新建的终端默认由当前窗口控制。点击「接管」切换输入权，其他窗口和助理仍可查看；只有控制窗口可以输入、中断、缩放和结束该会话。「交还助理」会通知助理读取最新输出后继续。接管不会中断已经运行的命令，需要时使用 Ctrl-C；已提交给 Shell 的命令不会撤回。接管不改变沙盒权限或额度。

关闭窗口或断线后会话继续运行，不自动交还助理；重新打开窗口可继续查看，刷新页面后需再次接管。结束会话使用「结束会话」。用户在运行任务中的「停止全部」仍可结束所有任务；助理工具的 stop_all 跳过用户控制或交还后尚未读屏的 TTY。停止助理当前一轮对话不会关闭已分离的任务。用户控制期间终端不会发送周期性运行提醒。

手动新建会话使用已授予的本机计算资源和网络范围，默认进入助理工作区，不启用 Full Access。Linux 和 macOS 支持交互终端；Windows 暂无 TTY。助理创建的远程 TTY 可以查看和接管，但远程节点使用其授权目录，与本机资源管理器的工作区不同。

同一助理跨全部沙盒最多同时运行 10 个普通隔离执行，包含前台、后台与终端；Full Access 不计入这一上限。任务仍受授权时长、到期时间和资源额度限制。后台任务结束后会通知助理，无需反复询问进度；仍打开的终端不一定正在计算。

运行任务列表优先展示活动任务，最近结束的记录折叠收起，最多保留 50 条历史记录。普通任务详情最多显示最近 64 KiB 输出，完整输出可从归档文件读取。

每次执行或终端有独立的 `/tmp`，结束后清空；持久文件保存到本地 `/work` 或远端授权目录。新终端不会恢复上一个终端的进程或环境，可以在本地 `/work/.profile` 保存交互 Shell 需要的环境变量。普通非交互命令不加载该文件。

Runtime 重启不恢复活进程，遗留任务标记为中断，不自动重跑。授权变更、沙盒断开和资源限额也可能终止任务；取消不回滚已写入的文件。

## Shell 端口转发

需要查看助理制作的网页时，可以要求：“启动这个项目，并把服务端口转发给我。”助理会取得可访问地址；使用它交付的地址，不使用命令输出中的 localhost。

运行任务详情显示转发端口、复制地址和打开 HTTP 网页入口。「等待服务」表示尚未通过连接检查；「可连接」只表示 TCP 连接正常，网页内容仍需检查。当前仅管理员可创建公开端口转发，普通成员暂不可用。

转发入口都位于 Runtime 所在机器，远程沙盒的服务也通过 Runtime 访问。每个任务最多转发四个端口，对外支持 HTTP、WebSocket 和 SSE。原始 TCP 无认证模式已隐藏下线，不能通过界面、助理工具或 API 创建。

访问入口须有有效的 Molr 登录会话，并有权访问对应助理和任务。从运行任务面板打开或复制链接，使用与登录入口相同的主机名／IP；入口会绑定所选登录会话。未登录返回 401，无任务权限返回 403。HTTP 请求与 WebSocket 握手均验证权限，注销和撤销会话也会关闭已建立的连接。转发前剥离 Molr 认证凭据，目标服务不能覆盖保留的认证 Cookie；应用自己的登录机制仍由应用管理。地址无法访问时由部署者检查[转发监听与网络](https://molr.ai/zh/docs/admin/sandbox/linux/#转发监听地址)。

关闭聊天不会关闭后台服务；任务停止、自然结束、撤权、到期或断开沙盒会回收端口。重启后不恢复转发，历史地址不适合作为长期服务入口。转发本身不需要出站网络授权，服务访问外部 API 或下载依赖仍需网络授权。

## 远程文件

远程电脑不保存助理工作区、Skills 或记忆。使用远程资源时，明确告诉助理目标电脑和目录；持久结果需写入该节点已授权的目录，远端临时目录在执行结束后清除。

可以在本地与一个远程节点之间传输单个文件，单次最多 20 MiB；源和目标分别需要授权。覆盖文件需要核对目标版本，不支持目录自动同步或两个远程节点间直接传输。需要发到聊天的远程文件先下载到本地。
