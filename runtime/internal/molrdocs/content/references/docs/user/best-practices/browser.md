# 操作浏览器

助理可以使用浏览器打开网页、读取内容、填写表单、点击按钮和截图。聊天标题栏的「浏览器」打开实时画面，显示助理正在使用的同一个浏览器。

> [!INFO]
> 助理通过浏览器操作网站时，可能被网站的反爬虫或反机器人策略拦截。对于提供官方命令行工具（CLI）的服务，建议优先使用官方 CLI 等接入方式。

启动浏览器或终端时，只有一个可用计算资源会自动选中并隐藏资源选择框；多个资源时可以选择。只有普通授权时使用沙盒，只有 Full Access 授权时使用 Full Access 并显示模式标识；两种授权都可用时默认沙盒，可切换执行模式。Full Access 使用服务账户权限，不受 Molr 文件、网络隔离和资源配额限制，浏览器仍启用 Chromium 自身沙盒。选择只影响新会话；浏览器更换资源或模式前需要先结束当前会话，网站登录状态继续保留。已有授权失效时需重新选择，运行中撤权会结束相应任务。

## 开启与观看

沙盒模式需要本机计算资源和网站网络权限；Full Access 模式需要本机计算资源上的 Full Access 授权。首次使用时，管理员可以在浏览器面板点击「安装并启动」，下载并校验当前兼容版本；关闭面板后安装继续，完成后会重新检查授权并启动浏览器。支持 Linux amd64 和 macOS（Apple Silicon／Intel）。也可由管理员预先配置[浏览器组件](https://molr.ai/zh/docs/admin/administration/components/)。macOS 的授权与隔离边界见 [macOS 浏览器说明](https://molr.ai/zh/docs/admin/sandbox/macos/#受管浏览器)。可以直接告诉助理：

> [!PROMPT]
> 打开这个网站，比较两个产品的规格，把结果整理给我。需要登录时等我接管。

也可以在浏览器面板选择已授权的本机计算资源，点击「启动浏览器」。每个助理最多一个活跃浏览器任务，重复启动复用已有任务；浏览器内可以打开多个标签页；标题栏浏览器图标的角标显示当前标签数量，关闭面板后仍会更新。浏览器作为沙盒任务运行，选择计算资源用于确定运行时限及平台支持的 CPU、内存、进程数限制，沿用已有授权。面板默认选中首个可用资源，可按需要切换；浏览器占用现有执行名额，受计算额度和授权期限限制。

关闭面板只停止观看。网页切到后台或网络离线时也会暂停画面，返回前台并恢复网络后自动重连；浏览器任务和接管状态继续保留。浏览器继续运行，可在「浏览器」或「运行任务」中关闭。关闭浏览器保留网站登录态和本地数据，下次启动继续使用；网站登录是否仍有效由网站决定。不同助理的数据互不复用。

桌面端默认以浮窗显示浏览器，不占用聊天侧栏，可以同时聊天与观看网页。拖动顶部空白处或移动手柄调整位置，拖动右下角缩放区域等比例放大或缩小画面，鼠标移入时显示缩放指针；移动手柄和缩放区域也支持方向键微调，按住 Shift 加大调整步幅。网页画面保持 16:10，标签栏、地址栏和状态栏保持正常大小。浮窗限制在当前窗口内，同一页面关闭再打开时保留位置和尺寸；放大显示不会增加远端画面的分辨率。

侧栏和手机抽屉中的网页按可用画布比例渲染，调整窗口或展开辅助输入后自动适配；远端固定宽度为 1280 像素，高度随比例变化。有人接管时，以接管窗口的画布为准，其他观看窗口等比例显示同一画面。

点击「停靠侧栏」可回到侧栏；可用空间不足时使用抽屉。「浮窗模式」恢复浮窗，切换时保留当前连接和接管状态。手机端使用底部抽屉。标签、新建、布局切换和关闭按钮位于同一行，接管／交还按钮位于地址栏右侧；标签较多时先缩窄，再通过左右箭头浏览溢出部分。

## 浏览器代理

浏览器标题栏会显示代理是否启用。代理设置由管理员在[组件管理](https://molr.ai/zh/docs/admin/administration/components/#浏览器代理)中维护，助理仍需获得代理端点的网络授权。设置变更后重新启动浏览器任务以应用新配置；已有任务继续使用原配置。

## 接管与交还

> [!WARNING]
> 不建议将个人网站账号的密码直接提供给助理。需要登录时，建议接管浏览器并自行完成登录，再将控制权交还给助理。

点击「接管」后，等待当前已接受的操作结束，再使用鼠标点击、滚动、拖动以及地址栏和标签页控件。点击网页输入框后即可直接键入中文或粘贴，仅显示系统输入法的候选窗口，位置靠近点击处，组合文字确认后一次发送到网页。底部「已连接」右侧的键盘按钮可展开「辅助输入」，适合手机或特殊输入法；结束会话按钮与它并排，远离右下角缩放区域。标签栏用「＋」新建，每个标签的关闭按钮仅关闭对应标签。

接管期间，助理仍能读取快照、截图、标签页和当前网址；点击、填写、导航、关闭等操作会收到明确的接管提示。接管影响该浏览器的所有标签页。你在浏览器里登录的网站，交还后也能由助理在相同授权范围内使用。

完成后点击「交还」。助理会收到通知，并须先读取新快照才能继续操作。交接前的排队操作和旧控制权版本不会在交还后重放。多个窗口同时请求接管时，过期请求会被拒绝，并通过可关闭的 Toast 提示重新接管；提示也会自动消失。

断线或关闭面板不会自动交还控制。在同一页面关闭再打开面板会恢复当前窗口的接管状态，无需再次接管；刷新页面或换到其他窗口后需明确接管。页面自身的脚本和网络活动仍受原有沙盒权限约束，接管不会扩大授权。

接管输入会按顺序分批发送：连续鼠标移动保留最新位置，拖动保留有限路径采样；相邻同方向滚轮事件累加实际滚动量，支持横向滚动。文字、按键和点击保持顺序，不跨点击、切换标签或导航合并。请求失败时停止后续排队输入；请检查页面实际结果后再操作，避免重复提交。

## 范围与故障

当前支持本机 Linux 和 macOS 的受管 Chromium，可按授权选择沙盒或 Full Access 模式。浏览器程序共享只读安装，网站数据按助理持久保存。实时画面不自动录制，人工逐键输入不写入操作日志；截图只有明确调用时保存。

组件未安装时面板显示安装入口和空间需求；系统库缺失、后台维护服务不可用时显示管理员操作指引。安装进度与结果可在浏览器面板及「管理员设置 → 组件」查看，失败后可以重试。Runtime 重启后不会自动重放“安装并启动”的浏览器启动请求。系统库不可用、资源不足或授权过期时，面板与运行任务会显示不可用或结束状态。正常关闭会先让 Chromium 保存数据，再回收执行；强制停止、崩溃和撤权不保证尚未写入磁盘的数据全部保存。Runtime 重启后任务标记中断，不自动重放操作。

浏览器异常退出会显示可关闭的 Toast，即使启动失败发生在两次状态轮询之间也会提示。进程／线程数超限、内存不足、运行超时、授权变化和任务中断分别给出处理指引；其他失败提示查看浏览器任务的错误输出。同一页面内每个失败任务只提示一次，关闭再打开面板不会反复弹出。Linux 将线程计入进程额度，调整额度仍须通过资源授权，启动浏览器不会自动提高限制。
