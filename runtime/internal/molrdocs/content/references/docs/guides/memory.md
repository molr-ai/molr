# 记忆与自动整理

在「用户设置 → 记忆」选择共享范围或一位助理，管理长期事实与偏好。

## 保存位置与编辑

记忆保存事实、沟通偏好与长期认知。同一账号内的共享和助理私有记忆具有不同范围，不会跨账号共享；修改或删除记忆影响后续使用，不等于删除原聊天记录。详细执行上下文是另一类内部状态。

记忆以 Markdown 文件保存在助理本地工作区：`/work/MEMORY.md` 放自动加载的核心认知，`/work/.agents/memory/` 放按需查阅的主题记忆；同一账号的共享文件位于 `/global` 对应目录。文件工具和 Shell 读取同一份内容，可以用 `rg` 搜索。支持 `用户偏好/沟通偏好.md` 这样的分类目录和语义文件名。界面可新建目录、重命名、移动和删除空目录；同名创建不会覆盖。直接修改文件后刷新记忆页即可看到变化；`/global` 对助理的普通命令只读。远程电脑不存放助理工作区或记忆。

## 记忆管理

本地 MEMORY.md 核心认知自动进入有大小上限的上下文；主题记忆由助理使用文件搜索和读取工具主动检索。模型整理主题时负责同步相关核心内容和文件引用。目录就是分类，改名后旧路径不再有效；当前明确要求优先于历史偏好。

您可以查看、编辑、确认、删除或遗忘记忆。普通删除只移除文件，之后可能从原资料重新整理出来。遗忘还会记录内容摘要及已知来源，并清理相关撤销副本；没有来源信息的外部 Markdown 不能保证所有改写都被识别。原始聊天不会因此删除。

撤销已完成的一批整理会按反序恢复其未被后来修改的文件操作，包括创建、编辑、移动及删除。后来编辑、确认或遗忘的内容受到保护；具体保留文件会显示在批次记录中。

## 做梦（自动整理）

做梦会向模型提供前一个完整自然日的新增经历和文件工具。模型自行查找、读取已有记忆，更新、合并、移动或删除主题文件，并维护 `MEMORY.md` 中的核心认知；最后保存本批整理回顾。没有新经历但已有私有记忆文件时，仍可进行整理。模型负责判断信息的范围和可靠性，应保留不确定性，避免把助手声称或临时要求当作长期事实。

在“用户设置 → 记忆”中选择在职助理，可以设置每天的做梦时间、时长上限或立即整理。全局共享范围不显示做梦操作。做梦使用助理当前选定且支持工具调用的模型，每批可进行多轮调用，用量计入该助理预算。历史材料作为数据提供，不会作为新指令重放。

开发工作台展示实际的文件写入、编辑、移动、删除以及每轮工具结果。文件操作出错时，模型可以根据错误重新读取并修正。您在记忆界面保存或确认的文件会标为只读，共享记忆也只读；直接编辑普通 Markdown 不会自动锁定文件。

做梦期间助理显示“正在做梦”，新消息和计划排队等待，消息保持未读，加急不可用。时段结束或手动停止会保留已经成功的文件操作，即使当前批次尚未完成。一次做梦涉及多个资料日期时，按设置时区从最早到最晚依次整理，先补旧日期，再处理新日期；同一天分多批时，完成当天各批后再处理下一天。回顾按资料所属日期保存。未处理完的资料最多在次日补处理一次；错过整个预留时段则跳过，失败的整理在原截止时间内可重试一次。

记忆可以使用普通 Markdown，自定义元信息不必符合固定模板。已知元信息有格式问题时，做梦会将问题随文件内容提供给模型，允许修复或继续整理其他文件；未修复的问题可保留在回顾中，不会使服务退出。若损坏的元信息导致无法判断文件是否已确认，该文件会保持只读，需由您修复，其他整理照常进行。
