## 聊天

- **Ctrl+K**：选择助理，也可发送 `/assistant`。
- **Ctrl+P**：查看授权申请，也可发送 `/approval`。
- **Enter**：发送消息。
- **Alt+Enter** 或 **Ctrl+J**：换行。
- **PgUp / PgDn**：滚动聊天记录或审批详情。
- **Ctrl+R**：刷新服务数据。
- **滚轮**：滚动当前聊天或帮助页。
- **鼠标拖动**：选中文字；**Ctrl+C** 复制，**Esc** 或单击任意位置取消选区。
- **Ctrl+End**：回到最新消息。

## 页面导航

- **Ctrl+O** 或 `/connections`：打开连接管理（在线模式）。
- **N**：在连接管理页新增连接。
- **Tab**：切换连接或登录表单的输入项。

- **↑↓**：选择助理或审批操作。
- **Enter**：打开助理，或确认审批操作。
- **Esc**：返回上一页。
- **F1** 或 `/help`：查看帮助。
- **Ctrl+Q** 或 `/quit`：退出；没有选区时也可按 **Ctrl+C**。
