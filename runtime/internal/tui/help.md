## 聊天

- **Ctrl+K**：选择助理，也可发送 `/assistant`。
- **Ctrl+P**：查看授权申请，也可发送 `/approval`。
- **Enter**：发送消息。
- **Alt+Enter** 或 **Ctrl+J**：换行。iTerm2 使用 **Option+Enter**；若直接发送，可在 Keys → Key Mappings 将其设为 Send Hex Code：`0x1b 0x0d`。
- **PgUp / PgDn**：滚动聊天记录或审批详情。
- **Ctrl+R**：刷新服务数据。
- **滚轮**：滚动当前聊天或帮助页。
- **鼠标拖动**：选中文字；松开鼠标自动复制，**Ctrl+C** 再次复制，**Esc** 或单击任意位置取消选区。
- **Ctrl+End**：回到最新消息。

## 页面导航

- **Ctrl+O** 或 `/connections`：打开连接管理（在线模式）。
- **N**：在连接管理页新增连接。
- **Tab**：切换连接或登录表单的输入项。

- **↑↓**：选择助理或审批操作。
- **Enter**：打开助理，或确认审批操作。
- **Esc**：返回上一页。
- **F1** 或 `/help`：打开操作菜单和帮助。
- **Ctrl+Q** 或 `/quit`：始终退出。聊天页无选区时，**Ctrl+C** 先清空正文与附件，空输入时退出。

## 执行与指令

- **Ctrl+S**、`/stop` 或 `/停止`：停止当前一轮。退出终端不会停止任务。
- `/expedite` 或 `/加急`：工作中优先读取已发送的补充消息。
- `/compress` 或 `/压缩`：请求上下文压缩。
- `/permission approve|reject [ID|all]` 或 `/权限审批 同意|拒绝 [ID|全部]`：审批最新、指定或全部待审批申请。
- 输入 `/`，**↑↓** 选择、**Tab / Enter** 补全，再按 **Enter** 执行。
- `/channel`：查看当前聊天入口；绑定时输入标识为 `/`，可直接输入命令名；确认解绑后恢复消息草稿。

## 文件与长文本

- **Ctrl+F** 或 `/attach [路径]`：添加文件。**空格** 多选，**Ctrl+L** 编辑路径，**Tab** 补全，**Backspace** 返回上级目录。
- **Ctrl+E** 或 `/drafts`：待发送附件；**R** 重试、**D / Delete** 移除、**Enter** 预览粘贴文本。
- 超过 4000 字符、达到 20 行或使正文累计超限的粘贴成为文本附件，按文件名和大小展示，正文按需读取。
- **Ctrl+T**：把输入框全文转为文本附件，再输入说明。正文最多 4000 字符；每条消息最多 5 个附件，每个最多 20 MiB。
- `/attachments`：查看已加载历史中的附件，**Enter** 选择保存路径；重名需要确认替换，**Esc** 取消下载。
- 文件路径属于运行 TUI 的机器。通过 SSH 使用时读写远端文件。

- 未转附件、但超过 100 字符或两行的粘贴，显示为紫色 `[粘贴了 N 字符：预览…]` 文本块；左右键跳过整块，Backspace / Delete 整块删除。发送时在原位置展开正文。
- **Ctrl+C**：有鼠标选区时复制；否则聊天页有正文或附件时清空，空输入时退出。清空会取消附件上传，不会撤回已提交的消息。

## 独立使用

- `/new` 创建助理；助理列表中 Ctrl+N 也可创建。
- `/settings` 修改名称、已授权模型、预算和压缩阈值。
- `/status` 查看状态与当前提醒；关闭提醒不会解决源问题。
- `/permissions` 查看、新增、调整或撤销授权；`/approval` 逐项补全申请。
- `/tasks` 查看任务、修订与交付物；`/plans` 管理后续安排。
- `/processes` 查看输出、结束后台进程；停止助理一轮不会停止这些进程。
- `/files` 浏览助理工作区，上传、预览及下载文件。
- `/search [关键词]` 搜索消息；`/messages` 查看完整原文并复制或保存。
- `/retry-send` 按原载荷与幂等键重试未确认发送。
- 管理表单 Tab 切换字段，左右键切换选项，Enter 确认，Esc 返回。
- 连接页 E 编辑、L 退出、A 换账号、D 删除连接、X 同时清理本机草稿。
- 草稿和附件原文自动保存到本机，重新登录同一账号可恢复；失败提示会持续显示。
