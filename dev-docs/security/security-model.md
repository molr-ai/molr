# Runtime 公网部署与安全边界

Go 单体 server 支持部署在公网服务器。认证、授权、会话和审计内置于同一程序；自托管不代表请求可信，局域网访问也默认需要认证。支持独立账号和管理员用户组：业务数据按账号隔离，资源目录由管理员维护，普通成员的执行同时受用户组范围、成员配额与助理授权限制；不提供用户间共享空间或独立认证服务。

Full Access 是显式计算权限例外：部署 `sandbox.allow_full_access`、普通用户组的 `AllowFullAccess`、助理 `Scope.FullAccess` 授权及每次 `full_access: true` 均检查通过，才直接在服务环境执行。此路径没有 Molr 提供的文件、网络、进程隔离或资源限额，可接触服务账号本身能访问的凭证和数据；应用层多用户保密边界不能约束这种系统访问。它面向已在外部隔离环境部署的可信使用场景。未显式请求 Full Access 的调用继续遵循本文的隔离机制，隔离失败不回退直接执行。

## 局域网 HTTP 与首次安装

`tls_mode: lan` 是显式的可信局域网明文模式，允许数字私网／回环 URL 和监听地址，拒绝公网 peer、未登记 Host／Origin 及代理转发头。它不提供传输机密性；公网使用 TLS。会话 Cookie 按端口命名，保留 HttpOnly、SameSite 与 CSRF，HTTPS 的 Secure／__Host Cookie 不降级。

本机 bootstrap 生成随机所有者密码，保存到私有数据目录的 `initial-password`（0600），同时写入首次引导状态。HTTP 不开放账号初始化。access／doctor 通过正常认证 API 执行，遵守当前密码与 MFA；重跑安装不重置账号。Provider 自动发现只由管理员触发、仅限固定回环候选且拒绝重定向，不构成通用端口扫描或网络策略豁免。

## 1. 入口与部署

公网入口必须使用 HTTPS，可由 server 直接配置证书，也可在受信任反向代理终止 TLS。代理模式下用网络访问控制限制后端直连，并仅信任明确配置的代理来源及转发头，不能根据客户端自报的 `X-Forwarded-For` 或协议头认定来源可信。

监听地址可以是 `0.0.0.0`，监听范围与认证相互独立。配置中明确对外地址、允许的 Host／Origin、可信代理、证书和数据目录；验证公网部署的实际 TLS 链路，不能仅凭请求头判断“已加密”。业务 API 不接受明文公网认证请求。

公开入口仅包含登录所需页面／静态文件、登录流程及不含内部信息的最小存活探测。其余接口默认要求认证，包括 SSE、搜索、附件、产物下载与管理操作。调试、性能分析和详细运行指标不作为默认公网接口。

## 2. 账号初始化与认证

所有者通过本机 `molr init -config … -username … -password-stdin` 创建，完整部署步骤见 [部署指南](../../docs/deployment/README.md)。未初始化时不开放业务服务，不提供可被公网抢先注册的安装页面，不设置默认账号密码或公开注册入口。密码通过交互或受保护输入提供，不写入命令行参数和普通日志。

首版支持用户名／密码登录、密码修改、登录设备管理与退出。支持 TOTP 二次验证和一次性恢复码，公网部署建议启用。安全设置变更、密码修改、访问令牌创建与数据清理始终要求近期重新验证身份。保存 Provider／管理凭证及数据导出由“敏感操作验证”开关控制，默认关闭；关闭时仍校验有效所有者会话、权限和 CSRF。开启后必须再次验证，已绑定 TOTP 时同时校验验证码。该开关及验证器绑定／解绑集中在用户设置 → 安全中。账号恢复由持有主机管理权的操作者本地执行，恢复后撤销旧会话和访问令牌，并留下审计记录。登录错误不暴露账号是否存在，登录及二次验证按账号与来源限速，避免永久锁定被滥用来阻断所有者访问。[OWASP 认证建议](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html)

密码使用带独立盐的 Argon2id，只保存哈希；参数及验证逻辑见 `runtime/internal/auth`，不使用明文或普通快速摘要保存密码。TOTP 密钥需要受保护存储，恢复码只保存校验摘要。[OWASP 密码存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)

## 3. 浏览器会话与客户端令牌

浏览器使用随机、不可预测的会话令牌，服务端保存可撤销的会话记录及令牌摘要。设备标识只参与会话匹配，不授予权限；客户端按浏览器站点来源或 App 安装实例与服务地址保存随机 deviceId，服务端仅保存其摘要，并以账号与摘要唯一约束设备会话。每次完整认证生成新 SessionID、Token 和 CSRF，在同一事务中替换该设备的旧记录、通知权限订阅并记录审计；失败登录不替换。MFA challenge 绑定设备摘要、展示信息和开始时的会话 ID，旧 challenge 不能覆盖较新的成功登录。Cookie 设置 `Secure`、`HttpOnly` 和合适的 `SameSite`，非默认端口通过 Cookie 名称隔离，不向前端脚本暴露登录令牌。登录后更换会话标识，设置闲置与绝对过期时间；退出、修改密码或远程注销设备后撤销相应会话。[OWASP 会话管理建议](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)

对使用 Cookie 认证的状态变更请求校验 CSRF 令牌与来源，包括登录流程；GET 不产生业务写入。同源部署为默认方案，跨域访问仅允许明确配置的来源，CORS 不替代身份验证或 CSRF 防护。[OWASP CSRF 防护建议](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)

CLI 或原生客户端可使用独立、可撤销且有有效期与操作范围的访问令牌，通过 `Authorization` 头发送；服务端只保存令牌摘要。令牌不能放入 URL、SSE 查询参数、模型上下文或普通日志，也不能取得超出所有者权限的范围。高敏感账号管理操作还需独立身份确认，不能仅凭普通业务令牌完成。

浏览器 SSE 沿用登录 Cookie，原生客户端使用认证头。建立连接、断线补取和持续推送均检查身份与数据权限；会话／令牌过期或撤销后停止投递并关闭连接，不能因为连接已建立就永久授权。退出设备只终止该设备访问，已接受的后台任务仍按当前助理权限与任务状态运行，用户可另外取消任务。

## 4. 用户权限与助理权限

| 检查层 | 负责的问题 | 实施位置 |
| --- | --- | --- |
| 身份认证 | 请求由谁发起，凭据是否有效 | `auth` 与 API 中间件 |
| 用户授权 | 是否有权读写该助理、消息、任务、资源或文件 | 业务模块与 `policy` |
| 用户组约束 | 是否分配该模型、工具或沙盒，是否超出成员累计配额 | `auth`、`policy` 与 Runtime 执行入口 |
| 助理授权 | 该助理是否能对指定资源执行该动作、是否超出预算 | 工具、模型和操作执行入口 |

授权默认拒绝，并在每次对象访问与执行时检查。资源查询约束所有者与可见范围，不信任请求中的用户 ID；文件 ID、任务 ID、搜索筛选与 SSE 游标都不能代替授权。客户端隐藏按钮、随机 ID 和登录成功均不足以证明操作被允许。[OWASP 授权建议](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html)

每个账号的私人数据都保存归属并执行检查，管理员身份不绕过其他账号的私人对象权限。权限判断放在业务入口，保证 HTTP、内置工具和后台计划使用一致规则；不能只在路由上做检查。认证存储或授权检查失败时拒绝操作，不降级为匿名访问。

Agent 使用 server 绑定的所有者、助理与任务身份，不持有用户密码或登录令牌。计划到点以保存的助理身份执行，重新检查当前 Grant、资源范围、预算与任务状态；提示词、检索资料或模型输出不能授予权限。权限撤销阻止后续操作，在途操作按其取消和结果核对能力处理。

助理读取账号上传的附件时，必须能通过附件所属任务、助理归属或自身会话取得访问权。会话关联检查只读取消息的 ConversationID 与 AttachmentIDs，并在同一只读事务内对每个会话检查一次归属；结果仅用于本次访问，后续请求重新检查当前权限。

所有者聘请助理时选择模型，视为允许该助理读取并调用该模型。Runtime 在聘请事务中创建对应 Grant，授权绑定所选模型的 `Scope.ModelID` 及其所属 Provider，同一 Provider 下其他模型不自动授权，调用地址跟随 Provider 当前配置，不再另存 Grant 地址白名单，不授予写入、管理或其他资源权限。Grant 可在权限界面撤销；幂等重试与重命名不会恢复已撤销权限。此授权不豁免部署网络策略、模型价格及预算检查。

## 5. 文件、外部请求与程序执行

- **文件与内容**：上传限制大小、类型和配额，使用受控存储标识；访问校验归属及路径边界，处理路径穿越、符号链接和归档解压越界。数据库、配置和备份不置于静态资源目录。下载逐次授权；不可信 HTML、SVG、Markdown 和卡片不能在主站获得任意脚本执行能力，预览采用安全渲染或隔离方式。
- **外部请求**：模型代理、网页读取和外部连接验证协议、目标与实际连接地址，默认允许 `127.0.0.1`，阻断云元数据、其他回环、链路本地及未授权内网目标，并对重定向和 DNS 解析变化重新校验。需要连接本机或局域网模型时，仅由部署者在静态配置 `network.allowed_private_ips` 中放行具体 IP，重启后生效；WebUI 和资源接口均不能修改该策略。连接仍校验资源绑定的 origin，不开放通用内网访问，也不把认证信息转发到新目标。该边界用于防范 SSRF。[OWASP SSRF 防护建议](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)
- **程序执行**：宿主启动命令由可信代码构造，限定可执行操作、参数、工作目录、文件和网络权限；模型生成的脚本只交给已授权的沙盒内固定解释器。server 以非特权身份运行，受控子进程不能继承全部环境密钥或访问 server 私有数据；不能落实所需隔离时拒绝相关操作。
- **容量与超时**：限制请求体、上传、搜索结果、SSE 连接、任务并发、工具输出和执行时间。登录防护在认证前生效，业务配额按主体实施，避免一次请求或一位助理耗尽全局资源。

## 6. 数据、审计与升级

登录账号、会话与访问令牌保存在受保护的数据目录，真实模型和连接凭证由 `credential` 管理并加密保存，主密钥与数据库备份分开保护。日志不记录密码、Cookie、令牌、认证头和完整敏感请求体。

完整模型响应与原始 assistant 消息属于私有执行数据，正常执行即持久化，不依赖调试采集；不记录请求认证头，也不通过聊天、状态查询或普通 SSE 发布。适配器仅回传本协议允许且来源匹配的字段，未知字段的存储不能绕过跨 Provider 隔离。

`audit` 记录登录成功／失败、会话与令牌撤销、权限修改、资源连接变更、敏感数据操作和管理操作，包含主体、动作、目标、时间、结果与请求标识。审计入口只允许所有者访问，并设置保留与容量限制。审计不是防止主机管理员篡改的承诺；主机管理权属于部署信任边界。

备份含敏感数据，按受保护文件管理，不能通过公开静态链接下载。恢复备份后撤销旧登录会话和客户端令牌，避免恢复已撤销凭据；恢复流程重新确认账号控制权。升级保留权限语义并验证迁移，安全修复通过完整 server 发布交付。

## 7. 公网交付验收

公网访问能力属于首版基础要求，至少验证：

1. 未初始化无法抢占账号，匿名访问不能读取业务、搜索结果、附件或 SSE；公网入口经过 HTTPS。
2. 密码、二次验证、过期、远程注销、恢复与令牌撤销生效，旧 SSE 连接停止获得新数据。
3. 修改对象 ID、游标、资源路径或声明身份不能越权，后台计划与工具不能绕过权限撤销。
4. 跨站写入、恶意内容预览、文件越界、SSRF 与命令注入被相应边界阻止。
5. 伪造代理头不能绕过认证或来源限制，认证失败、上传和长连接不能无上限占用资源。
6. 日志、错误、下载及备份路径不泄露凭证，调试入口不暴露，恢复不会重新激活旧会话和令牌。

以上约束由后端实现及集成测试验证；测试不能代替独立安全审计。Agent Shell 只在已配置 Linux 沙盒且具有相应计算权限时开放，隔离条件不足时拒绝执行。Linux 目录工具使用 openat2 禁止链接遍历，其他系统拒绝该工具。部署仍需提供有效 TLS 与正确的可信代理配置。

Shell 已采用 Linux Bubblewrap、seccomp、cgroup v2 与受控网络出口，其他系统暂不开放；部署限制见 [Sandbox 使用说明](../../docs/deployment/sandbox.md)。模型脚本仅在落实隔离后交给固定解释器，宿主启动参数与资源绑定始终由可信代码构造。资源目录直接挂载，写入即时生效且取消不回滚；Shell 网络不继承模型连接的本机访问许可，设备直通不支持。

## 认证记录保留

登录设备查询在分页前排除已撤销、绝对过期及闲置过期会话。失效不依赖回收任务；Runtime 启动后及每小时执行认证回收，每批最多 500 条，积压批次间隔一秒，失败记录错误后下一周期重试。会话撤销满 7 天，或未撤销会话的绝对／闲置到期满 7 天后删除；登录链接在 ExpiresAt 超过 7 天后删除；过期 challenge 可直接删除。删除谓词在写事务内重新求值，保留有效会话及尚可完成的 MFA。审计记录不随凭证记录删除。

WebUI 使用 IndexedDB 原子事务初始化 deviceId 和维护登录租约，支持局域网 HTTP；租约覆盖预登录 CSRF、密码／链接兑换和 MFA，阻止其他标签页同时登录。退出保留 deviceId，关闭页面释放租约，异常退出的租约到期回收。跨标签页身份更新复用 BroadcastChannel；旧身份的迟到 401 不清除已轮换的会话。
