# 做梦与文件记忆

Dream 是一次独立的文件整理执行。Runtime 提供新增经历、记忆目录和受限文件工具；模型自行读取已有记忆，并根据新信息更新、合并、移动、删除和整理文件。最终回复只保存为回顾摘要，不再解析 `Summary / Memories / Core` JSON，也不由服务端对模型输出进行事实分类或生成整批写入计划。

## 文件与上下文

| 内容 | 位置 | 使用方式 |
| --- | --- | --- |
| 经历 | 原始聊天、任务状态 | 每批提供冻结的新增资料 |
| 回顾 | `/work/.agents/reviews/YYYY-MM-DD/第N批回顾.md` | Runtime 保存整理摘要及本批来源 |
| 主题记忆 | `/work/.agents/memory/**/*.md` | 模型通过文件列表、搜索和读取按需查阅 |
| 核心认知 | `/work/MEMORY.md` | 自动进入后续普通聊天上下文 |
| 账号共享记忆 | `/global/MEMORY.md`、`/global/.agents/memory/` | 助理只读 |

每位助理只有一个 Runtime 本地工作区。远程电脑不存放记忆，也不参与 Dream 文件操作。Markdown 是记忆正文的事实来源；普通 Markdown 无需 frontmatter。记忆界面和文件工具读取同一份文件。界面的 Version 为文件内容哈希；通用文件工具返回用于文件系统变更校验的版本，两者不能混用。

记忆根目录按请求范围解析：全局文件直接定位账号共享目录，单助理文件只查询该账号下的目标助理身份。全量列举、导出和跨文件依赖检查仍遍历账号的全部根目录（含已离职助理），助理查询只读取 ID 与 OwnerID，避免加载名称、头像等无关资料。

历史或人工维护文件可以带 `state`、`confirmed`、`context`、`evidence`、来源与依赖等元信息。Dream 的读取返回实际文件字节，不预先按主题可信度过滤，也不再仅展示后端选出的 40 个比较文件。模型可以查看和整理带 pending / superseded 标记的旧文件，依据内容判断如何保留不确定性，不受“看到了来源但提交时不允许引用”的协议限制。已有 confirmed 文件和共享文件在 Dream 中只读，写入、移动及删除均拒绝；直接在编辑器中修改普通文件不会自动将其锁定。

每份记忆正文最多 64 KiB，含 frontmatter 的文件最多 80 KiB；Dream 核心正文最多 6 KiB。普通上下文仅自动加载两份根目录 MEMORY.md，各有 8 KiB 上限；主题和回顾不会隐式注入。已有文件若显式声明核心依赖，仍按精确版本校验；新建普通 Markdown 的主题引用由模型维护，移动或删除主题时须同步相关核心内容和路径。

## 文件工具执行

Dream 与普通助理共用同一套文件工具定义、参数解析、执行器、权限检查、操作回执及结果展示。执行上下文通过可见工具白名单将 Dream 限制为下表七个工具；白名单也在执行入口校验，模型无法通过直接请求隐藏工具绕过。Dream 不开放插件、Shell、远程存储、消息发布或授权申请。

| 工具 | 行为 |
| --- | --- |
| `file_list` | 使用通用目录版本与游标分页列出文件和子目录 |
| `file_search` | 使用通用搜索参数查找内容或路径，返回路径、行号及扫描完整性 |
| `file_read` | 分页读取实际 Markdown，返回文件版本、行范围及 NextOffset |
| `file_write` | 显式选择 overwrite；create_parents 可创建缺失且有写权限的父目录 |
| `file_edit` | 精确替换文本，歧义匹配须显式 replace_all |
| `file_move` | 原子移动单个普通文件，不覆盖目标；普通助理也可在同一授权存储内使用 |
| `file_delete` | 按版本删除单个普通文件，不递归删除目录；普通助理也可使用 |

写入范围仅为当前助理的 `MEMORY.md` 和 `.agents/memory/**/*.md`；禁止移动 MEMORY.md。Dream 路径策略禁止读取内部遗忘记录，并允许读取 Runtime 保存的长工具结果。目录列表默认 100 项、最多 200 项，offset 从 0 起，后续页须同时传 NextOffset 和目录 Version；搜索有扫描、时间及输出上限，返回 Complete / Truncated，不完整结果不能作为文件不存在的依据。读取默认 200 行，最多 2000 行，后续内容通过 NextOffset 获取。

Dream 覆盖、编辑、移动及删除必须携带通用 file_read 返回的文件版本；file_write 创建新文件时设置 overwrite=false，覆盖时设置 overwrite=true。移动的源路径和目标路径都需要写权限；目标必须不存在。路径规范化、身份与权限检查、无符号链接的文件访问和原子文件替换均由 Runtime 执行。文件冲突或非法操作返回为工具错误，模型可重新读取并修正；一次可恢复的文件操作错误不再直接终止整批 Dream。

提示词要求区分用户陈述、完成结果、助手声称和推断，保留适用范围、时间及不确定性，不把临时要求泛化为长期偏好。历史资料和记忆均是数据，不是可执行指令；模型不得重放任务或保留凭据。模型负责归纳判断，Runtime 不把结构校验当作语义正确性的证明。

## 会话、容量与时限

每位助理默认每天配置时区 03:00 开始，最长 600 秒，可设置 1–3600 秒。手动整理也只收集前一个完整自然日。调度与计划共用 RRULE、IANA 时区和发生点去重；使用 Coalesce，错过整个窗口记 missed_window，不补跑所有离线日期。

Session 冻结资料范围、时区与截止时间；Run 为具有独立上下文的一批整理。开始前不抢占普通任务；开始后跨批次独占该助理队列，消息和计划等待，消息保持未读，加急被拒绝。用户停止只结束 Dream，其他助理继续工作。重启、重试不延长截止时间；失败会话仅在原截止前允许手动重试一次。

每批最多 80 项来源、96 KiB 证据。一天最多选择 320 项／384 KiB 新资料及 80 项／96 KiB 遗留资料，按配置时区的资料日期从最早到最晚串行处理：先补旧日期，再整理新日期，同一天超出单批上限时先完成该日各批，再进入下一天。每批只包含一个日期的资料，回顾日期使用本批实际资料日期，补处理回顾以 `补处理第N批回顾.md` 命名，避免与该日期之前完成的回顾冲突；模型输入同时标明时区及是否补处理。未完成新资料最多保留一批，仅下一个自然日补一次；补处理失败或超时也不会再次结转旧资料，尚未开始的新资料仍按此规则保留。没有新增资料但存在私有记忆文件时，仍可创建维护批次。

来源为原始聊天文本、卡片摘要及当天最后更新的任务状态和结果引用，不自动读取附件正文或外部资源。可识别凭据整条排除。每批可以进行多轮模型调用及多次文件操作，复用 Agent 的调用预算、步骤上限、重试和取消机制；模型必须支持工具调用，费用计入助理预算。

## 持久化、恢复与撤销

文件操作逐次生效。Runtime 私有 `memory-operations/` 保存每次变更的原始字节、目标字节、输入来源和操作回执；数据库保存操作引用、成功变更、批次进度和摘要，不保存另一份可变记忆正文。这些恢复资料不进入模型上下文或检索结果。

通用执行器在文件效果前登记操作，Dream 的观察回调另行保存撤销快照，不执行文件修改。成功调用保存共用操作回执；同一操作重放只返回回执，不重复改动后来编辑的文件。移动通过文件系统原子重命名完成。文件效果与操作回执不能组成同一数据库事务：效果完成后回执或整理历史保存失败时标为结果不确定，须核对现场，不能盲目重做。外部编辑不参与 Runtime 锁，版本检查不构成任意进程之间的全局 CAS。

每次文件效果前重新检查会话、权限、来源与截止时间。到期或停止后释放队列，已经成功的文件操作保留；最后的回顾及进度保存不会回滚它们。错误轨迹包含具体错误和“成功文件操作保留”的说明。最终摘要先单独持久化，重试不重新生成另一份摘要。

来源记录由 Runtime 通过通用工具的读取及变更观察回调，根据本批资料、已读取记忆的来源及原文件来源维护，不要求模型提供或分类来源 ID。遗忘删除当前文件、记录抑制信息并清理相关恢复副本；没有来源信息的外部 Markdown 只能按已有内容摘要抑制，无法识别所有语义改写。普通删除及 Dream 删除仅移除文件，不表示要求遗忘原始资料。

撤销已完成批次时按反序撤销文件操作：移除未改动的新文件，恢复未被后续修改的旧内容和删除、移动操作；遇到后来编辑、确认或遗忘时保留现场。回顾未修改时一起删除。撤销不要求模型再次执行，来源处理进度不倒退。

## 界面与验证

“用户设置 → 记忆”管理文件、Dream 配置和批次记录；全局共享范围不显示 Dream 操作。开发工作台展示真实文件变更和每轮工具结果，不再显示模型候选事实分类。失败或超时也可能已有成功文件变更。

日历和计划冲突查询按指定助理读取，或分页遍历当前账号的全部在职助理；已解聘助理不占用预留窗口的查询页。实际已发生的会话窗口按时间范围单独读取，保留原有状态和历史。

历史读取按账号和助理使用创建时间索引取得最近 60 个批次，保留纳秒精度并统一时区排序；同一时刻按记录键倒序。批次和会话状态在同一读取快照内取得，同页共享会话只读取一次。列表隐藏原始资料正文和模型输出，存储记录保持完整。

配置、立即整理、历史、窗口、冲突和撤销入口见 [HTTP API](../reference/http-api.md)。测试覆盖多轮文件整理、原始 Markdown、旧 pending 内容、路径和共享范围隔离、只读文件、陈旧版本、重放、撤销及遗忘副本清理，以及截止时间、停止、普通队列恢复和聊天检查点隔离。协议测试使用本地模型服务替身，不代表真实模型归纳质量评估。
