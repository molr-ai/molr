# 前端交互约定

维护跨主题共用的导航、表单、通知与反馈行为。组件属性和示例见[组件 API](../../../packages/ui/COMPONENTS.md)。

## UI/UX 标准

- 页面文案只保留帮助用户理解当前状态、作出判断或完成操作的信息；不放置对用户无帮助的文案，避免过多、过长的描述性文字。
- 遵循[设计系统](design-system.md)与本文的交互规范，优先复用共享组件及已有页面模式，保持同类页面的操作入口、交互反馈、布局、间距和视觉效果一致。

## 设置中的少量选项

设置页及其弹窗中，固定的两三个简短互斥选项使用共享 `SegmentedControl`，直接展示所有选项；明暗模式使用 `ThemeSelect variant="segmented"`。尺寸与相邻控件一致：常规、主题设置行、用量日历指标和分组使用 `sm`，标准弹窗表单使用 `md`，分别与同尺寸下拉的字号和总高度对齐。保留单选语义、方向键操作和保存时的禁用状态；空间不足时换行以展示完整选项。时区、模型、用户组及插件主题等可扩展列表继续使用 `Select`，布尔开关使用 `Switch`。

用量明细的排序入口位于「总 Token」「费用」「调用」列表头，复用共享 `Table` 的排序按钮和 `aria-sort`。点击列标题按该指标降序排列，并回到第一页；重复点击当前排序列保持不变。用户与管理员用量页共用此行为，排序由服务端在分页前完成。

## 弹层与面板

条件渲染的弹窗和抽屉统一由共享 `ModalPresence` 保留到退出结束，包括设置表单、确认操作、资源授权、计划、记忆、插件和身份验证；关闭时不能提前清空正文。常驻的 Dialog / Drawer 自行保留退出期间的标题与内容。嵌套弹层分别关闭；父级关闭会等待子级退出。聊天侧栏在停靠时沿用占位宽度动画，浮层模式使用相同的弹层退出流程。退出完成后才卸载表单、释放订阅与模态限制并恢复焦点，减少动态效果时立即完成；页面导航时直接清理。

聊天计划面板在同一抽屉内横向切换列表与详情，详情复用独立计划页的渲染与样式。标题栏返回按钮恢复列表及原条目焦点，列表独立保留滚动位置；非当前视图设为 inert 并从无障碍树隐藏。返回过渡期间保留详情，系统或账号启用减少动态效果时直接切换。

默认桌面助理页的两处分隔空隙由共享 `@molr/ui` 的 `PaneSeparator` 提供指针捕获和键盘调整，保持 8px 卡片间距。`useAssistantPaneSizes` 按浏览器来源与账号将列表宽度及各类面板宽度保存到 localStorage；释放指针或键盘调整后保存。列表最小 224px，聊天最小 360px，任务／运行任务面板最小 320px，其他面板最小 360px。ResizeObserver 约束当前布局，窗口缩小时不覆盖保存的偏好；停靠判断继续测量稳定的外层工作区。浮窗与移动端沿用各自布局。`assistant-pane-resize.spec.ts` 覆盖拖动、键盘、刷新恢复、面板独立宽度和窄屏边界。 切换停靠面板时从上一面板的实际宽度过渡到已保存的目标宽度，等宽切换仍有内容过渡；拖动及窗口约束即时应用，减少动态效果设置关闭过渡。动画中再次切换从当前画面续接。

终端无活跃会话时使用与文件、浏览器面板一致的普通标题栏留白和按钮尺寸；只有活跃会话使用紧凑标签栏。

## 导航与账号入口

移动端底部导航只保留业务页面，采用带阴影的圆角矩形悬浮样式，选中项展开文字，其余项仅显示图标，切换动画遵循减少动态效果设置；菜单覆盖在铺满视口的内容上方；各页面滚动内容末尾预留菜单高度、上下间距和设备底部安全区，滚动到底后最后一项完整露出。移动端计划与工作台的状态栏随内容滚动；计划清单空状态填充可用高度，日历保持完整网格高度，状态栏位于内容末尾和菜单退避留白之间；隔离插件 iframe 则缩短自身视口以避免内容被遮挡。进入聊天详情时菜单向下渐隐，返回助理列表时向上渐显；退出开始即停止菜单交互，快速返回可从当前进度反向过渡，系统或账号开启减少动态效果时直接切换。默认主题提供聊天返回按钮。移动端聊天面板打开和返回列表时使用原地透明度过渡，退出完成后卸载；退出期间不可交互，减少动态效果时直接切换，桌面聊天不使用该动画。移动端聘请新助理入口位于搜索按钮右侧，使用仅图标的 ghost 按钮，桌面保留列表底部入口。

默认主题在原 Logo 位置显示用户头像和用户名，点击进入用户设置。用户设置列表按常规、个人资料、安全、通知设置、主题、用量、记忆、个人数据导出、已离职助理、关于排列。管理员设置通过用户设置页头右上角按钮进入，普通成员不显示该按钮；管理员页头可返回用户设置。「管理员设置 → 组件」（`/#/settings/components`）以列表展示浏览器组件的版本、状态、安装进度及安装、更新和修复操作。条目上的「设置」按钮打开共享 Dialog 编辑代理设置，按需加载配置；保存后关闭并提示，取消或 Escape 丢弃草稿并恢复触发按钮焦点；窄屏抽屉完成退出动画后才卸载表单，减少动态效果时立即关闭。「关于」顶部在浏览器中显示服务版本，在桌面 App 中始终显示桌面版本。「版本不一致」和「可更新」标签可以同时出现，与版本号组成同一个可点击入口，共用悬停和键盘焦点。点击任意位置打开版本详情弹窗；窄屏使用底部抽屉。弹窗先展示更新结论和操作，有新版本时显示当前版本到目标版本的变化；管理员根据服务能力只看到一种升级入口：支持在线升级时显示「更新并重启服务」，不支持时显示「手动升级指引」，两者均保留更新说明。手动指引展开后才读取安装信息，提供终端命令或部署指南；读取失败可重试，不将加载或错误状态误判为不支持在线升级。下方以紧凑列表列出桌面 App（如有）、Runtime 和 WebUI 的版本与 commit，并保留带图标的一致性状态。不重复展示推荐版本、最近检查时间或可再次检查时间，冷却只在底部检查按钮显示。浏览器比较 WebUI 与 Runtime，桌面 App 还会纳入桌面版本；所有组件的版本号和 commit 均一致时显示「所有组件版本一致」。有差异时仅列出不一致的组件关系，构建信息不足或服务不可达时不显示一致。打开弹窗时自动读取组件版本与一致性；底部仅保留「立即检查新版本」按钮，禁用时直接显示原因或冷却剩余秒数。WebUI 标注「随服务更新」，不提供独立升级。默认页面保留 Logo 与版本入口、服务信息和 GitHub 入口，不再单独展示版本信息或服务更新分组。 版本详情集中提供检查更新、更新说明、桌面下载、服务升级指引和升级进度。检查更新分别遵守桌面和服务的冷却时间，一方暂时不可检查不影响另一方；查询失败保留上次成功信息并显示错误。桌面独立检查正式版目录，未连接服务时也可在连接管理页检查，开发版本不自动比较。组件版本或构建不同只作提示，不阻止使用；页面与服务不同会提供保存输入后刷新的操作。头像圆点引导进入「关于」，桌面更新和本地服务待更新对桌面用户显示，独立服务的新版本头像提醒仍仅对管理员显示。 桌面附带的 Runtime 比已安装本地服务更新时，顶部显示「版本不一致」和「可更新」。版本详情中的本地服务条目与连接管理页显示「本地服务更新待完成」、当前版本和目标版本。点击「更新并重启本地服务」后确认任务中断提示，才使用附带版本升级；完成后重新连接并更新各组件状态，顶部仍显示桌面版本。用户可以关闭弹窗继续使用旧服务，退出或重启桌面应用不会自动升级。取消保持原状，失败保留提示并可重试，不提供降级更新。Runtime 名称和地址放在关于页独立的「服务信息」分组，位于版本入口下方；设备与登录时间在安全页查看，退出当前设备统一使用「退出登录」，不提供独立的连接设置页。关于页顶部将 Logo 与当前版本并排展示，更新状态通过标签展示，GitHub 入口收于页尾；手机端保持同样的信息顺序，升级指引按需展开。登录后宿主层共享更新状态，每五分钟和恢复可见／连接时读取；关于页激活时按服务端冷却策略检查发布源。页面与服务构建不一致对所有成员显示入口标记；管理员可查看按安装记录生成的固定版本升级指引。不会自动刷新页面或安装更新；完整 Logo 使用 `animation="daily"` 和交互模式，按设备本地时间切换昼夜循环并沿用减少动态效果偏好。个人资料复用已有头像选择器和缩略图处理；桌面侧栏、手机顶部和管理员用户列表均显示账号保存的头像。

## 共享组件与资料同步

WebUI 主导航与助理列表区域统一使用 `user-select: none`（含 WebKit 前缀），避免页面全选和拖选带入导航文字、助理名称及消息预览；规则同时适用于桌面侧栏和移动布局。区域内的输入框与可编辑内容显式恢复 `user-select: text`，保留搜索框选字与 Ctrl/Cmd+A；聊天正文和详情内容保持可选择。

聊天历史顶部以浅色分隔线和居中文字按钮加载更早消息，线条沿用列表分隔线的颜色。距离滚动底部超过一屏消息区高度（至少 600px）时，消息区底部悬浮显示「返回底部」，有未读消息时文案显示为「有新消息」，没有未读消息时显示为「返回底部」，不占用输入区或改变滚动高度；返回时清除搜索定位和待恢复的分页滚动位置，立即滚动到底部并恢复最新消息跟随。滚动、消息更新和消息区尺寸变化时重新判断按钮显隐。

桌面主侧栏按钮统一为 44px，菜单按钮默认背景透明，悬停与选中时显示圆角矩形底色；搜索按钮与账号头像保持圆形，头像与按钮同尺寸。Logo 保留原样，移动端继续使用底部导航布局。

桌面 App 宽屏布局的主导航栏空白区域使用原生窗口拖拽区域，按钮显式设置为 `no-drag`，保留点击与悬停提示。样式限定在 `.app-frame` 内的非移动布局，浏览器和窄屏底部导航保持原有交互；模态弹层由全窗口的 `no-drag` 层承接操作。App 内的 Tooltip 等共享浮层显式使用 `app-region: no-drag`，其透明 `::backdrop` 使用 `app-region: initial`，避免继承侧栏拖拽属性后将全窗口纳入拖拽区域，同时保留标题栏和侧栏空白处的拖拽。`app-tooltip.spec.ts` 检查浮层及背景的拖拽属性、提示显示后的导航点击和键盘操作；原生 macOS 点击与窗口拖拽仍需桌面验收。

保存头像或显示名称后，账号资料在后台同步到当前页面及同源标签页，保留工作区与连接；登录、退出和身份切换仍重新初始化会话。

侧栏等位置的共享 Tooltip 在窗口失焦或页面隐藏时关闭并清除延迟计时；切回页面恢复焦点不触发提示，后续键盘导航或鼠标移动悬停仍正常显示。此行为由共享组件处理，宿主无需清除按钮焦点。 Tooltip 共同使用一组窗口活动监听；键盘与指针按下只推进输入版本，关闭中的实例不会逐个执行输入回调。最后一个实例卸载时移除共享监听。

## 微信连接与二维码

聊天页右上角「… → 切换聊天入口」打开独立的连接管理弹窗；绑定后底部使用共享 `ChatComposer.lock` 保留输入框轮廓，框内仅展示微信发送与解绑恢复输入的说明；「管理微信连接」打开同一弹窗，已连接状态在该弹窗中使用成功 `Alert`（`tone="positive"`），需要重新扫码等异常连接状态使用警告 `Alert` 展示；重新扫码的主动提醒沿用通用服务端通知，在聊天顶部队列中展示，助理信息页不再包含连接操作。

微信连接二维码使用共享 `--color-qr-foreground` / `--color-qr-background` token，所有配色及明暗模式保持深色模块和浅色背景，保留四模块静区。二维码在浏览器本地编码，不向第三方图像服务传递登录内容。

## 系统提醒与展示边界

连接横幅与 Logo 表达实时订阅状态。超过 20 秒未完成握手或终止性错误后，显示「实时更新暂不可用，正在自动重试」并继续退避重试；离线时暂停，恢复在线、前台可见、焦点或普通 API 成功可唤醒重连。自动唤醒合并并节流，不打断已有连接。仅收到 SSE `ready` 后收起提示、播放恢复动效并刷新查询，API 成功不直接标记实时更新恢复；认证失效停止重试并进入现有登录流程。

当前聊天在页面可见、窗口有焦点且停留于消息底部时自动标记已读。并排显示的侧面板不暂停已读；弹窗及覆盖聊天的抽屉暂停已读，关闭、移除或切换为并排侧面板后重新检查。后台页面、上翻历史和搜索定位期间不自动清除未读。新消息主动提醒沿用相同的面板遮挡判断。

宿主层 `notifications/AssistantNotifications.tsx` 提供共享的聊天提醒队列。微信投递与连接异常、助理持续受阻、授权请求、计划待交接、任务及后台执行失败由 Runtime 生成提醒；聊天横幅和主动提醒共用通知 ID。客户端不提供独立通知页或通知历史列表，长期信息由原聊天、审批、计划和任务页面管理。

聊天一次展示一条，按发生顺序选择下一条；新提醒不替换当前条。关闭仅确认当前 ID，服务端成功后推进；失败保留当前条及错误反馈。关闭后键盘焦点移至下一条的关闭按钮。提醒区无内部滚动条，仍需检查短屏输入及渠道操作可见。短暂模型重试提示只在没有服务端提醒时显示。已读不隐藏待处理横幅；源问题恢复后服务端解决提醒。

Toast 自动消失、桌面通知被系统收起不自动标记已读或忽略。后台执行失败的聊天横幅和 Toast 仅在 Runtime 支持且用户已设置显示开发工作台时显示「在开发工作台中查看」，按通知来源事件定位执行；桌面通知使用相同目标，未开启时无跳转。未采集或已过期的执行在工作台明确提示。查看其他提醒直接进入对应业务页面；聊天及 Toast 的查看操作标记已读。桌面通知、提示音与当前浏览器设置沿用现有设备策略，未开启主动提醒仍可查看聊天内的待处理提醒。助理新消息继续使用会话序号与已读状态；授权申请卡片的主动提醒由通知记录负责，避免重复弹出。

错误和信息提示原则上统一使用共享 Toast；通用请求和操作失败通过 `useErrorToast` 展示，普通操作结果与短暂信息使用 `useToast`，不占用页面布局。特殊情况可以在业务区域展示：表单校验错误放在对应字段附近；持续连接状态、终端输入暂停等影响当前操作的状态保留在对应控件旁；需要保留和比较的连接测试结果、做梦冲突沿用业务区域。例外须有明确的上下文或持续可见需求，不能仅为实现方便使用页面内 Alert。

关闭反馈不清除连接测试结果。短暂模型重试进度、本机断网、隐私说明和表单校验不写成持久通知。`DismissibleAlert` 仅用于上述需要就地展示且允许关闭的例外提示。普通错误按调用点区分，限流与服务不可用在当前会话去重；关闭或自动消失后，后台轮询不会反复弹出。主动操作可重新提示，错误恢复、来源卸载或退出会话时清理提示；连接横幅出现时抑制服务不可用 Toast。带重试的错误常驻，限流重试遵守 Retry-After，倒计时到期或提示关闭后停止计时。

## 安全设置的信息层级

安全页沿用其他设置页的平面列表与细分隔线，按“登录与验证、登录设备、登录链接”排列。修改密码放在对应设置行，退出当前设备放在页尾。分组标题和设置项使用共享小号正文尺度，通过字重区分；说明、日期与历史入口统一使用辅助文字尺度。设备与链接名称、状态和操作分别布局，时间使用成组的标签／值；窄屏允许换行，操作保持右对齐。登录链接历史默认折叠。

## 资源工具目录

MCP 工具目录复用内置工具的搜索栏、筛选按钮、紧凑分组列表和详情抽屉，以服务连接分组，筛选计数随搜索更新。分组标题旁提供连接管理入口；工具详情提供启用和助理授权，连接详情提供配置与调用记录。插件显示开关不影响 MCP，颜色复用共享语义 token。

资源工具页使用紧凑分组列表，搜索与分类共同筛选目录，分类计数随搜索结果更新。分组定义与助理信息共用 `tool-groups.ts`；空分组不显示，插件工具遵循账号插件可见性设置。共享 `SearchField` 和 `Drawer` 提供清除搜索、键盘操作、详情关闭及焦点恢复；详情顶部集中展示名称、标识、简述、执行影响和所需操作，下方用共享 `Tabs` 切换模型工具描述原文与参数结构；原文直接读取目录的 `Description`，以纯文本保留内容，长描述及参数自动换行，共用抽屉滚动区。读取／写入影响通过图标和文字区分，使用语义颜色适配各主题。


Skills 总览复用同一搜索栏、来源筛选按钮、紧凑分组列表和详情抽屉，使用共享语义颜色与列表反馈。助理筛选和来源、关键词共同生效；同名专属条目显示所属助理。详情以纯文本展示 `SKILL.md`，沿用抽屉唯一滚动区与长文本换行，关闭后恢复列表焦点和筛选。

## 模型页操作入口

资源页模型标签的页头只保留更多菜单，集中提供「连接提供商」和「默认模型」入口，管理员另可使用「刷新模型价格配置」手动检查部署价表；刷新期间禁用该项，完成后重载价格，结果与失败使用共享 Toast。默认模型在弹窗中通过共享 `ModelSelect` 管理当前账号的默认模型，沿用即时设置保存流程：读取最新设置、仅替换 `DefaultModelID`、校验版本，保存期间禁用控件，失败恢复原值。用户设置不再提供独立的偏好子页面。助理显式选择的模型优先于账号默认模型。

连接提供商弹窗与首次引导共用本机模型发现区域，仅当检测成功且至少一个服务的 `State=ready`、`Models` 非空时显示；首次检测期间、检测失败或无可用模型时不显示标题、占位说明或重新检测按钮。

点击提供商打开模型列表抽屉，点击模型列表项向左滑入同一抽屉的配置页，标题栏显示返回按钮。保存、取消或返回后恢复列表与滚动位置；关闭抽屉恢复提供商入口焦点。添加模型使用相同配置页，可从抽屉或提供商更多菜单进入。切换页面时隐藏页不可交互，减少动态效果设置关闭滑动过渡。

## 个人数据导出

用户设置的「个人数据导出」页直接说明默认包含的记忆、助理与任务计划、账号设置与资源记录、做梦记录，并介绍可选的聊天记录和附件与交付物。默认勾选聊天记录，不勾选附件与交付物；点击「导出数据」在弹窗中选择范围，生成后在本页下载 ZIP。范围说明沿用设置页描述和分组列表样式。

## 浏览器浮窗

浏览器与终端的无会话状态共用 `SessionStart`，统一图标、标题、说明、执行选项与启动操作的尺度和间距，内容区独立滚动。终端仅在已有会话时显示标题栏的新建按钮；无会话时保留单一主按钮。加载、能力不可用和启动进度就地展示，普通请求失败继续使用 Toast。选中 Full Access 时，在执行选项下方使用共享警告 `Alert` 持续展示服务账户权限及隔离、配额边界；切回沙盒模式后移除，不提供单独关闭操作。

启动浏览器或终端时，只有一个可用计算资源会自动选中并隐藏资源选择框；多个资源时可以选择。只有普通授权时使用沙盒，只有 Full Access 授权时使用 Full Access 并显示权限范围警告；两种授权都可用时默认沙盒，可切换执行模式。Full Access 使用服务账户权限，不受 Molr 文件、网络隔离和资源配额限制，浏览器仍启用 Chromium 自身沙盒。选择只影响新会话；浏览器更换资源或模式前需要先结束当前会话，网站登录状态继续保留。已有授权失效时需重新选择，运行中撤权会结束相应任务。

桌面浏览器默认使用非模态浮窗，通过共享 Drawer 的非模态模式保留同一 DOM、串流连接与控制状态；浮窗打开时 ChatSidePanel 不保留侧栏占位，聊天保持可交互。停靠模式沿用可用空间判断，手机端使用底部抽屉。位置与尺寸保存在当前页面内存，关闭面板后重开可恢复。

`useBrowserView` 处理拖动、等比例缩放、方向键微调及视口边界约束。网页画面保持远端 1280×800 的比例，工具栏不缩放；尺寸计算扣除实际工具栏高度，辅助输入展开和窗口缩小时重新约束边界。指针输入按实际显示比例映射回远端坐标。`browser-panel.spec.ts` 覆盖浮窗与停靠切换、聊天交互、画面比例、坐标映射、边界及手机抽屉。

底栏仅保留连接状态及紧邻右侧的辅助输入、结束会话按钮。右下角缩放区域保持透明，无图标和悬停底色；鼠标显示缩放指针，键盘聚焦时保留焦点轮廓。

## 工作区资源管理器

聊天页的文件入口与浏览器共用单面板选择机制。`WorkspaceFiles` 使用共享 Drawer 和 ModalPresence，桌面浮窗非模态，停靠时由 ChatSidePanel 保留宽度，手机使用底部抽屉。`useFloatingPanel` 管理自由宽高、拖动、键盘微调及视口约束；浏览器仍使用独立的画面比例约束。浮窗／停靠切换保留同一组件与草稿。页面内按助理保存目录、选择、滚动、排序和隐藏文件偏好。

面板宽度超过 640px 时并排展示当前目录与预览，否则使用列表／详情两级视图。新建、重命名、移动、删除和上传冲突均使用共享弹层。编辑冲突保留草稿，允许重新加载或另存为；普通请求失败沿用错误 Toast。应用导航与面板切换通过可取消的 `molr:before-navigation` 事件保护未保存修改，浏览器关闭使用 beforeunload，页面内存另保留草稿以应对原生历史导航。

`workspace-explorer.spec.ts` 使用真实 Runtime 验证桌面与手机的文件操作、上传冲突、版本冲突和浮窗几何。配色与截图验收记录保存于本地内部目录。

## 聊天指令

WebUI 在发送普通消息之前解析 `/compress`（`/压缩`）与 `/permission approve|reject`（`/权限审批 同意|拒绝`），不将已识别指令提交给模型。审批使用当前助理的待审批申请：无参数选择接口按创建时间倒序返回的最新一条，完整 ID 精确选择一条，`all`／`全部` 固定选择发送时已有的全部待审批申请。执行前重新读取列表，核对所选 ID 与版本；无参数还需最新 ID 一致。批量操作预检查所有申请，再逐条通过原有 resolve API 按预期版本提交；失败停止并显示已处理数量，不回滚先前成功项，也不追加新到申请。权限卡片显示可复制的申请 ID。批准保留原申请及组合项的资源、操作、范围、额度、临时额度和有效期；缺少资源或计算／网络额度时提示使用审批表单。服务端继续负责所有权、申请状态、版本和授权范围校验。

共享 `ChatComposerCommand.aliases` 声明可补全的别名；匹配中文别名时补全中文文本，多词指令支持空格筛选。菜单只负责补全，业务层负责解析和执行。

## 沙盒计算状态

总览、连接测试和计算分区共用受控计算状态判断，依次处理已断开、已关闭、离线、命令执行未启用、受控计算可用或不可用。受控计算依据 `Capabilities.Shell`，完全访问单独依据 `Capabilities.FullAccess`，不得用后者把受控计算标为可用。离线时不把快照中的能力展示为当前可用；未就绪时隐藏可申请额度并展示原因与恢复步骤。计算资源卡片及新增普通授权入口与能力一致，保留已有授权的查看和撤销。空状态按存储、网络、计算分别提供指引。完全访问保持独立分区，描述存储、计算与网络的完整范围。
