# 开发环境

本文维护开发机器目录、共享下载缓存和开发服务约定。任务隔离见[协作流程](workflow.md)，验收实例与交付要求见[验收规范](acceptance.md)。

## 开发机器目录与共享下载缓存

每台开发机器（包括通过 SSH 使用的远程机器）推荐以 `~/workspace/molr` 作为主工作目录，以 `~/workspace/molr/.cache` 作为固定缓存根目录。`~` 指实际执行命令的机器上当前用户的主目录。已有仓库位于其他路径时，可以继续使用原工作目录，不为统一路径搬迁正在运行的服务；可复用下载仍集中到上述固定缓存根目录。

| 内容 | 固定目录（相对于 `~/workspace/molr/.cache`） |
| --- | --- |
| npm 下载缓存 | `npm/` |
| Go 模块与自动下载的 Go 工具链 | `go-mod/` |
| Electron 二进制下载缓存 | `electron/` |
| Electron Builder 下载缓存 | `electron-builder/` |
| Playwright 浏览器 | `ms-playwright/` |
| 其他工具链、安装包和可复用下载文件 | `downloads/<工具>/<版本>/<系统>-<架构>/` |
| 需要解压后复用的独立工具链 | `tools/<工具>/<版本>/<系统>-<架构>/` |

- 所有任务、worktree 和重复验收均复用当前机器的固定下载缓存。通过工具支持的缓存选项或环境变量传入展开后的绝对路径，不使用随当前目录变化的相对缓存路径。例如 npm 使用 `npm_config_cache`，Go 使用 `GOMODCACHE`，Electron 使用 `electron_config_cache`，Playwright 使用 `PLAYWRIGHT_BROWSERS_PATH`；安装和运行时使用相同设置。配置仅作用于相关命令或开发会话，不擅自改写用户全局配置。
- 下载前先检查固定目录和该工具已有的默认缓存。已有文件匹配所需版本、系统、架构及工具提供的完整性校验时，优先复用，并将可复用文件归入固定目录；缺失或校验失败时才重新下载。使用工具自身的缓存锁和完整性校验；手动下载先写临时文件，校验后原子替换，避免其他任务读到未完成的文件。同一下载进行中时等待或复用该任务，不再启动重复下载。
- 共享范围包括下载包、工具管理的模块缓存及按版本安装的公共工具。`node_modules`、应用构建产物、编译缓存、测试输出和验收实例数据仍归各 worktree 所有；不得通过共用可写安装目录破坏任务隔离。数据库、凭证、登录会话和用户资料不进入共享下载缓存。
- 缓存独立于任务生命周期，清理 worktree 或临时验收目录时保留共享下载。需要清理缓存时，仅处理已确认损坏或不再使用的条目，不清空其他任务可能正在使用的目录。

## 开发与预览服务

- 本地日常开发只使用开发服务。主工作区常驻 WebUI、官网、UI Design 各一个实例，不同时运行同一应用的构建预览或重复开发实例；官网首页和文档共用同一个官网服务。
- 以下默认端口适用于主工作目录；独立 worktree 按任务需要使用各自分配的空闲端口，每个涉及的前端应用同样只运行一个开发服务。下文的“仓库根目录”指当前任务 worktree 的根目录，主分支服务则使用主工作目录。
- 启动前核对进程所属目录、命令和监听端口。已有符合要求的服务就复用；切换启动方式时停止同一工作区的旧实例，不通过另开端口保留重复服务。
- 开发服务默认监听 `0.0.0.0`，允许同一局域网内的设备访问。除非用户明确要求，否则不要绑定 `127.0.0.1` 或 `localhost`。

| 应用 | 仓库根目录启动命令 | 主工作区端口 |
| --- | --- | --- |
| WebUI | `npm run dev`（或 `npm run dev:webui`） | `5191` |
| 官网及文档 | `VITE_SITE_MODE=live npm run dev:website` | `5189` |
| UI Design | `npm run dev:design` | `5188` |

- 官网本地开发和验收在启动命令中显式带上 `VITE_SITE_MODE=live`。未设置该变量或留空时，程序仍使用 `coming-soon`；检查其他模式时调整同一实例的环境变量并重启，不另起常驻服务。
- 现有 `build`、`preview` 等命令保留，构建预览仅用于明确需要验证产物的临时检查，检查完成后停止，不作为日常开发或合并后的常驻服务。官网预览沿用构建产物中的模式。
- 启动或调整后确认实际监听地址、端口、开发模式和实例数量，并提供可用的局域网访问地址 `http://<本机局域网 IP>:<端口>`。
