本目录维护贡献者与编码代理共同遵守的开发流程。[AGENTS.md](../../../AGENTS.md) 是必读索引；所引用规范具有相同约束力。产品实现文档按主题从[开发文档索引](../README.md)进入，正式部署见[管理员指南](../../admin/README.md)。

## 设计与交付原则

把复杂留给自己，把简单留给用户。设计、实现和交付都应以减少用户的理解成本、配置项和操作步骤为目标，并遵循 KISS 原则。

- 通过合理默认值、自动初始化和自动化流程承接必要的复杂性，让常见场景用最少步骤完成。
- 安装、部署和更新提供可直接执行的命令或完整配置；能够由程序完成的准备工作由程序完成，避免让用户手动拼接命令或了解内部实现。
- 按需提供高级配置；界面与文档优先呈现用户完成当前任务所需的信息，并清楚说明需要用户决定的选项及其影响。
- 验收时从首次使用者的角度走通完整流程，持续消除不必要的步骤、重复输入和额外依赖。
