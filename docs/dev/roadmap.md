# 路线图

本页维护未来功能，按近期要做、远期计划和尚未决定分组；当前可用能力见[用户指南](../user/README.md)。近期项同步到根 README，远期项尚未排期，待定项仍需决定是否投入开发。具体发布日期随实现和验收确定。

## 近期要做

### 多助理群聊

当前会话绑定一位助理，其他助理不能读取或向该会话发布消息。群聊将扩展这一参与关系，见[会话模型](../../runtime/internal/im/conversation/api.go)与[参与者校验](../../runtime/internal/im/conversation/service.go)。

- **新增范围**：用户在 WebUI 创建群聊、加入或移除自己的助理，通过 @ 指定回复者；参与者读取群内共享消息和明确分享的交付物，消息标明发送助理。
- **完成标准**：两位及以上助理可在同一会话按指定对象回复；移除成员后停止其后续读取与发言；各助理继续遵守自己的资源授权和预算。
- **范围边界**：首期面向同一账号下的助理。私聊历史、私有记忆和未分享文件不因入群而开放；跨用户群聊、外部聊天平台群组和自动任务委派不包含在首期范围内。

## 远期计划

### 手机 App

当前手机可通过浏览器使用 WebUI，独立手机客户端尚未发布。

- **新增范围**：提供独立安装的手机客户端，连接 Molr 服务，支持聊天、附件收发、计划查看和权限审批，适配触屏操作。
- **完成标准**：在支持的手机系统和实机上验证安装、登录、核心操作及网络切换后的重连；与其他客户端使用同一账号和服务时，数据保持一致。
- **范围边界**：支持的系统和分发方式在设计阶段确定；后台推送需结合移动系统限制另行设计，不以 App 安装完成作为推送已可用的依据。

### 助理间任务委派

当前已有[计划前置依赖与交接](../user/guides/plans.md)，助理的[计划工具](../../runtime/internal/agent/tools/plans.go)限定操作分配给自己的计划。本项增加执行过程中的委派与结果回收。

- **新增范围**：在用户允许的协作范围内，一位助理可向另一位助理委派子任务、传递必要资料、等待结果并汇总；用户可查看父子任务、责任助理、状态和费用。
- **完成标准**：可以完成一次拆分、委派、执行、回传和汇总；子任务失败、取消或等待授权时，父任务正确反映状态；限制委派深度和并发，避免循环委派。
- **范围边界**：委派不复制发起者的权限或私有记忆，接收者按自己的授权和预算执行；共享内容需有明确范围。

### 关闭网页后的推送通知

浏览器已有页面内提醒和桌面通知，但关闭页面后暂不推送。桌面 App 的原生通知需要应用保持运行并连接服务，见[通知设置](../user/guides/settings.md)。

- **新增范围**：用户订阅设备后，即使关闭 WebUI 页面，也能收到任务完成、失败或待授权提醒；点击通知进入对应任务或审批位置。
- **完成标准**：在支持的浏览器和设备上验证关闭页面后的投递、点击跳转、去重、取消订阅及退出账号后的停用；用户可控制通知类型与内容预览。
- **范围边界**：先确定自托管环境的推送接入方式、所需网络条件和支持平台；涉及外部推送服务时明确发送的数据范围。

### 智能家居与设备控制

- **新增范围**：支持接入 Home Assistant、米家、摄像头、拓竹（Bambu Lab）3D 打印机等平台与设备，让助理在用户授权下查询设备状态、执行控制操作并参与自动化任务；涵盖家居设备控制、摄像头画面查看与可用控制、打印状态查询与打印任务控制。
- **完成标准**：在各类接入的真实设备上验证连接、状态读取、控制执行及结果反馈；设备离线、操作失败和撤销授权时正确反映状态并停止未获授权的操作。
- **范围边界**：具体型号、接入协议和可用操作随各项集成确定；摄像头画面访问与设备控制分别授权，打印启动等会触发实体设备动作的操作遵守用户审批设置。

## 尚未决定

### 多入口同时聊天

当前同一助理的[聊天入口互斥](../../runtime/internal/app/chat_channels.go)，绑定外部渠道后 WebUI 保留查看和管理能力，聊天输入转到所选渠道。

- **候选范围**：同一助理同时接受 WebUI 和外部渠道消息，延续同一段对话；支持回复原入口或用户指定的入口。
- **待决定的问题**：消息是否同步到所有入口、不同平台身份如何关联、哪些历史与附件可跨入口显示，以及并发输入时如何避免重复回复。
- **纳入计划的条件**：明确需要同时使用多个入口的场景，并确定身份关联、投递规则和隐私边界后，再决定是否开发及排期。

## 维护方式

功能完成并验收后移入相应使用文档，从路线图移除；调整近期范围时同步更新中英文 README。新增候选项先核对当前实现，写明新增范围，避免把已有能力重复列入计划。
