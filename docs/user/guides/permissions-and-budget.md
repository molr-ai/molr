# 权限与预算

管理员连接资源并通过用户组分配可用范围；你在这个范围内给自己的助理授权动作、目录、模型和额度。

## 选择模型

在「资源 → 模型 → 右上角更多 → 默认模型」设置当前账号的默认模型，也可以选择「无」。新聘请助理时优先预选该模型；助理单独指定的模型优先。聘请时只授权所选模型，不覆盖同一提供商的其他模型。

管理员接入模型的步骤见[连接与管理模型](../../admin/resources/models.md)。

## 浏览工具

在「资源 → 工具」按聊天、文件、计划等用途浏览工具，或搜索名称、工具标识与功能说明。分类数量随搜索更新；没有匹配结果时可清除筛选。点击工具打开详情，查看功能简述、执行影响和所需操作。详情中的「模型工具描述」保留提供给模型的完整原文，可切换到「参数结构」查看输入参数定义。具体可用范围由助理权限决定，在助理信息中查看和配置。

## Full Access 权限

授权表单先选择资源类型「模型／工具／沙盒」。选择沙盒后，再选择具体沙盒和权限类型「存储／计算／网络／完全访问」。存储继续选择存储资源和路径，网络继续选择网络范围，计算填写计算额度。部署已允许 Full Access 时，可以选择「完全访问」。普通用户组还需管理员明确允许授予此权限。它允许助理显式选择不隔离、无资源限额的文件和命令调用；未选择的调用继续遵循原权限。同一资源可以同时保留普通计算授权和 Full Access 授权，分别设置有效期、修改和撤销。

选择完全访问后不填写配额，也不需要另授目录和网络权限。详情见 [Full Access 部署与执行语义](../../admin/sandbox/linux.md#按需授予-full-access)。

## 助理请求授权

缺少权限时，助理会在聊天中发送申请卡片，说明用途、资源、动作、目录范围、额度和有效期。可申请范围由管理员已连接并分配的资源决定；缺少资源时先联系管理员。

点击「查看并授权」打开预填表单，核对并按需修改范围、额度和到期时间，再点击「批准授权」。点击「拒绝」不会增加权限。组合申请需要全部有效才会提交；同一张卡片最多组合八项计算、网络或存储申请。

卡片保留申请原文、最终批准内容和处理状态，刷新或换设备后仍可查看。批准后助理按最终有效授权继续，拒绝后会收到明确结果；已经手动停止、暂停或结束的任务不会因处理旧申请自动恢复。

助理权限页保留最近最多 200 项申请，待处理优先。批准记录表示曾经批准，实际访问仍取决于授权是否有效及资源是否在线；沙盒离线时应恢复资源连接。

## 修改与撤销

授权可以限定动作、资料范围及有效期。断开资源、撤销或到期会限制后续执行，相关运行可能被停止；已经完成的写入或已经发出的数据无法通过撤权撤回。

Shell 读写挂载要求同时具有读取和写入权限，并会直接修改原目录；取消不回滚。仅写权限可以由支持该操作的文件工具使用，不自动获得 Shell 读取权限。

模型和外部服务凭证由管理员在资源配置中管理，不在普通聊天中填写密钥。提供商被删除后，受影响的助理需要重新选择可用模型。

## 助理预算

在聘请助理或“助理信息 → 概览”中设置金额、币种及每日／每周重置周期。所有聊天、后台和定时执行共享所属助理额度；没有全局默认预算或任务独立预算。

模型调用前会占用预留费用，取得实际费用后结算。本地调用结束时自动结束费用预留和并发占用；费用未知时保留历史记录，不按零费用结算，也不要求手动处理。运行中的调用跨周期仍占用额度，结束后费用归入调用原所属周期。Runtime 重启会先补结算已有回执，再清理上一进程遗留的调用占用；未知调用不会因此自动重试。修改预算、修订任务或周期重置不会删除历史账单。

预算用于个人使用时防止意外大量消费，依据服务配置的模型价格及返回用量执行，不等于供应商账号的最终账单或支付限额。中断请求可能已在供应商侧收费但未计入本地消费；后续取得实际费用时会补记，超过预算后阻止新调用。价格未知时需要补充配置，不按免费处理。手动价格与币种应按实际服务核对。

常规设置的币种只影响新输入默认值和展示，编辑已有金额时保留原币种和精度。金额展示统一按偏好币种换算，多币种费用显示一个合计，不并列原币金额；固定两位小数，不足一分向上取整，换算金额带 `≈`。暂时无法换算时显示 `—`。换算使用带版本的参考汇率，不是实时交易报价。重置时间按账号时区计算，设置时区后留意页面显示的下次重置时间。

## 数据发送范围

使用远程模型时，提交给模型的资料会发送到该服务；本地部署 Runtime 并不能消除这类传输。允许 Shell 读取资料并连接某个目标，也意味着脚本可以向获准目标发送可读数据。

网络目标授权限制可连接的主机和端口，不等同于网站内某项业务动作授权。HTTPS 隧道不承诺检查加密内容中的路径、请求正文或具体动作。

## 计算、网络与工作区额度

计算与网络的额度在助理授权中设置，也可由助理通过聊天卡片申请。用户可以修改申请值后批准；同一张卡片最多组合八项计算、网络或存储申请，任一项验证失败均不创建部分授权。组合审批先显示每项资源及额度摘要，展开后可修改；顶部统一设置授权时间，整组权限共用此有效期，批准后的卡片也只显示一个授权时间。临时额度另有恢复基础额度的时间，该时间不得晚于授权到期。需要提额时编辑已有授权。

| 类型 | 授权属性 | 用量口径 |
| --- | --- | --- |
| 计算 | CPU 算力、内存、进程／线程数 | 同一助理在同一沙盒中的执行共享 |
| 计算 | 单次最长运行、内存临时盘 `/tmp` | 分别限制每个执行；不限运行时长须显式批准 |
| 网络 | 双向流量、周期、时区 | 按助理与实际网络来源跨执行累计；支持累计、每天、每周、每月 |
| 网络 | 并发连接 | 同一网络来源的所有执行共享 TCP 连接与 UDP 会话名额 |
| 工作区 | 容量、单文件大小、文件和目录数量 | 同一助理在此沙盒中的 `/work`，所有写入入口共用文件系统额度 |

网络页展示访问范围，流量和连接额度在助理的网络授权中设置与查看；计算页显示可申请的计算能力范围。权限页显示实际获批额度及用量。CPU 的 1 核算力等于原来的 100%。授权有效期与单次最长运行时间分别设置。

周期按授权记录中的时区计算，重启或重新执行不清零；修改额度保留已用量。已有周期与时区不能通过编辑更换，避免重复领取额度。临时额度保留基础值，到期恢复；当期临时追加可将临时流量上限提高到基础额度加追加量，并把到期设为当前周期结束。已用量超过恢复后的额度时停止继续消耗，不删除历史账单。

命令默认自动使用该助理在当前沙盒内已获批、有效且仍有部署目标的网络权限。模型不必传入网络资源 ID；没有授权时仍可执行离线命令。流量耗尽不能靠重开命令绕过。网络提额可用于运行中的任务；网络授权到期或撤销限制其连接，不因其他未使用网络权限的到期而停止计算。计算授权修改会停止受影响的任务，新执行采用批准后的额度；已结束的命令不会自动重跑。

工作区容量需要部署启用并预配置 Linux 文件系统项目硬配额。未配置的工作区明确显示不支持容量额度，不能仅修改界面数字宣称已扩容。达到容量或临时扩容到期不会删除文件，仍可读取和清理；单文件上限适用于 Shell 与文件写入工具。外部共享目录不计入某个助理的工作区额度。上传附件库限制与工作区容量分别管理。

`/tmp` 是计算授权中的内存临时盘（`temp_bytes`），每次执行独立，写入按实际占用计入计算内存，执行结束后清空。64 MiB 是可调整的申请示例值，不是持久存储容量；需要保留的文件应写入 `/work`，其容量由存储授权管理。

沙盒的「存储」页按工作区和已连接目录显示可使用的容量上限及磁盘剩余空间。工作区上限受用户组存储额度与所在磁盘容量限制；同一磁盘上的目录共享空间，不能把各目录容量相加。工作区显示的磁盘容量扣除部署要求保留的空间。「计算」页显示部署／用户组上限与机器 CPU、内存和进程容量中的较小值；未配置限制时显示机器容量，检测失败时显示未知。多个 GPU 逐行显示型号、显存和必要的设备标识。 每块 GPU 下方分别显示整卡计算利用率和显存占用快照，与 CPU 一样在重新检查时更新；无法读取的指标显示暂不可用。内置工作区的默认名称按界面语言显示为「本地工作区」，自定义资源名称保持原样。 存储、CPU 和内存数值下方的细进度条显示本次读取的占用快照，点击「重新检查」可刷新，不持续轮询。CPU／内存按整机容量、存储按目录所在整盘容量计算占用比例；该比例不是助理授权配额的使用率。检测失败时显示占用信息暂不可用。

## GPU 授权

部署已开放 GPU 且用户组允许时，可在助理计算权限中选择设备；卡片显示型号与显存，同型号设备附带短标识。普通命令使用当前计算权限中批准的设备，临时配置到期后恢复基础授权。修改计算授权会停止受影响任务，新执行使用更新后的设备范围。

GPU 为共享访问，不预留显存或保证算力。不可用时不会自动改用 CPU 或 Full Access；核对原因并联系部署者，或移除 GPU 授权后继续普通计算。

## MCP 工具权限

管理员连接并启用 MCP 工具后，可在助理权限中选择该工具并授予执行权限。普通成员需先由用户组开放连接和工具。工具定义变化后旧授权失效，需要重新授权；配置说明见 [MCP 工具](../../admin/resources/mcp.md)。
