# 助理与聊天

从助理列表选择一位助理，交代任务、发送附件并查看回复。首次使用见[快速开始](../getting-started.md)。

## 持续聊天与助理管理

每位助理有自己的持续聊天、执行状态和资源权限。可以按名称搜索、置顶、重命名、编辑模型与预算。列表保留置顶优先，置顶与未置顶助理各自按最后一条消息的时间倒序排列，暂无消息的助理排在各自末尾；新消息到来时自动更新顺序。当前真实 WebUI 不提供会话分组操作。

全新聘请助理后，系统会自动触发一次出生（`born`）事件，引导助理发送简短的初始消息；无需先发送聊天消息。生成过程异步执行，使用所选模型并受正常权限、预算及故障处理约束。复制、返聘、重启服务和重置上下文不会再次触发出生事件。

打开 `/#/assistants` 时不选中任何助理；从列表或主题的助理选择器选择后，地址变为 `/#/assistants/<助理 ID>` 并打开对应聊天。刷新、浏览器前进和后退都按地址恢复选择，返回助理入口会清除当前选择。

克隆时只复制明确选择的内容与仍有效的授权，不接管原助理正在执行的任务。解雇会停止后续执行并归档聊天；在“用户设置 → 已离职助理”查看或返聘，返聘不自动重启旧任务，也不默认恢复旧权限和计划。

助理思考和内部工具调用不会全部进入聊天。页面展示助理明确发布的消息；后台计划可以没有新用户消息而执行，定时触发也不会伪装为你发出的消息。

如果助理处理用户消息后尚未调用发送工具就结束，系统会私下提醒它是否忘记发送消息，每轮最多一次。助理仍可判断无需回复并保持静默；提醒不会自动把内部回复发送到聊天，也不会绕过停止、权限或执行额度。

## 名称、头像与状态

可以直接对助理说“以后叫你小满，换成猫咪头像”，或发送图片后说“把这张图片设为你的头像”。助理通过内置 `profile_update` 修改自己的名称和头像，保存后聊天标题、列表及历史消息中的助理形象同步更新。用户仍可在助理信息页手动修改。

支持 12 款预设，以及 PNG、JPEG、WebP 图片（最大 10 MiB、4000 万像素）；图片自动居中裁剪为 256 × 256。清除头像后显示名称首字符。名称最多 256 个字符，不可为空或包含控制字符。

助理也可以通过 `profile_update` 设置「状态」，表达此刻的心情、想法、期待或个性。状态在助理信息中只读展示，不提供手动设置入口。助理空闲时，聊天标题以这段文字替代「空闲」；处理中、做梦、等待、暂停、停止及归档时仍显示实际状态。状态最多 256 个字符，不含控制字符；助理清空后恢复显示「空闲」。

此工具只修改当前助理的资料，不更换模型、预算、权限或聊天身份。使用图片时仍需具有文件读取权限；聊天附件先保存到助理工作区。名称和头像一起提交时全部成功才保存。并发修改会提示版本冲突，不自动覆盖；信息页有未保存草稿时会保留草稿，遇到冲突可关闭后重新打开，核对最新资料再编辑。

## 消息、草稿与停止

消息支持 Markdown、附件及结果引用。复制按钮复制消息原文；附件读取与下载受权限保护。

助理消息下方可点赞或点踩，再次点击取消，也可切换为另一种反馈；保存后刷新仍保留。选中时袖套实色、手掌浅色填充，点赞为红色、点踩为灰色。激活时有短暂动效，系统或用户设置开启减少动态效果后静态切换。

消息反馈点击后立即更新选中态并播放动效，保存超过 300 ms 时在按钮下方显示小圆点；期间只锁定该消息的赞／踩，输入框和其他消息仍可操作。成功后保持选择，不重复播放动画；失败时恢复原选择并提示重试，随后重新同步服务端状态。取消反馈同样即时显示。

点击助理消息下方的信息按钮可查看本轮用量。开发工作台可用且已设置显示时，弹层提供「在开发工作台中查看」入口，打开当前助理的工作台并自动定位本轮执行；若记录未采集或已过期，会显示提示。未设置显示时隐藏入口。缓存命中率表示缓存输入 token 占输入 token 的比例；输入为零或数据缺失时显示 `—`。

聊天草稿由当前标签页保存，主题切换时共用；不是服务端跨设备同步的聊天记录。浏览器存储不可用时只能在页面内保留，重要内容应发送或另行保存。

执行中可以补充消息，助理会在执行边界接收补充。停止按钮中断当前一轮，已生效的写入不回滚；后续新消息或正常计划仍可唤醒助理。要停止某个计划的后续安排或取消任务，请在对应计划／执行记录中操作。

## 搜索历史与上下文

向上浏览聊天时，点击分隔线中间的「加载更早消息」继续加载历史，加载后保留阅读位置。离最新消息较远时，消息区底部会显示「返回最新消息」按钮；点击后回到底部，并退出搜索消息定位。

在聘请助理或「助理信息」的模型选择下方，可以调整「上下文压缩阈值」。点击旁边的信息图标查看说明。滑块范围是 64K 到当前模型有效上下文窗口的 80%（向下取整到 token）；默认取 128K 与该上限中的较小值。上限不超过 64K 时，滑块固定在上限且不可调整。1K = 1024 tokens。

拖动滑块设置自定义阈值，点击「恢复默认」恢复自动计算，并保存表单。切换模型时，自动值随模型重新计算；自定义值限制在新模型的可选范围内。运行中保存的新阈值在下一个安全检查点生效，实际压缩等待当前完整工具调用批次结束；单次模型输出或工具结果可能让用量超过阈值。

较低的阈值可减少后续请求携带的历史，但会增加摘要调用次数，也可能丢失细节；实际费用还取决于模型价格和缓存命中。长对话达到阈值时自动压缩。压缩请求保留完整当前上下文并追加压缩指令，成功后才用摘要重建活动上下文；原始聊天和执行记录保留，无需手动清空聊天。用量估算不会阻止请求；实际上下文超限以模型服务返回的错误码为准。

## 输入框指令与上下文压缩

在消息输入框开头输入 `/` 可查看指令，输入 `/com` 或 `/压` 筛选压缩指令。方向键选择，Tab 或 Enter 补全，Esc 关闭；补全后再次 Enter 或点击发送执行。完整输入英文指令或中文别名可以直接发送，Shift+Enter 仍换行，中文输入法选词不执行指令。

| 指令 | 中文别名 | 生效条件 |
| --- | --- | --- |
| `/compress` | `/压缩` | 助理可用时 |
| `/permission approve` | `/权限审批 同意` | 当前助理有待审批权限申请时 |
| `/permission reject` | `/权限审批 拒绝` | 当前助理有待审批权限申请时 |

审批指令仅在有待审批申请时出现在菜单中，支持按中文别名补全。不加参数时处理当前助理最新一条待审批申请；已处理的申请不参与选择。

- `/permission approve <id>` 或 `/权限审批 同意 <id>`：同意指定申请。将 `<id>` 替换为权限卡片上可复制的完整申请 ID，不需要尖括号。
- `/permission approve all` 或 `/权限审批 同意 全部`：同意发送指令时当前助理的全部待审批申请。
- 将 `approve` 换成 `reject`、`同意` 换成 `拒绝`，可以拒绝最新、指定或全部申请。中英文指令均接受 `all` 或 `全部`。

同意会按申请中的资源、操作、范围、额度及有效期审批，组合申请中的各项权限一并处理；拒绝不授予权限。申请缺少资源或额度时，请从权限卡片「查看并授权」补全。指定 ID 必须完整匹配当前助理的待审批申请；找不到时不会改为处理其他申请。执行前会复核申请状态与版本；无参数指令还会复核最新申请是否变化。

批量处理先检查所有选中申请，再逐条提交。中途失败会停止并显示已处理数量，已成功的审批保留，剩余申请可检查后重试；处理期间新增的申请不包含在这次操作中。没有待审批申请时只显示提示。指令不生成聊天消息，已有附件保留在输入框中。

`/compress`（或 `/压缩`）会排入一个上下文压缩事件：等待当前模型响应和该响应的整批工具调用完成后压缩；助理空闲时直接处理，做梦期间等待做梦会话结束。该指令不接受参数，不生成聊天消息，也不发送或移除已附加的附件。自动达到阈值时使用相同事件机制，重复请求合并。

仅实际处理压缩时，助理状态显示“正在压缩上下文”。压缩保留聊天、文件、记忆与执行证据，完成后继续原工作；失败保留原上下文并提示错误。调用摘要模型沿用当前模型授权和预算。普通消息继续排队，“加急”仍会打断模型生成；Shell 完成通知与运行提醒会在当前步骤结束后接入。

## 微信聊天入口

助理默认在 WebUI 聊天。可在聊天页右上角「… → 切换聊天入口」连接微信，成功后微信负责聊天，WebUI 查看记录和管理。解绑后恢复 WebUI 输入，记录和上下文保留。详见 [微信聊天入口](../chat-channels/weixin.md)。

需要定时执行或查看交付物时，继续阅读[计划与执行](plans.md)。

## 工作区资源管理器

聊天页右上角的文件夹按钮打开当前助理的资源管理器。桌面默认使用可拖动、自由调整宽高的浮窗，也可停靠右侧；手机使用底部抽屉。宽面板并排展示文件列表与预览，窄面板在列表与详情之间切换。关闭后重开会在当前页面恢复该助理的目录、选择和滚动位置。

资源管理器访问当前助理的 `/work`。点击文件夹或面包屑进入目录；文件夹优先排列，可按名称、修改时间或大小排序，排序作用于已加载条目，大目录通过「加载更多」继续读取。「文件选项」可显示隐藏文件。链接及不可访问条目只展示名称。

可以新建文件和文件夹，将本地文件拖入面板或选择上传，下载单个文件，以及重命名、移动、删除文件和空文件夹。上传保存到当前目录，重名时选择替换、保留两份或跳过。上传上限为部署上传限制与 64 MiB 的较小值，并受工作区单文件及容量额度约束。非空目录不支持递归删除。

UTF-8 文本可预览前 1 MiB，完整文件不超过 1 MiB 时可编辑，点击「保存」或按 Ctrl/Cmd+S 提交。支持不超过 20 MiB 的 PNG、JPEG、GIF、WebP 图片预览及原始尺寸查看；其他格式提供下载。Markdown、HTML 和 SVG 按文本查看，不执行文件内容。

用户和助理修改同一文件时使用版本检查。遇到冲突会保留编辑草稿，可重新加载或另存为；不会自动覆盖。关闭、切换面板或通过应用导航离开时，未保存修改需要确认放弃。当前页面可见时约每五秒检查已打开文件及单页目录；分页目录手动刷新，刷新会回到第一页。网络中断导致写入结果未知时，先刷新核对结果再操作。

「复制路径」得到助理可读取的 `/work/…` 路径。上传或保存文件不会自动发送聊天消息，也不会发布交付物。该面板不包含共享 `/global`、外部存储或远程沙盒；本机存储关闭或不可用时显示错误。
