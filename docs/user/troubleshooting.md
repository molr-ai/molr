# 使用问题排查

先查看页面中的状态和错误信息，按当前任务决定继续、调整设置或联系管理员。

## 等待与失败

| 现象 | 可以检查的内容 |
| --- | --- |
| 等待授权 | 打开聊天中的申请卡片，核对资源、动作、额度与有效期后批准或拒绝 |
| 预算不足 | 检查助理预算、用量和重置时间；用户组额度不足时联系管理员 |
| 没有可用模型或工具 | 请管理员检查用户组资源分配；已有资源仍需给助理授权 |
| 模型或命令失败 | 保存错误信息，检查所选模型、任务输入与助理权限；资源连接和执行环境问题交给管理员 |
| 页面断线 | 检查设备网络并尝试重连；服务无法访问时联系管理员 |
| 结果未知或待核对 | 先查看消息、执行记录与实际产物，再决定是否重试，避免重复已生效的操作 |

调整权限或预算后，按任务当前提供的操作继续。导航连接状态表示客户端连接情况，不代表所有任务成功。

## 收集求助信息

在「用户设置 → 关于」查看 WebUI 与 Runtime 版本。记录错误提示、发生时间、相关任务与复现步骤；截图和日志分享前移除密码、令牌和无关个人资料。

忘记密码或无法完成二次验证时，请管理员协助恢复。需要检查服务器、模型连接或沙盒时，提供[管理员排查入口](../admin/troubleshooting.md)。如实例已开放开发工作台，可用它查看自己的执行记录，操作见[开发工作台](../dev/runtime/workbench.md)。
