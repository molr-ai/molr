# 快速开始

准备管理员提供的服务地址和账号，从登录开始完成第一次委托。需要自行安装 Molr 时，先阅读[搭建 Molr 实例](../admin/getting-started.md)。

macOS 桌面应用的连接管理页和连接后的 WebUI 使用左上角系统红黄绿按钮，分别用于关闭窗口、最小化和全屏，Logo 位于按钮右侧。关闭窗口后，已启动的 Runtime 继续运行。

## 登录

首次管理员使用初始化时创建的账号登录；普通成员使用管理员创建的账号。没有默认用户名密码组合或公开注册入口。启用了二次验证时，按页面提示输入验证码或恢复码。

已有登录设备可以在“用户设置 → 安全 → 登录链接”生成一次性链接，用于另一设备登录。链接有有效期，只能使用一次；启用 MFA 时仍需二次验证。链接应只交给本人或明确授权的使用者，不要放进公开文档。

## 选择可用模型

管理员通过用户组分配可用模型和工具。聘请助理时，选择支持当前任务及工具调用的模型。如果没有可用模型，或能力、价格尚未配置，请联系管理员。自行管理服务时，按[连接与管理模型](../admin/resources/models.md)完成接入。

## 聘请助理

为助理设置名字、支持工具调用的模型、消耗上限及每日或每周重置周期。聘请时会授权所选模型；不会同时授权该提供商下所有模型或你的文件目录。

预算属于助理。该助理的聊天和所有计划执行共用额度，没有单独的任务预算。详细规则见 [资源、权限与预算](guides/permissions-and-budget.md)。

## 交代第一件事

先选择你能核对结果的小任务，例如上传一份资料，请助理列出要点与待确认问题，并指出依据。说明输入、期望结果和不要改变的原件，有助于判断是否完成。

附件发送、模型回复或工具操作可能失败，留意页面中的状态与原因。普通对话不强制生成计划；模型明确创建任务时，执行会关联计划。实际可处理的文件类型和内容规模受模型与部署能力限制。

## 查看结果并继续

在聊天和“计划”中查看相关执行及产物；已有交付物可以下载，任务修订保留历史版本。收到一段回复并不等于资料已经修改或任务已经验收，核对实际结果与明确的完成状态。

需要助理读取外部目录时，请管理员先添加可用目录，再为助理授予范围；需要执行命令时，另外授予就绪计算环境的执行权限。操作路径见 [助理、聊天与计划](guides/assistants-and-chat.md) 和 [文件与命令](guides/files-and-commands.md)。
