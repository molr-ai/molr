# Molr 使用指南

本指南面向使用已有 Molr 服务的成员。准备服务地址和账号，连接已分配的资源，管理自己的助理与任务。自行部署或管理成员请阅读[管理员指南](../admin/README.md)。

## 开始使用

- [快速开始](getting-started.md)：登录、选择可用模型、聘请助理并完成第一次委托。
- [基本概念](concepts.md)：助理、计划、记忆、资源与数据边界。

## 日常使用

- [助理与聊天](guides/assistants-and-chat.md)、[计划与执行](guides/plans.md)：交代任务、安排时间、查看结果。
- [记忆与自动整理](guides/memory.md)：查看、编辑、确认或遗忘记忆。
- [权限与预算](guides/permissions-and-budget.md)：为自己的助理授权资源、设置额度和撤销授权。
- [文件与命令](guides/files-and-commands.md)：工作区、后台任务、终端和临时服务。
- [插件与 Skills](guides/plugins-and-skills.md)：使用已分配插件，在助理工作区安装 CLI 与 Skill。
- [个人设置](guides/settings.md)、[账号安全](guides/account-security.md)：外观、提醒、用量、数据导出、密码与登录设备。

## 聊天入口与实践

[微信](chat-channels/weixin.md)和[Telegram 聊天入口](chat-channels/telegram.md)和 [Slack 聊天入口](chat-channels/slack.md)介绍绑定、消息收发和解绑。按任务查阅[最佳实践](best-practices/README.md)，使用浏览器、钉钉、飞书、邮箱、知乎、GitHub 或 Google 服务。

## 遇到问题

从[使用问题排查](troubleshooting.md)检查连接、权限、预算与执行状态。需要新增资源或修改服务器配置时，联系管理员并提供错误信息和版本。
