# QQ 聊天入口

在助理聊天页打开「… → 切换聊天入口」。未绑定外部入口时，抽屉显示入口列表；点击 QQ 后，列表向左切换为 QQ 详情。已经绑定时，抽屉直接显示该入口的详情和绑定状态；解绑成功后自动返回列表。其他入口也使用相同的导航方式。

## 扫码连接

点击「扫码连接 QQ」，用手机 QQ 扫描页面内的二维码，在 QQ 页面选择或创建专属机器人并确认授权。二维码在本地绘制；机器人密钥由 Runtime 接收并加密保存，不返回浏览器。

扫码返回用户身份后，助理只接收该用户与机器人的单聊。若 QQ 未返回用户身份，页面会显示配对码：在机器人私聊中发送完整配对码，十分钟内完成配对。配对前仍可在 WebUI 聊天，配对消息不会触发助理。二维码过期时点击刷新；返回列表或关闭抽屉会取消当前页面尚未完成的扫码会话。

每个机器人在一个 Molr 实例内只绑定一位助理。助理已经绑定其他聊天入口，或其他入口正在配对时，需要先解绑或取消配对。

## 手动填写

选择「手动填写凭据」，在 [QQ 开放平台](https://q.qq.com/qqbot/openclaw/login.html) 创建机器人，填写 App ID 和 App Secret，再按页面提示在 QQ 私聊发送配对码。不要把 App Secret 发到聊天中。刷新页面后无法重新显示旧配对码，可取消后重新连接。

## 使用与解绑

当前支持私聊文字收发。QQ 入站附件会明确标记为未读取；请在 Molr 上传文件。助理发布的附件和卡片转换为文字及 Molr 链接，访问链接需要可达的 Molr 地址和登录权限。群聊、原生媒体收发和流式消息暂不支持。

绑定后，QQ 负责聊天输入；WebUI 保留聊天记录、任务、文件和权限管理，既有记录不会补发到 QQ。用户在 QQ 关闭「允许主动发送」后，定时提醒和超过回复窗口的通知可能发送失败。投递失败或结果未知会在 Molr 提示；结果未知时不会自动重发。

点击「解绑 QQ」并确认后，恢复 WebUI 输入，已有记录和上下文保留，未发送的回复取消，抽屉自动返回入口列表。解绑不会删除 QQ 平台的机器人。渠道消息会传输给腾讯。
