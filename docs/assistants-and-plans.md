# 助理、聊天与计划

## 持续聊天与助理管理

每位助理有自己的持续聊天、执行状态和资源权限。可以按名称搜索、置顶、重命名、编辑模型与预算。当前真实 WebUI 不提供会话分组操作。

全新聘请助理后，系统会自动触发一次出生（`born`）事件，引导助理发送简短的初始消息；无需先发送聊天消息。生成过程异步执行，使用所选模型并受正常权限、预算及故障处理约束。复制、返聘、重启服务和重置上下文不会再次触发出生事件。

打开 `/#/assistants` 时不选中任何助理；从列表或主题的助理选择器选择后，地址变为 `/#/assistants/<助理 ID>` 并打开对应聊天。刷新、浏览器前进和后退都按地址恢复选择，返回助理入口会清除当前选择。

克隆时只复制明确选择的内容与仍有效的授权，不接管原助理正在执行的任务。解雇会停止后续执行并归档聊天；在“用户设置 → 已离职助理”查看或返聘，返聘不自动重启旧任务，也不默认恢复旧权限和计划。

助理思考和内部工具调用不会全部进入聊天。页面展示助理明确发布的消息；后台计划可以没有新用户消息而执行，定时触发也不会伪装为你发出的消息。

如果助理处理用户消息后尚未调用发送工具就结束，系统会私下提醒它是否忘记发送消息，每轮最多一次。助理仍可判断无需回复并保持静默；提醒不会自动把内部回复发送到聊天，也不会绕过停止、权限或执行额度。

## 名称与头像

可以直接对助理说“以后叫你小满，换成猫咪头像”，或发送图片后说“把这张图片设为你的头像”。助理通过内置 `profile_update` 修改自己的名称和头像，保存后聊天标题、列表及历史消息中的助理形象同步更新。用户仍可在助理信息页手动修改。

支持 12 款预设，以及 PNG、JPEG、WebP 图片（最大 10 MiB、4000 万像素）；图片自动居中裁剪为 256 × 256。清除头像后显示名称首字符。名称最多 256 个字符，不可为空或包含控制字符。

此工具只修改当前助理的资料，不更换模型、预算、权限或聊天身份。使用图片时仍需具有文件读取权限；聊天附件先保存到助理工作区。名称和头像一起提交时全部成功才保存。并发修改会提示版本冲突，不自动覆盖；信息页有未保存草稿时会保留草稿，遇到冲突可关闭后重新打开，核对最新资料再编辑。

## 消息、草稿与停止

消息支持 Markdown、附件及结果引用。复制按钮复制消息原文；附件读取与下载受权限保护。

助理消息下方可点赞或点踩，再次点击取消，也可切换为另一种反馈；保存后刷新仍保留。选中时袖套实色、手掌浅色填充，点赞为红色、点踩为灰色。激活时有短暂动效，系统或用户设置开启减少动态效果后静态切换。

消息反馈点击后立即更新选中态并播放动效，保存超过 300 ms 时在按钮下方显示小圆点；期间只锁定该消息的赞／踩，输入框和其他消息仍可操作。成功后保持选择，不重复播放动画；失败时恢复原选择并提示重试，随后重新同步服务端状态。取消反馈同样即时显示。

点击助理消息下方的信息按钮可查看本轮用量。开发工作台可用且已设置显示时，弹层提供「在开发工作台中查看」入口，打开当前助理的工作台并自动定位本轮执行；若记录未采集或已过期，会显示提示。未设置显示时隐藏入口。缓存命中率表示缓存输入 token 占输入 token 的比例；输入为零或数据缺失时显示 `—`。

聊天草稿由当前标签页保存，主题切换时共用；不是服务端跨设备同步的聊天记录。浏览器存储不可用时只能在页面内保留，重要内容应发送或另行保存。

执行中可以补充消息，助理会在执行边界接收补充。停止按钮中断当前一轮，已生效的写入不回滚；后续新消息或正常计划仍可唤醒助理。要停止某个计划的后续安排或取消任务，请在对应计划／执行记录中操作。

## 计划与执行记录

“计划”汇总本人和助理的事项、时间安排和自动执行，可以按负责人、类型和状态筛选；聊天内的计划面板默认查看当前助理。

清单默认按发生时间升序展示接下来的 50 个事件，可继续加载。重复计划的每次发生单独列出；无日期事项和逾期未完成的一次性安排通过独立入口查看。点击具体事件查看的日期、完成操作都对应那一次安排，系列编辑仍作用于整个计划。

日历默认展示当月，提供上月、下月、回到今天及月份选择。格子放不下的事件以 +N 折叠，点击 +N 或日期打开当天完整清单。做梦不是日历事件；页脚独立入口展示预留时段和设置入口，冲突提示在创建、编辑和详情中展示。

清单前的实心圆点表示类型：绿色为事项、蓝色为时间安排、紫色为自动执行，仅用于区分，不能点击。创建、编辑、计划详情及未结束的执行详情会醒目提示做梦冲突；页脚“个时段”数量按所选日期和负责人筛选统计，每位助理每天只有一个可配置的自动时段。

新增事项可以先填写标题，再指定负责人、日期或时间。指派给助理只表达责任，不等于立即启动。一次性执行和重复计划的每次发生都有独立记录，查看记录可以了解当时的说明、状态、费用和产物。

重复安排完成的是某次执行，不是一次勾选就结束整个系列。已有执行历史或被后续计划依赖的记录需保留，可暂停后续安排。计划修订不覆盖旧执行的说明快照。

## 交接与定时执行

计划可以设置前置事项。当前前置依赖支持一次性计划；前置完成后可以在应用内提示交接，或者由用户明确启用自动启动后续助理执行。

交接不会附带扩大权限或预算。个人填写的结果说明和前置产物可成为后续依据，资料读取仍受助理权限限制。当前应用内交接提示不等于系统推送或邮件通知。

定时执行以服务中保存的时区与重复规则为准，受执行设备在线状态、资源、权限和预算约束。客户端关闭后，在线 Runtime 可继续已接收的工作；Runtime 停机期间不能执行，错过安排的处理取决于计划策略。

## 结果与修订

在执行详情查看等待原因、用量和交付物，并按当前状态暂停、恢复或取消。追加修订保留历史产物及已发生费用；不能把取消理解为删除历史结果。

“已收到消息”“助理已发布回复”“执行已完成”是不同状态。任务交付依赖实际产物和检查证据，当前没有可自动判断任意内容质量的通用验收器。重要结果需要自己核对。

## 做梦（自动整理）

做梦会向模型提供前一个完整自然日的新增经历和文件工具。模型自行查找、读取已有记忆，更新、合并、移动或删除主题文件，并维护 `MEMORY.md` 中的核心认知；最后保存本批整理回顾。没有新经历但已有私有记忆文件时，仍可进行整理。模型负责判断信息的范围和可靠性，应保留不确定性，避免把助手声称或临时要求当作长期事实。

在“用户设置 → 记忆”中选择在职助理，可以设置每天的做梦时间、时长上限或立即整理。全局共享范围不显示做梦操作。做梦使用助理当前选定且支持工具调用的模型，每批可进行多轮调用，用量计入该助理预算。历史材料作为数据提供，不会作为新指令重放。

开发工作台展示实际的文件写入、编辑、移动、删除以及每轮工具结果。文件操作出错时，模型可以根据错误重新读取并修正。您在记忆界面保存或确认的文件会标为只读，共享记忆也只读；直接编辑普通 Markdown 不会自动锁定文件。

做梦期间助理显示“正在做梦”，新消息和计划排队等待，消息保持未读，加急不可用。时段结束或手动停止会保留已经成功的文件操作，即使当前批次尚未完成。未处理完的资料最多在次日补处理一次；错过整个预留时段则跳过，失败的整理在原截止时间内可重试一次。

## 记忆管理

本地 MEMORY.md 核心认知自动进入有大小上限的上下文；主题记忆由助理使用文件搜索和读取工具主动检索。模型整理主题时负责同步相关核心内容和文件引用。目录就是分类，改名后旧路径不再有效；当前明确要求优先于历史偏好。

您可以查看、编辑、确认、删除或遗忘记忆。普通删除只移除文件，之后可能从原资料重新整理出来。遗忘还会记录内容摘要及已知来源，并清理相关撤销副本；没有来源信息的外部 Markdown 不能保证所有改写都被识别。原始聊天不会因此删除。

撤销已完成的一批整理会按反序恢复其未被后来修改的文件操作，包括创建、编辑、移动及删除。后来编辑、确认或遗忘的内容受到保护；具体保留文件会显示在批次记录中。

## 搜索定位与工作区指引

每位助理有一个独立、跨会话保留的本地工作区 `/work`。Runtime 初始化默认目录：`inbox/` 保存附件和导入原件，`projects/` 按事项组织草稿、脚本和工作文件，`outputs/` 保存交付成果。可以要求助理使用其他目录；文件保存后仍需明确发送到聊天才完成交付。

Skills、记忆和回顾沿用 `.agents/` 下的对应目录；`.local/state/molr/` 按用户状态目录的语义存放工具结果及命令输出等执行记录，跨重启保留，当前不自动清理。`.cache/` 是可重新生成的缓存，但当前不会自动清理。`/tmp` 只属于一次命令执行，需要下次继续使用的文件应保存在 `/work`。同一账号共享的 `/global` 对助理普通操作只读。

助理会自动收到这些路径、用途、持久性和可用状态，具体文件按需查找。根目录 `AGENTS.md` 自动加载；进入具体工作目录时，助理先列目录，再加载该目录及上级的指令。附件、交付目录、缓存和运行产物中的同名文件不会自动成为指令。目录约定不增加文件或命令权限。


全局搜索中的聊天结果会进入对应助理，自动加载目标所在的历史页并高亮消息；链接保留消息位置，刷新后仍可定位。点击“返回最新消息”回到会话末尾。目标不存在或不可访问时会明确提示。

助理可以发现Runtime 本地工作区 `/work/.agents/skills/<目录名>/SKILL.md` 中的 Skills，并在通过文件工具读取后按需加载流程指引。助理信息的 Skills 页可查看发现的条目，当前没有安装、编辑或启停管理入口；Skill 不额外授予文件、网络或工具权限。远程电脑的连接与显式文件传输见 [资源与权限](resources-and-permissions.md)。

长对话的模型上下文默认在达到窗口 80% 时自动压缩。压缩请求保留完整当前上下文并追加压缩指令，成功后才用摘要重建活动上下文；原始聊天和执行记录保留，无需手动清空聊天。用量估算不会阻止请求；实际上下文超限以模型服务返回的错误码为准。

## 输入框指令与上下文压缩

在消息输入框开头输入 `/` 可查看指令，输入 `/com` 或 `/压缩` 筛选 `/compress`。方向键选择，Tab 或 Enter 补全，Esc 关闭；补全后再次 Enter 或点击发送执行。完整输入 `/compress` 可以直接发送，Shift+Enter 仍换行，中文输入法选词不执行指令。

`/compress` 会排入一个上下文压缩事件：等待当前模型响应和该响应的整批工具调用完成后压缩；助理空闲时直接处理，做梦期间等待做梦会话结束。该指令不接受参数，不生成聊天消息，也不发送或移除已附加的附件。自动达到阈值时使用相同事件机制，重复请求合并。

仅实际处理压缩时，助理状态显示“正在压缩上下文”。压缩保留聊天、文件、记忆与执行证据，完成后继续原工作；失败保留原上下文并提示错误。调用摘要模型沿用当前模型授权和预算。普通消息继续排队，“加急”仍会打断模型生成；Shell 完成通知与运行提醒会在当前步骤结束后接入。

## 微信聊天入口

助理默认在 WebUI 聊天。可在聊天页右上角「… → 聊天入口」连接微信，成功后微信负责聊天，WebUI 查看记录和管理。解绑后恢复 WebUI 输入，记录和上下文保留。详见 [微信聊天入口](weixin.md)。
