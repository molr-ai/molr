# 个人设置

桌面点击侧边栏底部头像，手机点击助理页顶部头像和用户名，进入用户设置。管理员通过用户设置页头右上角的「管理员设置」按钮进入管理页面，操作见[管理用户与用户组](../administration/users-and-groups.md)。

## 个人资料与头像

在用户设置 → 个人资料中设置显示名称和头像。可选择预设头像，或上传不超过 10 MB、4000 万像素的 PNG、JPG、WebP 图片；图片会在浏览器内居中裁剪为 256 × 256 的缩略图。点击「保存」后，桌面侧栏和手机顶部显示新头像；清除并保存后恢复名称首字符。头像随账号保存，换设备登录后仍可使用。

## 语言、主题与偏好

常规设置管理语言、时区、币种等偏好。“显示插件”默认关闭，开启后显示插件导航、插件主题及相关管理选项，设置随账号同步；具体范围见[插件](plugins-and-skills.md)。主题页区分界面主题、配色和明暗模式，保存到账号后可在其他设备读取；提供默认、测试两套内置主题，也可选择管理员已安装、授权并启用的[插件主题](plugins-and-skills.md)。主题配色可选森林、海盐蓝、鸢尾紫、暖砂、玫瑰和素墨，均支持浅色与深色显示。素墨使用中性灰阶界面，成功、警告、错误等提示保留语义色。

记忆的查看、编辑和做梦时间见[记忆指南](memory.md)。默认模型与助理模型的选择见[权限与预算](permissions-and-budget.md#选择模型)。

## 系统提醒

微信投递／连接异常、助理持续受阻、授权请求、计划待交接和任务／后台执行失败由服务端统一管理提醒状态。后台执行失败提醒在开发工作台可用且已设置显示时显示「在开发工作台中查看」，点击定位对应执行；未设置显示时保留提醒和关闭按钮，不显示查看入口。未采集或已过期的执行会明确提示记录不可用。其他提醒直接进入对应的聊天、授权、任务或计划页面；需要长期查阅的内容保留在对应业务页面，不设独立通知历史页。

聊天一次显示一条提醒，并显示剩余数量。当前提醒不会被新到达的提醒打断；关闭成功后按发生顺序显示下一条，关闭失败时保留当前条。关闭状态在设备间同步，刷新不会重新出现同一次提醒；关闭不会重发消息、取消任务或改变业务处理结果。问题恢复后提醒自动消失，新的异常会产生新的提醒。

用户设置的“通知设置”管理当前浏览器的提醒、预览、声音和桌面通知。关闭主动提醒不影响聊天内的待处理提醒或消息未读计数。可信 HTTPS／本机环境可授权桌面通知；页面关闭后暂不推送，重新打开可在相应聊天查看仍待处理的提醒。桌面通知自动收起和 Toast 自动消失不等于已读或已解决。

## 组件管理

管理员从用户设置页头进入「管理员设置 → 组件」，查看浏览器组件版本与安装进度，并进行安装、更新或修复。点击浏览器组件条目的「设置」打开代理设置弹窗，保存后关闭，取消不保留草稿。浏览器的使用方式见[操作浏览器](../best-practices/browser.md)。

## 关于 Molr

用户设置最后一栏「关于」显示 WebUI 与 Runtime 的版本、Git commit、版本一致性和更新信息；点击 commit 可查看对应代码。版本信息下方的「服务信息」分组展示当前 Runtime 的名称与地址。下方可前往 [Molr GitHub 项目](https://github.com/molr-ai/molr)，为项目点 Star。完整 Logo 使用昼夜循环动画，按设备本地时间在 08:00 和 20:00 自动切换，沿用减少动态效果偏好。

## 数据导出

用户设置 → 个人数据导出将当前账号的数据打包为 ZIP，生成后在页面下载。默认包含共享及助理私有记忆（含核心、主题、回顾与遗忘记录）、助理资料、任务与修订、待办和计划、账号设置、属于当前账号的资源记录，以及做梦配置和处理记录。导出时可选择聊天记录（默认勾选）和附件与交付物（默认不勾选）。导出请求取消或超时后，Runtime 会停止继续读取附件并关闭已打开的文件；尚未完成的压缩包不会发布。数据导出不是完整服务灾备。部署者仍需备份数据库、文件、助理工作区、配置和密钥，见 [部署与维护](../deployment/maintenance.md)。
