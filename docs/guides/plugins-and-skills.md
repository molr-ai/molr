# 插件与 Skills

先在 **用户设置 → 常规** 开启 **显示插件**，再通过侧栏 **插件**（`/#/extensions`）管理主题、页面和 HTTP 工具。此开关默认关闭，按账号保存并跨设备同步。关闭后隐藏插件入口、插件主题、插件工具目录、登录链接的插件目标、用户组中的插件和服务连接选项，以及用量中的连接明细；直接打开插件页面会转到常规设置。已选择的插件主题暂时使用默认主题，重新开启后恢复。已有插件配置、授权和后台工具执行不受影响。CLI 和 Skill 直接安装在助理工作区，无需导入插件包。

## 使用已授权插件

普通成员使用管理员已启用并分配给所属用户组的插件。个人启停只影响自己的使用；插件有个人设置时，可在对应配置入口填写。插件页面、主题和 HTTP 工具仍受组权限、个人启用和助理授权限制。安装与共享服务连接由[管理员管理](../administration/plugins.md)。

## 安装 CLI 或 Skill

直接在聊天中告诉助理来源与用途，例如：“把这个 CLI 安装到你的工作目录，并按文档验证可用。”助理使用普通 Shell 和文件工具安装程序及依赖，需要计算或网络资源时沿用现有权限申请流程。

CLI 安装在助理的 `/work` 内。Skill 放入 `/work/.agents/skills/<名称>/SKILL.md`，系统自动发现，助理按需读取。不同助理拥有独立工作区，文件跨执行和重启保留。登录按 CLI 自身支持的流程完成，登录文件保存在工作区；更新、检查和删除也由助理使用普通工具完成。

这类安装不会在插件列表中生成记录。插件启停、版本切换和卸载不管理这些工作文件。

助理信息的 Skills 页可以查看已发现的条目；当前没有安装、编辑或启停入口。Skill 提供流程指引，不额外授予文件、网络或工具权限。
