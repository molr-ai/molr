# 插件

通过侧栏 **插件**（`/#/extensions`）浏览插件、搜索名称并筛选启用状态。插件可以提供主题、页面、助理工具或 Skills；是否提供个人配置、管理员配置，以及有哪些选项，都由插件声明。

## 管理员操作

在插件页面点击 **导入插件包**，选择 `.molr-plugin.json`。导入不会运行安装脚本，也不会自动授权。每张卡片提供全局启停，更多菜单集中提供以下操作：

- **权限与助理**：批准插件声明的能力、选择版本、绑定管理员自己的助理。Shell 工具还需要计算资源和助理计算授权；HTTP 工具无需计算资源。
- **授权用户组**：允许所选组使用插件，并授予当前版本的工具、Skill 及当前可用服务连接。取消授权后，该组无法打开插件或调用其能力。工具、连接的细分范围和配额仍可在管理员设置的用户组中调整。
- **管理员配置**：仅在插件声明共享设置或外部服务时显示。共享字段、自定义管理员页面及服务连接在此管理。
- **卸载**：移除已安装插件的可用入口。

管理员的“全局启用”控制整个实例；“为自己启用／停用”只控制管理员本人。管理员也可通过卡片的“配置”设置自己的个人选项。

## 普通用户操作

普通用户只看到管理员已全局启用、且其用户组获准使用的插件。卡片上的启停只影响本人，停用后仍保留卡片，方便重新启用。插件页面、主题和助理能力遵循同一启停状态。

只有提供个人设置的插件才显示 **配置**。提供自定义设置页时直接打开插件页面；只声明设置字段时由宿主生成表单。没有个人设置的插件无需配置，也不会显示空设置入口。插件配置统一位于插件页面，用户设置和管理员设置中不再重复列出插件管理。

插件支持个人服务选择时，每个用户可独立选择获准使用的连接；连接决定 provider。新选择从下一次调用生效，已经开始的请求保持原配置。插件也可只使用管理员配置的共享连接，完全不要求用户级设置。共享连接仍须授予用户组。

## 服务连接与额度

管理员在插件的管理员配置中添加连接，选择 provider、输入 API Key，并设置累计调用上限、并发和超时。同一 provider 可以有多个连接。API Key 由 Molr 加密保管，界面只显示配置状态；编辑时留空会保留原 Key。开启敏感操作验证时，保存或删除凭证需要完成验证。

“测试连接”会向供应商发送一次固定请求，使用调用额度，可能产生费用；页面加载和保存配置不会自动测试。配置缺失、连接失效或无权限时，调用会报错，不会自动切换服务。

Shell 工具在助理已有沙盒内运行，可以读写该助理 `/work`，网络关闭，最多运行 30 秒。HTTP 工具由 Runtime 请求批准的服务接口，不依赖沙盒。

HTTP 连接累计调用上限包含测试和结果未知的请求。提高上限不清空用量；成员同时受工具和连接的组级配额约束。供应商用量按原单位展示，未计价不代表免费。

连接的“调用记录”显示最近 100 次请求的状态、provider、耗时和可用用量。超时、取消或重启后无法确定外部结果的请求会保留并发占用。管理员核实后可“确认并释放并发占用”；这不会退还次数或重试请求。

## 更新、停用与卸载

新版本导入后只暂存。在“权限与助理”切换版本会停用插件并清空能力授权和管理员助理绑定。管理员复核服务地址、连接和共享配置，并检查新版本的用户组工具授权；有个人配置的用户也需复核保存。相同版本内容不可替换，每个插件最多保留八个版本。

停用和撤权会阻止新调用并请求取消受影响的在途执行，不能撤销已经发生的文件写入或供应商处理。卸载保留包、配置、连接记录、工作区文件和操作历史；重新安装不自动恢复插件能力权限。删除服务账号需单独删除连接及其专用凭证。

## 支持范围

插件页采用市场式卡片布局，展示本实例已安装的插件；目前安装来源为本地文件，不包含在线插件目录或远程下载。支持 Plugin API 2。当前没有 MCP 工具、后台常驻服务、OAuth、用户自带 Key 管理、任意 URL 抓取或自动 provider 兜底，也不预装搜索或演示插件。

包格式、HTTP 声明和 SDK 合同见 [插件架构](../dev-docs/runtime/PLUGINS.md)。
