# 操作飞书

飞书官方 [Lark CLI](https://github.com/larksuite/cli) 支持日历、文档、消息、表格和任务等操作。助理通过 `lark-cli` 在已授权的账号和应用范围内完成工作。

## 安装与授权

先完成[执行环境准备](README.md#准备执行环境)，再把下面的委托发给助理：

> 按 https://github.com/larksuite/cli 的官方说明，把 Lark CLI 和需要的 Skills 安装到你的工作区。引导我完成应用配置和账号授权，把需要我打开的链接发给我。先验证读取日程。

官方安装入口是 `npx @larksuite/cli@latest install`，需要 Node.js 和 npm。让助理检查安装位置及依赖；安装后按官方流程配置应用并登录：

```bash
lark-cli config init
lark-cli auth login --domain calendar
lark-cli auth status
```

跟随引导配置或创建应用，在自己的浏览器中打开授权链接。本例先授权日历；需要文档、消息等能力时，再按对应命令要求补充权限。应用权限与用户授权都需要满足。

## 可以这样委托

> 查看我今天的飞书日程，整理成时间表，并标出时间冲突。

> 阅读我指定的飞书项目文档，汇总本周进展、阻塞项和待办，附上文档链接。

> 根据这份周报起草一条发往项目群的消息，先给我确认内容和目标群，再发送。

提供文档链接、时间范围或目标群，有助于助理找到正确对象。需要写入多维表格或创建任务时，说明目标表、字段或负责人。

## 验证与排查

登录状态正常后，再验证一次实际查询：

```bash
lark-cli calendar +agenda
```

登录成功但资源不可访问时，让助理检查当前身份、应用权限、用户授权及资源分享范围。用户身份与机器人身份的可见范围可能不同，委托时说明应使用哪个身份。

命令参数先查 `lark-cli <服务> --help`，安装和授权细节见[官方仓库](https://github.com/larksuite/cli)。
