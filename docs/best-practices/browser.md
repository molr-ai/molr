# 操作浏览器

助理可以使用浏览器打开网页、读取内容、填写表单、点击按钮和截图。聊天标题栏的「浏览器」打开实时画面，显示助理正在使用的同一个浏览器。

## 开启与观看

为助理授予本机计算资源和需要访问的网站网络权限。首次使用时，管理员可以在浏览器面板点击「安装并启动」，下载并校验当前兼容版本；关闭面板后安装继续，完成后会重新检查授权并启动浏览器。也可由管理员预先配置 [浏览器程序](../sandbox/linux.md#受管浏览器任务)。可以直接告诉助理：

> [!PROMPT]
> 打开这个网站，比较两个产品的规格，把结果整理给我。需要登录时等我接管。

也可以在浏览器面板选择已授权的本机计算资源，点击「启动浏览器」。每个助理最多一个活跃浏览器任务，重复启动复用已有任务；浏览器内可以打开多个标签页；标题栏浏览器图标的角标显示当前标签数量，关闭面板后仍会更新。浏览器作为沙盒任务运行，选择计算资源用于确定 CPU、内存、进程数和运行时限，沿用已有授权。面板默认选中首个可用资源，可按需要切换；浏览器占用现有执行名额，受计算额度和授权期限限制。

关闭面板只停止观看。浏览器继续运行，可在「浏览器」或「运行任务」中关闭。关闭浏览器保留网站登录态和本地数据，下次启动继续使用；网站登录是否仍有效由网站决定。不同助理的数据互不复用。

标签、新建、全屏和关闭按钮位于同一行，接管／交还按钮位于地址栏右侧。标签较多时会先缩窄，再通过左右箭头浏览溢出部分。大屏侧栏会提供更宽的浏览空间。点击「全屏视图」可铺满 Molr 页面，保留标签栏、地址栏和接管按钮；展开和收回都以侧栏当前位置为起点或终点；「退出全屏」或 Esc 返回原布局，不切换设备的原生全屏模式。

## 接管与交还

点击「接管」后，等待当前已接受的操作结束，再使用鼠标点击、滚动、拖动以及地址栏和标签页控件。点击网页输入框后即可直接键入中文或粘贴，仅显示系统输入法的候选窗口，位置靠近点击处，组合文字确认后一次发送到网页。底部键盘按钮可展开「辅助输入」，适合手机或特殊输入法。标签栏用「＋」新建，每个标签的关闭按钮仅关闭对应标签。

接管期间，助理仍能读取快照、截图、标签页和当前网址；点击、填写、导航、关闭等操作会收到明确的接管提示。接管影响该浏览器的所有标签页。你在浏览器里登录的网站，交还后也能由助理在相同授权范围内使用。

完成后点击「交还」。助理会收到通知，并须先读取新快照才能继续操作。交接前的排队操作和旧控制权版本不会在交还后重放。多个窗口同时请求接管时，过期请求会被拒绝，并通过可关闭的 Toast 提示重新接管；提示也会自动消失。

断线或关闭面板不会自动交还控制。在同一页面关闭再打开面板会恢复当前窗口的接管状态，无需再次接管；刷新页面或换到其他窗口后需明确接管。页面自身的脚本和网络活动仍受原有沙盒权限约束，接管不会扩大授权。

## 范围与故障

当前支持本机 Linux 沙盒中的 Chromium。浏览器程序共享只读安装，网站数据按助理持久保存。实时画面不自动录制，人工逐键输入不写入操作日志；截图只有明确调用时保存。

组件未安装时面板显示安装入口和空间需求；系统库缺失、后台维护服务不可用时显示管理员操作指引。安装进度与结果可在面板及设置页查看，失败后可以重试。Runtime 重启后不会自动重放“安装并启动”的浏览器启动请求。系统库不可用、资源不足或授权过期时，面板与运行任务会显示不可用或结束状态。正常关闭会先让 Chromium 保存数据，再回收执行；强制停止、崩溃和撤权不保证尚未写入磁盘的数据全部保存。Runtime 重启后任务标记中断，不自动重放操作。
