# 组件管理

## 在 WebUI 中管理

管理员从用户设置页头进入「管理员设置 → 组件」，查看浏览器组件版本与安装进度，并进行安装、更新或修复。点击浏览器组件条目的「设置」打开代理设置弹窗，保存后关闭，取消不保留草稿。浏览器的使用方式见[操作浏览器](../../user/best-practices/browser.md)。

## 命令行维护

`molr-setup` 同时管理 Molr 本体和可选组件。浏览器面板的「安装并启动」会在当前实例安装经过验证的 agent-browser 与 Chrome for Testing（基于 Chromium）组合；程序由同一实例的助理只读共享，网站数据仍按助理隔离。当前自动下载清单支持 Linux amd64、macOS arm64 和 amd64。macOS 使用完整 Chrome 应用包，不需要手动修改系统设置。

```bash
molr-setup components status --json
molr-setup components install browser
molr-setup components update browser
molr-setup components repair browser
molr-setup tasks status <task-id> --json
molr-setup tasks cancel <task-id>
```

组件更新以当前安装器内置的兼容版本清单为准。下载包按 SHA-256 保存在实例私有缓存中，后续安装或修复复用时重新校验大小和摘要，损坏缓存会重新下载。修复安装到新的版本目录，不覆盖运行中任务使用的文件；旧目录暂不自动清理。显式配置浏览器程序路径时，这份程序由管理员维护，自动安装不会覆盖它。

本体和组件维护共用实例级排他锁。重复请求复用已有任务，其他修改请求返回忙碌状态；状态查询不需要占锁。任务阶段和结果保存在实例私有缓存中，组件状态与本体安装记录分开。下载可取消，文件提交和服务重启阶段不接受取消；失败或中断后可以重试，未校验文件不会成为有效安装。

Linux WebUI 使用服务账户的独立 systemd 用户服务执行维护，需要可用的用户级 systemd 管理器。macOS 使用继承实例锁的独立安装进程，无需注册额外服务。关闭页面或重启 Runtime 不会取消组件安装；macOS 本体更新仍通过 CLI 或桌面端完成。管理员配置在 Runtime 服务环境中的代理与证书变量会传递给维护服务，变量值不进入命令行或任务响应。组件目录及其父目录不得允许其他用户写入。

普通组件安装不执行系统包管理器，也不自动调用 sudo。缺少浏览器系统库时，由管理员显式运行 `molr-setup components install browser --install-deps`；当前自动依赖准备支持 APT。系统级 Molr 更新仍由安装账户在宿主执行。用户级安装满足权限条件时，管理员可在 WebUI 主动选择「更新并重启 Molr」；该操作会中断运行任务，更新器不会自动降级或恢复浏览器 Profile。

## 浏览器代理

管理员在「管理员设置 → 组件」的浏览器组件条目点击「设置」，在弹窗中配置代理，所有用户新启动的浏览器任务统一使用该设置。支持 HTTP 代理（可选用户名和密码）以及无认证 SOCKS5；HTTP 代理也可承载 HTTPS 网站访问。代理地址必须包含协议、主机和端口，例如 `http://host.molr.internal:7890`。Linux 宿主服务使用 `host.molr.internal`，`localhost` 属于沙盒自身；macOS 沿用宿主网络，宿主代理使用 `127.0.0.1` 或其实际地址。

保存后，下次启动浏览器时生效；已有任务继续使用启动时的配置，不会自动中断。关闭并重新启动浏览器即可应用新设置，无需重启 Runtime。密码不回显，保持代理地址和用户名不变时留空保留密码；修改地址或用户名须重新填写密码，选择无认证或直连会清除认证信息。

代理端点仍需助理的沙盒网络授权，不会自动放行。绕过代理的地址用逗号分隔，支持主机、通配域名及 IP/CIDR；这些连接按实际目标地址检查权限。经代理访问时，沙盒检查代理端点，最终网站范围由代理控制。macOS 使用整体网络开关，不提供目的地址或流量额度控制。断网、撤权及平台支持的网络额度继续生效，代理失败不会自动切回直连。

当前浏览器会话启用代理时，标题栏显示「代理已启用」标签；直连或尚未启动时不显示网络标签。助理通过 `browser_session` 的 start/status 获取相同的脱敏代理摘要，不包含认证账号和密码。导航失败返回浏览器错误码与同期沙盒事件；同期事件不一定是当前导航的失败原因，未能确定原因时明确标注。最近失败记录包含任务和时间，后续导航成功或新任务启动后更新；配置已保存不代表连接验证成功。
