# 接入 llama.cpp

返回[模型接入概览](../models.md)。Molr 已提供 llama.cpp 连接预设。

## 连接配置

| 配置项 | 值 |
| --- | --- |
| 预设 | llama.cpp |
| 默认基础地址 | `http://127.0.0.1:8080/v1` |
| 认证 | 默认无认证；服务配置了 Bearer API Key 时填写对应密钥 |

先运行 llama.cpp 的 HTTP 推理服务，再选择 llama.cpp 预设或本机发现结果。Molr 连接 OpenAI 兼容接口，不负责加载模型文件、启动服务或选择服务端聊天模板。

按[通用连接步骤](../models.md#连接提供商)测试、保存并刷新模型。地址中的本机指 Runtime 所在设备；私网／回环地址需获 Runtime 网络配置允许，容器部署也应核对网络可达性。

## 能力与验收

工具调用取决于模型及聊天模板。验证工具请求、参数和结果回传；上下文容量应与服务实际配置一致。配置模型价格，免费部署明确填写 0。

若提示聊天模板或工具解析错误，先修复推理服务设置，再发送新消息验证。通用网络排查、凭据维护与预算见[模型接入概览](../models.md)。
