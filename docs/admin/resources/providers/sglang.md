# 接入 SGLang

返回[模型接入概览](../models.md)。Molr 已提供 SGLang 连接预设。

## 连接配置

| 配置项 | 值 |
| --- | --- |
| 预设 | SGLang |
| 默认基础地址 | `http://127.0.0.1:30000/v1` |
| 认证 | 默认无认证；服务配置了 Bearer API Key 时填写对应密钥 |

选择 SGLang 预设或本机发现结果；在「更多配置」修改地址可连接其他部署。Molr 使用 OpenAI 兼容 Chat Completions，不包含 SGLang 原生推理 API 或厂商专属 reasoning 字段适配。

按[通用连接步骤](../models.md#连接提供商)测试、保存并刷新模型。地址中的本机指 Runtime 所在设备；私网／回环地址需获 Runtime 网络配置允许，容器部署也应核对网络可达性。

## 能力与验收

配置匹配的聊天模板和工具解析器，再验证连续工具调用。目录中的合法 `context_window` 优先，其次采用 `max_model_len`；刷新保留手动覆盖。能力以实际部署为准，免费模型也需明确填写零价格。

若提示聊天模板或工具解析错误，先修复推理服务设置，再发送新消息验证。通用网络排查、凭据维护与预算见[模型接入概览](../models.md)。
