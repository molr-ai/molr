# 接入 vLLM

返回[模型接入概览](../models.md)。Molr 已提供 vLLM 连接预设。

## 连接配置

| 配置项 | 值 |
| --- | --- |
| 预设 | vLLM |
| 默认基础地址 | `http://127.0.0.1:8000/v1` |
| 认证 | 默认无认证；服务配置了 Bearer API Key 时填写对应密钥 |

选择 vLLM 预设或本机发现结果；在「更多配置」修改地址可连接其他设备或端口。Molr 使用通用 Chat Completions，不会根据模型名切换到 DeepSeek 专属协议。

按[通用连接步骤](../models.md#连接提供商)测试、保存并刷新模型。地址中的本机指 Runtime 所在设备；私网／回环地址需获 Runtime 网络配置允许，容器部署也应核对网络可达性。

## 能力与验收

服务端需配置适合模型的聊天模板和工具解析器。目录中的合法 `context_window` 优先，其次采用 `max_model_len`；刷新保留手动覆盖值。配置图片等能力与价格，免费部署明确填写 0。

若提示聊天模板或工具解析错误，先修复推理服务设置，再发送新消息验证。通用网络排查、凭据维护与预算见[模型接入概览](../models.md)。
