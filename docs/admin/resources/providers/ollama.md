# 接入 Ollama

返回[模型接入概览](../models.md)。Molr 已提供 Ollama 连接预设。

## 连接配置

| 配置项 | 值 |
| --- | --- |
| 预设 | Ollama |
| 默认基础地址 | `http://127.0.0.1:11434/v1` |
| 认证 | 默认无认证；服务配置了 Bearer API Key 时填写对应密钥 |

先在 Runtime 可访问的设备运行 Ollama 并准备模型，再选择 Ollama 预设或本机发现结果。Molr 使用其 OpenAI 兼容接口；基础地址应包含 `/v1`，不是原生 `/api/chat`。

按[通用连接步骤](../models.md#连接提供商)测试、保存并刷新模型。地址中的本机指 Runtime 所在设备；私网／回环地址需获 Runtime 网络配置允许，容器部署也应核对网络可达性。

## 能力与验收

模型下载与服务启动由管理员完成。工具、图片和上下文容量按实际模型与服务设置配置；本机发现不会证明这些能力可用。自托管不自动视为免费，免费部署需明确填写 0。

若提示聊天模板或工具解析错误，先修复推理服务设置，再发送新消息验证。通用网络排查、凭据维护与预算见[模型接入概览](../models.md)。
