# 连接与管理模型

本页面向管理员。先连接提供商，再通过[用户组](../administration/users-and-groups.md)分配成员可用的模型与工具。

## 连接提供商

在「资源 → 模型」右上角更多菜单中选择「连接提供商」，填写服务地址和认证信息，测试连接后保存。一个提供商连接可以包含多个模型。

百炼、智谱和 Moonshot 预设通过 OpenAI 兼容接口连接。保存后可刷新模型列表；模型价格未覆盖时需手动配置。连接成功只表示接口可访问，实际推理和工具调用仍需所选模型支持。

## 连接 vLLM 与 SGLang

在「资源 → 模型 → 连接提供商」选择 vLLM 或 SGLang，也可通过「本地」筛选找到。默认连接 Runtime 所在设备：vLLM 为 `http://127.0.0.1:8000/v1`，SGLang 为 `http://127.0.0.1:30000/v1`。在「更多配置」修改地址以连接其他部署；这里的本机地址指 Runtime 所在机器，不是浏览器所在设备。

默认无需认证；服务启用 API Key 时选择对应认证方式并填写密钥。可先测试连接，保存后自动获取 `/v1/models` 中的模型，后续可以刷新列表或编辑连接。Runtime 必须通过 `network.allowed_private_ips` 允许目标私网／回环 IP，选择预设不会绕过网络限制。

两种预设使用 OpenAI 兼容 Chat Completions。服务端需配置适合模型的聊天模板；助理工具调用还需启用服务端对应的工具解析器。图片、音频等能力按实际模型配置，不从模型名称猜测。模型列表返回的 `max_model_len` 会作为上下文上限；手动覆盖值在刷新后保留。自托管不自动视为免费，使用前请配置实际价格（免费部署可明确填 0）。

若模型提示聊天模板或工具解析错误，先核对服务端模板配置；维护者可参考[模型适配说明](../../dev/runtime/model-adapters.md)。修复后发送新消息发起新的调用。

## 价格、凭证与维护

使用前核对模型能力、上下文容量和价格；明确免费时才填写 0。模型网络许可与外置价格文件由部署者维护，见[模型网络与价格配置](../deployment/configuration.md#模型网络与价格配置)。

提供商密钥通过资源配置保存，更换时不回显旧值。删除提供商会清理连接、相关模型与权限，保留助理和聊天；失效模型需要重新选择。

模型服务收到的请求携带 `User-Agent: molr/<版本号>`，用于服务日志识别；开发构建未注入版本时使用 `molr/development`，连接测试和模型列表查询也使用该标识。

连接不会自动授权全部模型。用户为自己的助理选择模型、设置预算和授权，见[权限与预算](../../user/guides/permissions-and-budget.md)。

### 连接被网络配置拒绝

模型列表查询和推理由 Runtime 直接发出，受顶层 `network.allowed_private_ips` 限制；沙盒 Shell 使用独立的 `sandbox.networks`，配置沙盒网络不会放行模型地址。私网或回环 IP 未获允许时，连接窗口会提示部署者将目标 IP 加入 `network.allowed_private_ips` 并重启 Runtime。公网 HTTP 地址需改用 HTTPS；云元数据、链路本地等禁止地址不能通过白名单放行。

## 本机模型自动发现


首次引导和「资源 → 模型 → 连接提供商」都自动检测 **Molr 所在设备** 的常用端口：Ollama 11434、llama.cpp 8080、vLLM 8000、SGLang 30000。探测仅读取接口与模型列表，不启动服务、不下载模型、不发送推理请求。无法确认实现类型时显示 OpenAI 兼容服务。

自定义端口或其他设备可手动填写地址。服务需要认证、暂无模型或已经连接时会明确提示。容器里的本机地址指容器网络；发现结果不表示模型工具调用已经验证，也不代表服务免费。

源码部署和离线安装分别见[源码构建](../deployment/source-build.md)与[安装指南](../deployment/installation.md)。
