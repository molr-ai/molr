# MCP 工具

管理员可以在「资源 → 工具 → MCP 工具」连接远程 MCP 服务。内置工具和插件工具使用各自的分类；关闭插件显示不会隐藏 MCP 工具。

## 连接与授权

1. 点击「添加 MCP 连接」，填写名称和完整 HTTPS Streamable HTTP 地址，例如 `https://mcp.example.com/mcp`。
2. 选择无认证、Bearer Token 或 API Key。API Key 请求头支持 `X-API-Key`、`API-Key`、`X-Auth-Token`；凭证加密保存，页面不会读回明文。
3. 设置累计调用上限、并发上限和请求超时，保存后点击「测试并刷新工具」。测试执行工具发现，不调用业务工具。
4. 工具目录按连接分组。点击工具查看描述和参数，在详情底部启用，再通过「授权助理」授予执行权限。也可在助理信息的权限中选择该工具。
5. 普通成员还需要管理员在用户组中同时开放对应连接和工具。组内成员的助理仍需要各自的工具授权。

资源管理页仅管理员可访问。成员在助理权限与工具能力中使用已开放的工具；连接地址、凭证和跨成员调用记录不向成员公开。

公网地址必须使用 HTTPS；私网服务还需要部署者在 `network.allowed_private_ips` 放行，并使用 Runtime 信任的 TLS 证书。地址不能包含账号、查询串或片段。连接测试与工具调用由 Runtime 发出，因此服务必须能从 Runtime 所在机器访问。

## 更新与停用

刷新保存服务的工具目录快照，普通页面读取和模型上下文装配不访问远端。新增工具默认未启用；工具名称、描述或参数结构变化会生成新标识，需重新启用并授予助理权限，旧工具授权不再生效。原样返回的工具保留启用状态和授权。

服务地址和认证方式在创建后固定；更换服务时新建连接。更换密钥会停用现有工具，并要求重新发现和启用。停用或删除连接阻止新调用并取消本地在途请求；远端已接收的操作可能继续执行。删除同时删除专用凭证，历史调用记录保留。

## 调用记录与限制

连接详情展示最近 100 次调用的时间、工具、状态和耗时。超时、断线或 Runtime 重启后无法确定远端结果时，记录为「结果未知」，不自动重试。先核实外部系统中的实际结果，再决定是否发起新操作。工具返回业务错误与未发出调用分别展示。

累计调用上限和连接并发上限覆盖所有成员；用户组还可以配置每位成员的连接、工具调用额度。调用获准后计入连接次数；失败和未知结果不会退款，本地请求结束即释放并发名额。

当前支持文本和结构化 JSON 返回；非文本内容标明已省略，资源链接不自动抓取。暂不支持 stdio、本地进程启动、OAuth、Resources、Prompts 和交互请求。参数支持嵌套对象和数组，不支持 Schema 引用及 `x-mcp-header` 参数头映射；不兼容的工具会标明原因。

每个实例最多 32 个未删除连接；每个连接最多发现 128 个工具、16 页及 512 KiB 目录。单工具 Schema 最多 32 KiB，描述最多 16 KiB，调用参数和结果分别最多 64 KiB。单次连接操作累计读取最多 4 MiB，超时可设为 1–60 秒，并发为 1–16。

实现与接口见 [MCP 接入](../../dev/extensions/mcp.md)。
