# 用户与用户组

Molr 支持家庭和小团队在同一服务上使用独立账号。管理员创建账号，不提供公开注册。用户之间没有共享空间、群聊或数据交换功能。

## 两个设置入口

桌面侧边栏底部的头像、手机助理页顶部的头像和用户名打开**用户设置**，管理显示名称、语言、主题、时区、回答偏好、记忆、个人用量和账号安全。用户设置中的「管理员设置」入口打开**管理员设置**，只有管理员可见，包含用户、用户组、汇总统计和插件管理。资源配置统一从侧边栏的**资源**页面进入。

普通用户可以创建、修改自己的助理，设置助理预算和资源授权。普通用户不能配置模型、工具或沙盒，也不能安装、配置或启用插件。管理员已启用并分配的插件能力可以在授权范围内使用。

## 创建用户组并分配资源

1. 管理员先在资源页面配置模型和沙盒；插件在管理员设置中管理。
2. 在管理员设置 → 用户组中新建组，从现有目录勾选模型、工具或沙盒，再设置对应配额。这里仅保存资源引用，不会复制连接、密钥或沙盒配置。
3. 在管理员设置 → 用户中添加用户，指定用户名、初始密码和用户组。用户登录后可自行修改密码和设置二次验证。

新建普通用户组默认没有资源。支持普通聊天至少需要一个模型及 `conversation_read`、`conversation_publish` 工具；命令和文件能力还需要相关工具、沙盒引用以及助理自己的资源授权。

删除引用会使现有助理也失去对应访问权限。已经创建的聊天、助理和附件保留。停用或更换用户组会撤销该账号已有会话、令牌和一次性登录链接。删除组前须移走其成员；最后一个正常管理员不能被停用或降级。

## 配额如何计算

每位成员独立继承组的额度上限，在自己的全部助理之间累计，其他成员不会消耗这份额度。用户组没有额外的助理预算池。

| 资源 | 可设上限 |
| --- | --- |
| 模型 | 周期费用、调用次数、并发调用数 |
| 工具 | 周期调用次数、并发调用数 |
| 沙盒 | 并发执行数、计算资源、网络流量与连接数、工作区存储 |

模型和工具可以按日、周、月或累计计量，按指定时区确定周期。留空费用上限、将调用或并发上限设为 0，表示该项没有组级限制。模型调用先预留费用，结束后按已知费用结算；费用未知时自动结束预留和并发占用，保留未知记录。已发出且结果未知的调用继续计入原周期调用次数，不会永久跨周期占用。

计算资源对同一账号的并发助理汇总限制 CPU、内存和进程数，同时限制单次执行时长和临时空间。网络同时受助理额度和账号额度限制；更换组或修改统计周期不会清空用量，周期变更时重叠旧周期用量会保守地计入新周期。

存储上限要求沙盒已配置存储硬配额。账号的存储容量按其所有助理获授权的工作区容量合计预留；撤销授权不会自动释放原有容量，需显式调低助理容量。未配置硬配额时不能启用这项限制。远程沙盒还需升级到支持用户组配额的版本。

内置管理员组自动可用全部现有及新增资源，没有组级限额。管理员的助理仍受自身授权、预算和资源限额约束。普通用户额外经过组级资源及配额检查；部署端上限也始终生效。

## 数据隔离与统计

聊天、附件、助理、计划、记忆、执行输出和个人设置按账号隔离。管理员可以查看账号的模型／工具／HTTP 连接调用数、已消费和预留费用、历史结果未知调用及附件总量；产品不提供查看其他用户详细数据的入口或越权接口。服务器管理者仍可以直接登录服务器读取磁盘数据，项目不对抗这种访问。

用户设置 → 用量分为累计用量和当前成员额度。费用与调用数为累计统计，附件为当前占用；模型、工具和连接按各自周期展示调用占用、并发占用与下次重置时间。跨周期仍在执行的调用继续占用额度；已结束且结果未知的调用仅作为历史记录展示，不要求手动处理。沙盒条目显示成员配置限额，实时资源用量在助理权限详情中查看。管理员的个人用量页仅显示累计用量，不显示当前成员额度区域；助理自身预算仍生效。

管理员设置 → 用量统计支持按用户名／显示名称和用户组筛选，汇总随筛选变化，展开成员可查看明细。HTTP 工具调用也计入工具次数，两者不可相加。预留费用尚未确认为实际消费；本地调用结束或 Runtime 启动恢复时自动清理占用，未知费用不计入已确认消费。

普通用户暂不能创建无需身份验证的公开端口转发。该入口会把助理工作区内服务直接暴露给访问者，因此当前只保留管理员已有的端口转发能力。

旧单账号服务需先停服并显式执行[一次性转换工具](deployment/multi-user-upgrade.md)，新版不会在启动时自动迁移。转换保留原账号 ID、凭证与私人数据，并将原账号设为管理员；原资源成为全局资源目录。
