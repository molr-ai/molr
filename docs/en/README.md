# Molr documentation

Choose a guide for the task you want to complete. The same person can deploy a service and then use assistants as an ordinary user.

| Guide | Tasks |
| --- | --- |
| [User guide](user/README.md) | Sign in, chat, schedule plans, manage assistant permissions and personal settings |
| [Administrator guide](admin/README.md) | Install the service, connect models and sandboxes, manage members, update and back up |
| [Developer documentation](dev/README.md) | Contribute, understand implementation, consult APIs and maintain releases |

With an existing service and account, follow the [user quick start](user/getting-started.md). To host your own service, begin with [Set up a Molr instance](admin/getting-started.md).
