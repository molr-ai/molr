# Connect OpenAI

Return to the [model connection overview](../models.md). This guide distinguishes the standard API from ChatGPT subscriptions.

## Standard API

Select OpenAI in "Resources → Models → Connect Provider", use `https://api.openai.com/v1`, and enter a key with API access. Test, save, refresh models, and configure their capabilities and prices.

The preset uses Chat Completions. Choose a model supporting that API; catalog presence does not establish protocol support. Responses-only models cannot currently be used directly. API keys and ChatGPT login are separate authentication methods; see [official authentication guidance](https://learn.chatgpt.com/docs/auth).

## ChatGPT subscriptions

Molr does not currently provide built-in support for this subscription plan. To use it, see [How to connect subscription plans](../models.md#how-to-connect-subscription-plans).
