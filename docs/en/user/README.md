# Molr user guide

This guide is for members using an existing Molr service. Start with a service address and account, use assigned resources, and manage your own assistants and tasks. For hosting or member management, see the [administrator guide](../admin/README.md).

## Getting started

- [Quick start](getting-started.md): sign in, choose an available model, hire an assistant and complete your first task.
- [Core concepts](concepts.md): assistants, plans, memory, resources and data boundaries.

## Everyday use

- [Assistants and chat](guides/assistants-and-chat.md), [Plans and execution](guides/plans.md): assign tasks, schedule work and inspect results.
- [Memory and automatic review](guides/memory.md): view, edit, confirm or forget memories.
- [Permissions and budgets](guides/permissions-and-budget.md): authorize resources for your assistants, set limits and revoke access.
- [Files and commands](guides/files-and-commands.md): workspaces, background tasks, terminals and temporary services.
- [Plugins and Skills](guides/plugins-and-skills.md): use assigned plugins and install CLI tools or Skills in assistant workspaces.
- [Personal settings](guides/settings.md), [Account security](guides/account-security.md): appearance, notifications, usage, exports, passwords and signed-in devices.

## Chat channels and practical tasks

[WeChat](chat-channels/weixin.md) covers binding, messages and disconnecting. Explore [best practices](best-practices/README.md) for browsers, DingTalk, Feishu, email, Zhihu, GitHub and Google services.

## When something goes wrong

Use [Troubleshooting](troubleshooting.md) to check connections, permissions, budgets and execution status. Contact your administrator with the error and version when resources or server configuration need changes.
