# Operate a Browser

Browser operation is being integrated. A built-in workflow for operating a browser is not yet available.

## Work with Web Content Today

To have your assistant read a page, paste its text into chat or save it as a file and upload it. Specify whether you want a summary, comparison, or extracted information. For example:

> [!PROMPT]
> Compare the features, intended uses, and pricing in the three product descriptions I uploaded. Present the differences in a table and identify the source file for each point.

See [Assistant & Chat](../guides/assistants-and-chat.md) for uploads and [Files & Commands](../guides/files-and-commands.md) for organizing files. Saved files reflect the content at the time of capture; provide fresh material when you need current information.
