# 快速开始

> [!WARNING]
> **项目状态：** Molr 仍处于开发阶段，尚未发布稳定版，可能存在不稳定行为，后续版本也可能包含破坏性变更。

<!-- -->

> [!WARNING]
> **使用环境：** 目前不建议将 Molr 服务直接暴露到公网，请在可信局域网等安全网络环境中使用。

从安装 Molr 到完成第一次委托。已有可访问的服务时，直接从[登录](#登录)开始；长期运行与维护配置见[部署与维护](deployment/README.md)。

## 安装 Molr

从官网安装区选择一个已有版本的渠道，再选择目标平台。可用版本以官网发布清单为准；暂无版本的渠道不会提供下载入口。当前平台定义为 Linux amd64／arm64，安装包包含 Runtime 与 WebUI，静态 BusyBox 等沙盒依赖通过目标机系统包管理器提供。

直接运行官网安装脚本并选择渠道，无需保存脚本文件：

```bash
curl -fsSL https://molr.ai/install.sh | sh
```

示例使用 stable；该渠道暂无版本时，在官网选择已有版本的 preview 或 nightly，并使用官网生成的固定版本命令。使用者无需安装 Go、Node.js 或单独部署网页。

首次安装默认使用当前普通用户、从 8787 开始选择空闲端口、安装 systemd 用户服务并生成独立配置。root 执行时须通过 `--user molr` 指定非 root 运行账户。依赖缺失时，apt 系系统会询问是否安装；其他系统需按输出补齐依赖。systemd 用户管理器必须可用；需要退出登录后继续运行时，按安装提示配置 linger。

安装完成会输出局域网访问地址和有效期 15 分钟的一次性登录链接。点击链接并确认登录后进入首次引导：

1. 选择自动发现的本机模型服务，或配置一个云端／自定义 Provider。
2. 连接后确认所选模型及默认每日 USD 1 预算，可以修改。未知价格需要补充；填 0 表示明确确认免费。
3. 点击「开始使用」，自动创建 **Molr** 助理并进入聊天。首次问候会调用所选模型并计入预算。

语言和时区根据浏览器设置。安装过程中自动创建 `owner` 账号，随机初始密码保存在数据目录的 `initial-password` 文件（0600）；具体路径显示在终端。后续可以修改密码并自行删除初始密码文件。需要重新生成登录链接时，使用安装目录的程序：

```bash
/path/molr access -config /path/server.json
```

未保留初始密码或已经改密时，通过 `-password-stdin` 输入当前密码；启用 MFA 后还需 `-mfa-code`。重跑安装会保留原配置、账号和数据，不重置密码或重复创建助理。

局域网可以使用 HTTP，无需证书。HTTP 不加密密码、会话及消息，仅适用于可信网络。HTTPS 配置见[部署与维护](deployment/README.md)。系统通知等浏览器能力可能要求 HTTPS，页面内提醒仍可使用。

### 本机模型自动发现

首次引导和「资源 → 模型 → 连接提供商」都自动检测 **Molr 所在设备** 的常用端口：Ollama 11434、llama.cpp 8080、vLLM 8000、SGLang 30000。探测仅读取接口与模型列表，不启动服务、不下载模型、不发送推理请求。无法确认实现类型时显示 OpenAI 兼容服务。

自定义端口或其他设备可手动填写地址。服务需要认证、暂无模型或已经连接时会明确提示。容器里的本机地址指容器网络；发现结果不表示模型工具调用已经验证，也不代表服务免费。

源码部署和离线安装分别见[源码构建](deployment/source-build.md)与[安装指南](deployment/installation.md)。

## 登录

首次管理员使用初始化时创建的账号登录；普通成员使用管理员创建的账号。没有默认用户名密码组合或公开注册入口。启用了二次验证时，按页面提示输入验证码或恢复码。

已有登录设备可以在“用户设置 → 安全 → 登录链接”生成一次性链接，用于另一设备登录。链接有有效期，只能使用一次；启用 MFA 时仍需二次验证。链接应只交给本人或明确授权的使用者，不要放进公开文档。

## 连接模型

管理员进入“资源”，选择模型类别并连接提供商。普通成员无需配置连接，由管理员通过[用户组](administration/users-and-groups.md)分配可用模型和工具；已有可用模型时可直接聘请助理。填写服务地址与所需 API Key，本地免认证服务可按其要求选择免认证。

可以先测试连接，再保存并获取模型列表。测试成功只说明模型列表接口可访问，实际推理和工具调用仍取决于所选模型能力。模型列表为空或缺少能力、价格时，在模型配置中补充。

不知道价格时不要填零；明确设置为零代表确认该项免费。连接本机模型时，地址指 Runtime 所在设备，而不是浏览器所在的电脑。部署网络策略可能需要管理员调整，见 [部署说明](deployment/configuration.md#模型网络与价格配置)。

## 聘请助理

为助理设置名字、支持工具调用的模型、消耗上限及每日或每周重置周期。聘请时会授权所选模型；不会同时授权该提供商下所有模型或你的文件目录。

预算属于助理。该助理的聊天和所有计划执行共用额度，没有单独的任务预算。详细规则见 [资源、权限与预算](guides/permissions-and-budget.md)。

## 交代第一件事

先选择你能核对结果的小任务，例如上传一份资料，请助理列出要点与待确认问题，并指出依据。说明输入、期望结果和不要改变的原件，有助于判断是否完成。

附件发送、模型回复或工具操作可能失败，留意页面中的状态与原因。普通对话不强制生成计划；模型明确创建任务时，执行会关联计划。实际可处理的文件类型和内容规模受模型与部署能力限制。

## 查看结果并继续

在聊天和“计划”中查看相关执行及产物；已有交付物可以下载，任务修订保留历史版本。收到一段回复并不等于资料已经修改或任务已经验收，核对实际结果与明确的完成状态。

需要助理读取外部目录时，再连接该目录并授予范围；需要执行命令时，另外授予就绪计算环境的执行权限。操作路径见 [助理、聊天与计划](guides/assistants-and-chat.md) 和 [Linux 命令环境](sandbox/linux.md)。
