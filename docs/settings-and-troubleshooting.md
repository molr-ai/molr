# 设置、安全与常见问题

桌面点击侧边栏底部头像进入用户设置；手机点击助理页顶部的头像和用户名进入，底部导航只保留业务页面。管理员在用户设置中点击「管理员设置」进入管理页面，可通过页头返回用户设置。用户、用户组、用量统计、开发工作台和插件管理位于管理员设置；资源配置从侧边栏的资源页面进入。详见[用户与用户组](users-and-groups.md)。

## 个人资料与头像

在用户设置 → 个人资料中设置显示名称和头像。可选择预设头像，或上传不超过 10 MB、4000 万像素的 PNG、JPG、WebP 图片；图片会在浏览器内居中裁剪为 256 × 256 的缩略图。点击「保存」后，桌面侧栏和手机顶部显示新头像；清除并保存后恢复名称首字符。头像随账号保存，换设备登录后仍可使用。

## 常规、主题与记忆

常规设置管理语言、时区、币种等偏好。主题页区分界面主题、配色和明暗模式，保存到账号后可在其他设备读取；提供默认、测试两套内置主题，也可选择管理员已安装、授权并启用的[插件主题](plugins.md)。主题配色可选森林、海盐蓝、鸢尾紫、暖砂、玫瑰和素墨，均支持浅色与深色显示。素墨使用中性灰阶界面，成功、警告、错误等提示保留语义色。

记忆用于保存事实，回答偏好用于沟通方式。同一账号内的共享和助理私有记忆具有不同范围，不会跨账号共享；修改或删除记忆影响后续使用，不等于删除原聊天记录。详细执行上下文是另一类内部状态。

记忆以 Markdown 文件保存在助理本地工作区：`/work/MEMORY.md` 放自动加载的核心认知，`/work/.agents/memory/` 放按需查阅的主题记忆；同一账号的共享文件位于 `/global` 对应目录。文件工具和 Shell 读取同一份内容，可以用 `rg` 搜索。支持 `用户偏好/沟通偏好.md` 这样的分类目录和语义文件名。界面可新建目录、重命名、移动和删除空目录；同名创建不会覆盖。直接修改文件后刷新记忆页即可看到变化；`/global` 对助理的普通命令只读。远程电脑不存放助理工作区或记忆。

界面的“遗忘”会删除文件并记录需要抑制的来源；界面的普通删除或直接删除 Markdown 只移除文件，日后可能再次从原始资料整理出来。做梦通过文件工具读取、更新、合并、移动和删除主题，并维护核心认知；文件操作逐次生效，停止或超时不会回滚已经成功的操作。在记忆界面保存或确认的文件会标为只读，直接编辑普通 Markdown 不会自动锁定文件。撤销已完成批次可恢复未被后来修改的文件操作。

## 登录与设备

安全设置支持修改密码、二次验证、恢复码、设备会话和一次性登录链接。退出或撤销设备会话终止该设备访问，不会自动取消后台任务。

一次性链接可选择 15 分钟、1 小时或 24 小时有效期，仅显示完整链接一次；已用、过期或撤销后不能继续兑换。启用二次验证时仍要求验证码。需要新的链接时，从已登录设备重新生成。

“敏感操作验证”默认关闭，开启后保存／更换凭证及数据导出需要再次验证；修改密码与安全设置始终要求身份确认。账户无法登录时，由部署者按 [本机恢复流程](deployment/README.md#备份恢复与升级) 处理。

## 系统提醒

微信投递／连接异常、助理持续受阻、授权请求、计划待交接和任务／后台执行失败由服务端统一管理提醒状态。后台执行失败提醒在开发工作台可用且已设置显示时显示「在开发工作台中查看」，点击定位对应执行；未设置显示时保留提醒和关闭按钮，不显示查看入口。未采集或已过期的执行会明确提示记录不可用。其他提醒直接进入对应的聊天、授权、任务或计划页面；需要长期查阅的内容保留在对应业务页面，不设独立通知历史页。

聊天一次显示一条提醒，并显示剩余数量。当前提醒不会被新到达的提醒打断；关闭成功后按发生顺序显示下一条，关闭失败时保留当前条。关闭状态在设备间同步，刷新不会重新出现同一次提醒；关闭不会重发消息、取消任务或改变业务处理结果。问题恢复后提醒自动消失，新的异常会产生新的提醒。

用户设置的“通知设置”管理当前浏览器的提醒、预览、声音和桌面通知。关闭主动提醒不影响聊天内的待处理提醒或消息未读计数。可信 HTTPS／本机环境可授权桌面通知；页面关闭后暂不推送，重新打开可在相应聊天查看仍待处理的提醒。桌面通知自动收起和 Toast 自动消失不等于已读或已解决。

## 等待与失败

| 页面现象 | 可以检查什么 |
| --- | --- |
| 模型无权限 | 当前助理是否已获得该模型的调用授权，授权是否过期 |
| 模型价格缺失 | 模型配置是否有明确价格；不要为了绕过等待而随意填零 |
| 预算不足 | 当前周期用量、执行中预留、助理额度，以及当前用户组授予该账号的额度 |
| 提供商认证失败或限流 | 连接地址、Key 和供应商配额；等待后再决定是否重试 |
| 本机模型连接被拒绝 | 地址是否指向 Runtime 主机，部署网络策略是否允许 |
| 命令环境不可用 | 查看 [Linux 命令环境诊断](deployment/sandbox.md#检查与验证)，不要改为无隔离执行 |
| 客户端断线 | 网络和 Runtime 是否在线；页面重连后核对消息与执行记录 |
| 结果待核对 | 先确认实际操作和产物；不要直接重复可能已生效的操作 |

导航连接图案反映客户端连接状态，不代表所有任务成功。调整权限、资源或预算后，按任务当前提供的操作继续；不要仅因保存设置成功就认定旧任务已经恢复。

## 关于 Molr

用户设置最后一栏「关于」显示版本号和 WebUI 构建时的 Git commit ID，点击 commit 可查看对应代码。下方可前往 [Molr GitHub 项目](https://github.com/molr-ai/molr)，为项目点 Star。完整 Logo 使用昼夜循环动画，按设备本地时间在 08:00 和 20:00 自动切换，沿用减少动态效果偏好。

## 数据与帮助信息

设置中的数据导出用于取得用户数据，不是完整服务灾备。部署者仍需备份数据库、文件、助理工作区、配置和密钥，见 [部署与维护](deployment/README.md)。

开发工作台的采集由服务端 `debug.enabled` 控制，默认关闭；服务端开启后会持续记录所有账号的执行。常规设置「显示开发工作台」只控制导航、聊天菜单和通知等入口，隐藏入口不会停止采集，已有链接仍可访问。打开显示后可查看保留范围内此前采集的记录；未采集或已过期的记录无法补回。服务端关闭采集时工作台不可用，但不会立即删除已有记录。排查模型调用可参考 [工作台文档](../dev-docs/runtime/WORKBENCH.md)。记录容量与保留期限仍然适用，不能代替业务历史或完整备份。

工作台的助理选择器只列出在职助理；已有链接仍可打开离职助理的工作台。

工作台标题下方是时长轴／事件轴，筛选、原始事件、跟随最新与搜索紧凑排列在轴下方的一行，不再显示「连续轨迹」标题统计、列表表头或轴底部横坐标。执行编号直接显示整数，不补前导零。同一轮的重试共用一条触发消息，轮次状态跟随最新尝试；各次模型请求及其详情独立保留。普通请求隐藏尝试次数及 HTTP 状态，重试请求标记为「重试 1/3」；完整信息可在详情中查看。

轨迹中的工具摘要按操作展示：发送消息只显示正文，读取聊天记录显示实际读取条数，文件操作显示路径，命令执行显示命令，记忆搜索显示查询内容。点击记录可查看完整输入和输出；执行中、失败或未采集结果时不会显示推算的成功条数。

加载到轨迹起点后，以独立提示显示「没有更早的事件」；当前助理实际发生清理后，显示「更早的事件已被清理」。悬停或点击可查看清理时的条数策略。默认每个账号保留最多 1000 次执行，所有助理共享，包含做梦记录。管理员在「管理员设置 → 开发工作台」修改执行次数上限；留空恢复部署默认值，保存后无需重启。

超过条数上限时，最早的已完成执行在后续采集写入或执行结束时清理；运行中的执行保留到结束。不再按天数或详情总容量清理，也不会因为旧记录占满详情额度而跳过新详情。单条详情仍有采集大小限制。工作台历史与 Agent 当前上下文独立引用共享存储，删除历史不会影响执行恢复；没有任何引用的内容由后台自动回收。

检查点用于中断后的执行恢复，因此执行过程中仍持续保存完整的最新状态。工作台的中间「检查点已保存」事件只记录版本、时间、原因和大小，减少重复存储；查看完整内容请打开模型调用的「调用上下文」或「最新检查点」。

工作台可查看已采集的模型请求、响应、工具结果与上下文；未采集或已过期的内容不能补推。模型未返回的内部推理不会展示。具体视图和采集边界由[工作台文档](../dev-docs/runtime/WORKBENCH.md)统一维护。
