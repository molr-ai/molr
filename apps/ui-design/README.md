# Molr UI Design

品牌与基础界面组件的展示应用，包名为 `@molr/ui-design`。页面示例和布局放在本目录，可复用的组件、变量与品牌资源由 [`@molr/ui`](../../packages/ui/README.md) 提供。

在仓库根目录运行：

```bash
npm ci
npm run dev:design
npm run build
npm run preview
```

也可以通过 `npm run dev --workspace @molr/ui-design` 等工作区命令运行。开发服务保留 `0.0.0.0:5188`，生产构建输出至本目录的 `dist/`。根目录 `npm run build` 构建所有提供 build 脚本的工作区；仅构建本应用时使用 `npm run build --workspace @molr/ui-design`。

Vite 的 `publicDir` 指向共享 UI 包的 `public/`，开发时直接提供 Logo，构建时复制到产物中，统一使用 `/brand/*.svg` 路径。字体由本应用加载 DM Sans；页面专用布局与基础页面样式保留在 `src/styles.css`。

`#app-icon` 是独立的 Identity 区域，可切换圆角／直角版本，图标、小尺寸预览及下载链接随之更新。两版均提供 SVG 原稿以及 16、32、48、64、128、180、192、256、512、1024 px 的 PNG 下载。PNG 位于共享资源目录，由 `npm run brand:generate` 从图标原稿重新生成；开发与构建后的页面均可直接下载。

导航右侧提供跟随系统、浅色、暗色三种外观选择，默认跟随系统。偏好保存在 `localStorage` 的 `molr-theme` 中，并在同源标签页之间同步；浏览器禁用存储时仍可在当前页面切换。共享 `/theme-init.js` 在应用加载前应用主题，避免暗色页面先闪白，后续由 `@molr/ui` 的 `useTheme` 同步系统变化、共享颜色变量及浏览器主题色。暗色模式下，导航和页脚使用反白 Logo；青柠主视觉与浅色 Logo 样例继续使用深绿字形。外观选择与 Logo 的昼夜动作编排分别生效。

主题选择使用基于 `Select` 的共享 `ThemeSelect` 组件。`#components` 展示带说明的选项、占位与错误、整组禁用等状态；支持鼠标、触摸和键盘选择。手机导航保留图标入口，弹层按视口空间调整位置。

语言选择也使用同一 `Select`，提供简体中文和 English。首次访问按浏览器的语言优先级选择中英文，其他语言回退到英文；手动选择保存于 `molr-ui-design-locale`，并在同源标签页之间同步。存储不可用时仍可在当前页面切换。品牌文案位于 `src/messages.ts`，组件示例位于 `src/library-messages.ts`，产品交互文案按模块集中在 `src/i18n/`，均采用结构化字典及同一套语言类型约束。涵盖动画说明、组件示例、产品操作、反馈、读屏标签和页面元信息。切换语言保留表单与选项状态，并延续正在播放的 Logo 动画。英文页脚使用 “It starts with curiosity.”。

顶部导航、首屏主视觉和页脚 Logo 使用昼夜动画：本地时间 08:00–20:00 安静好奇，其余时间亲近俏皮。三处均可点击跳过动作间的等待；顶部 Logo 为独立动画按钮，避免与页面跳转冲突。动画不显示状态文字或悬停提示，保留读屏标签和键盘操作。系统启用减少动态效果时显示静态标识。

本应用承载设计示例。真实产品已位于 [WebUI](../webui/README.md)，继续复用共享 UI 包。

`#interfaces` 是个人 AI 助理原型，用户文案统一使用「任务」。Web、Desktop 共用页面实例，Mobile 提供独立触屏布局，CLI 使用 `task` 命令；四端共享当前助理的对话和草稿；任务与资源权限按助理区分，预算和个人偏好仍由用户管理。一级模块为助理、计划、资源、设置；执行任务归属助理对话；真实产品能力见 [产品范围](../../dev-docs/PRODUCT_SCOPE.md)。

首页为当前助理的唯一持续对话，可切换多个助理，普通聊天、委托、追问和追加修改都在这里。任务从对话产生；任务详情回到对话时带上引用，追加要求更新同一任务并保留旧版交付物。权限授予助理，其任务复用权限，其他助理不继承；任务详情可推进读取、整理、生成与验收四个步骤，查看模拟费用、调用次数、操作记录、检查点与下载产物。可演示预算不足、资源授权撤销、产物缺失与通知未送达。记忆支持明确保存、修改与确认删除。

任务、权限、预算、偏好和连接状态存于本浏览器 `localStorage` 的 `molr-assistant-prototype-v1`，刷新后恢复；存储不可用时提示退化为内存状态。设置中的「原型数据与恢复」可重置演示数据。每个助理的对话、草稿与任务引用也保存到本浏览器；页面导航与 CLI 命令历史仅保留在当前页面。此原型不连接真实模型、Runtime 或文件系统；模拟执行为手动推进，产物由内置资料生成，费用固定模拟，不代表生产执行与可靠性保证。

`#components` 按设计基础、输入与操作、聊天、导航、状态反馈、弹层、数据展示分类。设计基础（Foundations）是默认打开的第一个标签页，集中展示字体排印、圆角、间距与语义状态。示例集中在 `src/ComponentsShowcase.tsx`，新增中英文文案位于 `src/library-messages.ts`；组件本体和所有交互样式均来自 `@molr/ui`。表格可搜索、排序、多选和分页；弹窗可校验保存；通知支持撤销；任务演示可暂停与继续。这里的保存、归档、连接和任务进度只作用于示例页面，不调用业务服务。

在根目录运行 `npm run test:ui` 执行桌面和手机浏览器测试。首次使用需 `npx playwright install chromium`；也可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 复用已安装的 Chromium。组件接口见 [共享组件库](../../packages/ui/COMPONENTS.md)。

### 图形界面与平台边界

- `InterfaceShowcase` 组织 Web／Desktop／Mobile／CLI 标签，Web／Desktop 切换适配器时不重新挂载页面。
- `InterfaceWorkspace` 承载共用导航、资源与授权管理；`AssistantWorkspace` 组合聊天侧栏、助理重命名、当前对话；`AssistantChat` 承载持续对话，`AssistantPanels` 承载任务展示、记忆与用量页面。
- `interface-demo.ts` 承载演示任务状态机与本地持久化。底层类型保留 `Work`，用户界面称为「任务」。
- `InterfaceTerminal` 提供 `task list/show/new/pause/resume/next/budget/recover/cancel`、`memory list`、`usage`、资源授权和连接命令；旧 `work` 前缀仅作为兼容别名。
- `interface-platform.tsx` 提供窗口外框、系统通知与目录选择的模拟适配器，不调用浏览器通知权限或原生桌面 API。

侧栏为助理、计划、资源；资源内包含授权管理。品牌 Logo 置顶，设置图标置底，侧栏不展示 Runtime。Mobile 使用助理／计划／资源／我的底部导航，以文字颜色、字重和图标线条加重表示选中，不使用选中背景；未读徽标固定在助理图标右上角。Web 在手机屏幕下重排页面和表单，Mobile 在桌面浏览器中也按手机宽度展示。

Web／Desktop 主侧栏为 64 px 宽的 Canvas 底色图标栏，不显示常驻文字。悬停或键盘聚焦显示文字提示；悬停加粗图标，当前页面使用粗图标和品牌色，不使用选中底色。最上方使用 44 × 44 px、8 px 圆角的 Logo 点击区域，首字母动态图案为 36 × 36 px 并居中留白，背景透明，仅字形配色跟随 App 明暗主题；复用昼夜编排，点击跳过动作间等待，减少动态效果时显示静态标识。设置图标固定在最下方。窄屏 Web 将图标栏横向排列。助理列表和消息头像保持 32 × 32 px 圆形。搜索以独立图标放在主侧栏 Logo 下方，点击打开统一搜索面板。普通页面保留内容区标题，右上角统一为顶部对齐的页面操作区，放置新增计划或资源详情的返回与授权管理按钮；已移除消息中心按钮和面板。聊天页头与消息列表的内边距为 12 px；发送框区域顶部为 0，其余三边为 12 px，各端一致。

界面配色遵循 [品牌色规范](../../dev-docs/frontend/BRAND.md#品牌色) 的约 80 / 15 / 5 视觉层级：Canvas／White 承担大面积背景，Forest 承担正文、按钮与助理头像，Lime 用于用户消息气泡及少量身份与选中标记；Lime 底搭配 Forest 文字。辅助文字、分隔线及输入边框继承共享语义变量；暗色和状态反馈使用配色表已有的语义色，不在页面中添加临时色值。比例是视觉层级建议，随内容变化，不按像素强行填色。

当前为规则模拟对话，不连接真实模型；任意任务意图和修订内容的语义执行尚未实现。修改后的示例产物保存追加要求及历史版本，不宣称真实 AI 已完成改稿。

Web／Desktop 的「助理」直接打开当前助理的持续对话，移除原助理团队主页。`AssistantSidebar.tsx` 将助理列表放在聊天内部的左侧，使用白色底色，暗色主题分别使用主背景和内容表面色；侧栏 padding 和 gap 均为 0，助理列表 padding 上方与左右为 9 px、下方为 0，列表项间距为 0，列表项无额外 margin；按钮使用 8 px 控件圆角，列表助理名保持 12 px。聊天头部助理名使用正文 16 px 字号（`--text-base`）。当前助理使用 Canvas 对应的主题背景色，不使用侧边标记；悬停不改变背景色。助理头像使用 Forest 底与 Canvas 文字。「聘请新助理」按钮固定在助理侧栏最下方，左右留白同样为 9 px，使用全宽主色按钮，显示加号和「聘请新助理」文字；当前仅展示入口，不实现点击行为或创建表单。Mobile 更多菜单中的「聘请新助理」入口同样只作展示。列表显示最近消息与未读数；切换保留各自草稿。窄屏 Web 可通过聊天页头的列表按钮展开／收起。右上角包含任务和更多操作；更多菜单收纳重命名助理、会话分组、会话置顶、克隆助理、权限、计划和解雇助理，权限指向当前助理的授权管理。克隆需二次确认，说明将继承原助理的记忆、消息和权限；解雇需确认聊天记录归档及无法再发送消息，并提示「设置 → 已离职助理」的查询和返聘入口。确认后仅提示交互示意，不创建、移除或更改助理数据。

Mobile 的助理入口先显示独立列表页，顶部左侧为透明背景完整 Molr 动态 Logo，图案高 36 px，在原有 44 px 高的点击区域内左对齐、垂直居中，左侧不额外增加留白，搜索图标按钮和更多菜单按钮并排居右，均为 44 × 44 px，Logo 同样跟随主题并支持点击与昼夜编排，聘请新助理收在菜单中；侧栏 padding 和 gap 均为 0，列表项无外边距，按钮保持直角。点击助理后页面向左滑动进入聊天，助理名称前的返回按钮或聊天内容区域的右滑手势返回列表。竖向滚动、短滑动和输入器内的手势不会触发返回；减少动态效果时直接切换。聊天详情隐藏底部导航，返回列表后恢复。聊天头部的助理名与状态水平居中排列，间距为 8 px；窄屏 Web 同样采用横排，名称与状态过长时省略显示。Mobile 助理列表工具栏的下间距为 8 px。Mobile 与窄屏 Web 的普通操作按钮最小高度统一为 36 px，聊天头部按钮固定为 36 px；消息反馈图标按钮使用 36 × 36 px。两个页面保留草稿与列表状态，隐藏页面使用 `inert` 和 `aria-hidden` 排除焦点，且不会确认未读消息。

「计划」由 `PlanPanel.tsx` 管理事项、个人时间安排和自动执行，提供近期清单与共享 `PlanCalendar` 三个月日历。默认新增只需标题，可设置截止日期和可选时间段；时间段保存在同一待办记录中，日历不生成副本。无日期事项在清单查看，日历提供返回清单入口。已有待办与日程持久化数据原样兼容。

资源增加 Storage／Compute／Network／Tools 分类和对应详情。现有文件样例归入 Storage，其余分类提供能力与访问范围示例；授权仍按助理隔离。能力授权不产生真实系统操作。

主题与语言、待办筛选及编辑、日程负责人及重复频率、任务验收场景、聊天模型选择均使用共享 `Select`，统一弱边框、表面色、向内加粗的焦点反馈与下拉选项样式。模型选择使用紧凑触发器；点击选项或用键盘确认不会发送消息，Escape 取消选择并保留草稿。

设置统一收纳界面、记忆、偏好、用量、连接和数据子页面，各端均使用顶部 Tab，非移动端超宽时换行，Mobile 与窄屏保持单行并左右滚动。移动端隐藏滚动条，选中项未完整显示时平滑滚入可见区并露出相邻项；首尾项直接定位到对应端点，减少动态效果时无动画。支持方向键、Home／End 切换，选中项自动保持可见；各面板保留挂载，切换时保留未保存输入。主导航不再单列记忆或用量。记忆和偏好分别管理，旧版未标注类型的内容保留为偏好。实现见 `SettingsPanel.tsx`，测试见 `tests/settings.spec.ts`。

消息输入器拆分至 `MessageComposer.tsx`，消息展示拆分至 `ChatMessageView.tsx`；控件与消息卡片分别使用共享 8 px／16 px 圆角。textarea 单行起始，自适应到 180 px；外框默认使用弱边框，悬停时轻微加深，聚焦时向内加粗。Web、Desktop 和 Mobile 使用相同的输入器样式：内边距 12 px，发送、停止、附件和语音按钮为 34 × 34 px；仅随容器适配宽度，不单独放大 Mobile 控件。点击输入器空白区域自动聚焦 textarea，附件、模型、语音和发送控件保留自身操作；禁用时不会聚焦。支持附件元信息、演示模型选择、录音按钮（安全上下文可录音，原型不转写）、消息反馈、性能信息占位与静态卡片。自己发送的消息在气泡或附件下方右对齐显示「未读／已读」，对应模拟回复到达后标记已读，按消息与助理隔离并持久化；历史消息根据对应回复补齐状态。赞与踩使用共享 `ChatFeedback`：保留原版图形及袖套连接，选中时袖套实色填满、手掌使用同色 18% 浅填充，图标与同排复制／信息按钮统一为 15 px、24 px viewBox 内 1.7 线宽，同排按钮间距统一为 8 px，选中态无边框、无底色；赞为红色、踩为灰色。激活时赞轻弹、踩下压回弹，取消时不播放，系统减少动态效果时静态切换。UI Design 与真实 WebUI 使用同一份共享实现。显示选项在设置 → 界面中管理。

助理聊天头部和更多菜单均使用「计划」，打开当前助理的计划抽屉，并在计划下查看示例执行。负责人分配不启动执行。原型仅保存展示，不会自动执行或发送提醒。

聊天页重构为名称／状态 header、纯消息列表和现有输入器。移除消息下挂按钮；`TaskDrawer.tsx` 在宽屏从右侧、Mobile 与窄屏 Web 从底部展示任务列表与详情。助理菜单显示可持久化未读数，仅真正可见的对话确认已读。测试覆盖隐藏预览不误读、抽屉定位与焦点恢复。

事项保留紧急／高／普通／低等级；日历支持月份切换、日期跳转、方向键选日和窄屏数量显示。相关验证位于 `tests/plans.spec.ts`、`tests/calendar-priority.spec.ts` 和 `tests/schedule.spec.ts`。

界面示例下方的「重置红点」将现有助理消息重新标记为未读，方便反复查看各端菜单和助理列表的徽标效果。仅修改阅读进度，不重置对话、草稿、任务或偏好；进入对话后仍按正常阅读规则清除未读。

聊天组（英文版为 Chat）由 `src/ChatShowcase.tsx` 展示共享消息气泡、输入框、消息卡片、图片与附件、信息弹层、反馈和输入状态。组合预览支持本地发送、追加消息、模拟逐步输出和停止；消息卡片示例包含任务、交付物和权限申请，统一使用最大 480 px 宽的 `ChatCard` 与 `details` 信息行；可通过 `?components=chat#message-cards` 直达。卡片详情在桌面右侧、手机底部打开，示例交付物可预览和下载。权限申请演示预填表单、修改范围／时间、批准、拒绝和重置，只保存在示例状态中，不修改真实权限。输入示例支持文件元信息、移除附件、模型选择、禁用与录音状态演示；录音演示不访问麦克风。示例状态与助理原型隔离，不连接真实模型或上传文件。共享组件位于 `packages/ui/src/components/chat.tsx`，原型的 `ChatMessageView` 与 `MessageComposer` 也复用它们。

消息头像默认开启，位于气泡外侧，助理在左、用户在右；消息气泡示例提供独立的头像与发送者开关，产品设置 → 界面增加「消息头像」。聊天组增加独立的「助理状态」示例，可切换行动、思考、输入中、等待、完成、异常和空闲，支持紧凑显示与减少动态效果。`ChatStatus` 同时用于组合预览和助理原型的对话顶部；「正在浏览文件…」作为行动状态的说明展示。

设置 → 已离职助理使用独立示例档案展示名称／聊天内容搜索、只读归档查看和返聘确认，归档不提供发送框。返聘确认说明可继续发送消息并保留原有聊天记录；仅展示交互反馈，不修改现有助理或本地持久化状态。验证见 `tests/assistant-actions.spec.ts`。

助理列表加入分组与置顶的静态示意：Molr 显示在「置顶」区并带图钉标记，旅行助理显示在「生活」分组；其余助理归入「未分组」。分组标题显示当前可见数量，不显示空分组。分组分隔线使用共享边框色的 70% 不透明度，比普通边框更淡；各端分组头无左右内边距。Mobile 的左右 12 px 留白统一由 `assistant-list` 提供，助理项与空状态不再单独添加左右内边距，分隔线与内容对齐。更多菜单的「会话分组」打开共享 Select 选择窗口，提供未分组、日常、生活、工作；确认与「会话置顶」仅显示交互提示，不改变列表分组、顺序或保存数据。Web、Desktop、Mobile 共用此展示。

统一搜索面板由 `WorkspaceSearchPanel.tsx` 提供，复用 Dialog、SearchField 和 Select。搜索框位于面板顶部，筛选按钮常驻输入框最右侧；有内容时，清空按钮显示在筛选按钮左边，面板不显示关闭按钮，保留 Escape 与点击遮罩关闭。搜索框内左右留白为 12 px，为图标与按钮额外预留文字空间。筛选使用标准下拉多选，选项通过选中背景和勾选标记表达状态，不使用复选框；可连续选择多个来源，菜单保持展开。选择「全部」或清空选中项恢复所有来源，选中范围会显示在结果数量旁。空查询展示助理、资源、任务、计划与设置的快速跳转；输入后同时检索本地示例中的聊天记录、助理、资源、当前助理任务和待办，按来源分组，可筛选、清空并查看无结果状态。支持方向键选择、Enter 打开与 Escape 关闭，关闭后恢复入口焦点；Mobile 不显示底部按键提示，Web／Desktop 保留。聊天结果打开所属助理对话，资源与任务结果进入已有预览页面。浏览搜索结果不会确认聊天未读数。仅作界面演示，不接入远程搜索或真实数据源。

Mobile 预览使用 `ModalScope` 将搜索、确认、归档、任务详情和信息弹层统一显示为预览窗口内的底部抽屉；遮罩、进出动画与滚动均限定在预览边界，网页其它区域仍可操作。背景内容在抽屉打开期间不可聚焦，关闭后恢复焦点；多层抽屉仅允许操作最上层。下拉菜单与 Select 继续作为标准列表展开，并限制在预览边界内。下拉选项的悬停、键盘活动态和选中态使用同一背景色，选项间隔 4 px。

## 文案、断点与预览生命周期

产品代码使用 `const t = productMessages[locale]`，按 `t.common.cancel`、`t.assistantWorkspace.saveName` 等稳定字段读取文案。不要新增 `t('中文', 'English')` 或把整段文案内联在语言条件表达式中。重复使用的操作文案放在 `src/i18n/common.ts`；其他文案保留模块命名空间，避免不同语境被强行合并。姓名、数量等动态值通过类型明确的函数传入，例如 `t.common.unreadMessages(count)`，完整句式由字典决定。

语言范围由 `@molr/ui` 的 `UILocale` / `supportedLocales` 定义。新增语言时补齐品牌、组件示例、产品、共享组件和官网字典，再接入浏览器语言识别与语言选项；字典的 `Record<Locale, ...>` 及翻译对象的 `typeof zh` 会检查缺失字段和参数类型。示例聊天历史、资源名等演示数据继续属于数据模型，不把用户内容当作界面翻译键。

响应式宽度统一来自 `packages/ui/breakpoints.json`：`mobile`（700 px，手机控件和底部抽屉）、`compact`（1000 px，收起助理侧栏）。组件使用 `useBreakpoint('mobile' | 'compact')`，CSS 使用 `@media (--molr-mobile)` / `@media (--molr-compact)`，由共享 PostCSS 插件编译。不要在组件或样式中复制宽度数值；两档代表不同布局职责，不应合并为同一个断点。

InterfaceShowcase 首屏仅挂载 Web 工作区。Web / Desktop 继续共享同一工作区；Mobile、CLI 首次选择才挂载。访问过的页面用 React Activity 保留草稿、页面位置和 CLI 历史，隐藏时清理 Effects 和订阅。共享 demo 状态仍由父级持有；隐藏预览通过 memo 跳过父级 demo 数据更新，重新激活时读取最新 props；语言等 Context 的变化仍由 React 处理。

`tests/architecture-review.spec.ts` 验证语言同步与参数化文案、按需挂载与切换保留状态、隐藏页面订阅清理，以及两档断点边界上的 CSS / 组件一致性。

独立测试端口：`MOLR_TEST_PORT=5288 npm run test:ui`。测试不会复用已启动服务。

前置依赖与自动交接的完整行为在真实 WebUI／Runtime 验收；设计原型仍只展示本地安排与示例执行，不运行自动交接。

### 指令选择器

聊天分类新增独立的「指令选择器」示例，可通过 `?components=chat#command-selector` 直达。提供全部指令、关键词筛选与无匹配三种场景，演示 `/compress` 补全、发送、正在压缩和完成反馈。聊天组合、消息输入框示例及助理原型也使用相同菜单；原型只提供本地反馈，不调用 Runtime、不修改聊天历史，附件保留。

菜单复用 Select 的浮层、选项圆角和选中底色，桌面宽度上限 360 px；触屏隐藏键盘提示。原生非模态 popover 保持输入焦点，位置遵循可视区域与 Mobile 预览边界，避免被聊天容器裁切。Escape 关闭，Tab／Enter 补全，点击外部关闭；完成选择后再次提交才执行。测试见 `tests/command-selector.spec.ts`。
